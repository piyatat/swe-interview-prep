# Thermo Fisher Scientific engineering track

Sits beside [abbott.md](abbott.md), [medtronic.md](medtronic.md), and [veeva.md](veeva.md): **world leader in serving science** (NYSE: TMO) — instruments, reagents, lab software, Patheon / PPD pharma services — **not** a hospital-device Mission loop and **not** a life-sciences CRM. Official [culture](https://jobs.thermofisher.com/global/en/our-culture) mission: enable customers to make the world **healthier, cleaner and safer**. Recruiter confirms **instrument / embedded vs PPD / clinical vs enterprise IT**, Java vs C++ / Python, site, and live AI.

Typical timeline **up to ~45 days** official; SWE reports **~3–5 weeks** (Dataford 2026 — treat extra OA / panel counts as **reported**). Embedded: [../roles/embedded.md](../roles/embedded.md). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (Mission + 4i)

Do **not** invent Amazon LPs. Official 4i values ([careers culture](https://jobs.thermofisher.com/global/en/india-our-culture) + [CSR Our company](https://corporate.thermofisher.com/csr/csr-report/our-company)): **Integrity, Intensity, Innovation, Involvement**. Map **your** stories. Scientific accuracy beats “we shipped Friday.”

| Official line | What they publish |
| --- | --- |
| **Healthier, cleaner, safer** | Mission — customers do the science; you enable it |
| **Integrity** | Honor commitments; open communication; ethics |
| **Intensity** | Results with speed, excellence, and a passion to succeed |
| **Innovation** | Knowledge → differentiated products and services |
| **Involvement** | One global team; dignity and respect |

Official [interview resources](https://jobs.thermofisher.com/global/en/interview-resources): research the **JD**, STAR stories (situation / what you did / result), build rapport, connect your value to the mission, stay positive. A university recruiter (Forage) is blunt: do **not** ask “what does Thermo Fisher do?” — name a brand (Thermo Scientific, Applied Biosystems, Invitrogen, Fisher Scientific, Patheon, PPD) or an instrument / trial workflow.

“Why Thermo Fisher?” that only says “science / biotech / $40B” fails. Name a **lab-data, instrument-control, or quality** problem you have lived.

## Official + reported process

**Official** (interview resources): (1) online application (~5 min) → (2) recruiter text / phone / video / onsite, 15–60 min → (3) hiring manager, 30–60 min → (4) hiring-team round with **1–5** people, onsite or video. Clock: **up to about 45 days**. Contact them for accommodations.

**SWE (Dataford / Glassdoor 2026, treat as reported):** recruiter (4i + band) → technicals that are **resume + Java / SQL / OOP / architecture**, not a heavy CodeSignal grind on many teams → manager / panel. Instrument reqs look more like C++ / real-time / I/O; PPD / digital more like Spring + data pipelines. **Ask** which.

| Stage | Official / reported |
| --- | --- |
| Apply | [jobs.thermofisher.com](https://jobs.thermofisher.com/global/en) |
| Screen | Official recruiter 15–60 min |
| HM | Official 30–60 min |
| Team | Official 1–5 interviewers |
| Offer | Recruiter; site / hybrid is live |

Live AI: **ask**. Lab / GxP software is a reason many teams keep the pad AI-off. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md).

## How this track differs

| vs Medtronic / J&J | vs FAANG |
| --- | --- |
| **Serving science + 4i**, not a hospital Credo or six Mission tenets | Medium DSA optional; **instrument / trial / LIMS** design is first-class |
| Brands + PPD sit next to firmware | Intensity without Integrity (skipped verification) is a miss |
| Comp is life-science bands; Waltham vs site vs India hubs | “I like biotech” without a named customer workflow fails |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** Thermo Fisher brand / division — Integrity vs Intensity when a date and a quality hold collided.
2. Official STAR: situation, what **you** did, result — mapped to one 4i line.
3. Java collections / SQL / OOP if digital; C++ / sockets if instruments.
4. Design: lab-instrument ingest with checksums, backpressure, and audit trail — not a social feed.
5. Questions: instrument vs PPD vs IT, live AI, onsite days, GxP bar.
