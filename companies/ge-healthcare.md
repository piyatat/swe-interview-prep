# GE HealthCare engineering track

Sits beside [ge-aerospace.md](ge-aerospace.md), [ge-vernova.md](ge-vernova.md), and [medtronic.md](medtronic.md): **independent imaging / monitoring / digital health** (NYSE: GEHC, spun from GE in **2023**) — **not** GE Aerospace (engines / FLIGHT DECK) and **not** GE Vernova (grid / wind). Official [About](https://www.gehealthcare.com/en-us/about): **creating a world where healthcare has no limits**; ~**54k** colleagues; FDA AI-enabled device authorizations are a published talking point. Recruiter confirms **imaging vs monitoring vs digital / cloud vs embedded**, C++ / Java vs Python, site vs remote, and live AI.

Typical timeline **~3–5 weeks** (Dataford / Glassdoor 2026; treat extra OA / panel counts as **reported**). Embedded: [../roles/embedded.md](../roles/embedded.md). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (operating principles + values)

Do **not** recycle FLIGHT DECK, Vernova Way, or pre-2023 GE Leadership Behaviors as if they were this ticker. Official [Culture and Values](https://www.gehealthcare.com/en-us/about/employee-experience-and-support/culture-and-values) + About **Culture in action**. Map **your** stories.

Careers home ([careers.gehealthcare.com](https://careers.gehealthcare.com/)): mission copy is **make healthcare better**; they also post a **fraud alert** (GE HealthCare never asks you to pay). “Why GE HealthCare?” that only says “GE / medical devices / I like AI” fails. Name an **imaging workflow, DICOM, monitoring, or SaMD quality** problem. Do **not** reuse a FADEC or grid story.

## Official + reported process

Official how-to-apply is high-level (search / apply on the careers site, talent community). Dataford / Glassdoor fill SWE detail — treat round **counts** as **reported**. **Ask** HireVue vs live, OA vs skip.

| Stage | Official / reported |
| --- | --- |
| Apply | [Careers](https://careers.gehealthcare.com/) / Workday |
| Screen (reported) | Recruiter / HR (~15 min on some loops) then HM |
| Technicals (reported) | Coding (live or OA); some loops add system design |
| Behavioral | Operating principles + values; clinician / quality stories |
| Offer | Background; imaging vs digital vs embedded is live |

**JDs** (Workday samples, 2026): Molecular Imaging / platform C++ on Linux + OOD; Science & Technology cloud / Spring Boot + distributed services. Prep the **req**, not a generic GE hour. Device software may name **IEC 62304 / SaMD** — only if the posting says so.

Live AI: **ask**. GE Aerospace publishes an AI-off interview policy; GE HealthCare’s careers home does **not** copy that page. A regulated imaging stack is still a reason many teams keep the pad AI-off. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md).

## How this track differs

| vs GE Aerospace / GE Vernova | vs Medtronic / FAANG |
| --- | --- |
| **Imaging + no-limits purpose**, not engines or grid | Medium DSA on some teams; **workflow / image pipeline** design |
| Independent GEHC ticker since 2023 — three different companies | Quality / 510(k) language helps on device teams, not every cloud role |
| Comp is public-company RSUs + bonus | “Why GE?” without naming **HealthCare** is a miss |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** GE HealthCare product line — Serve patients when a deadline and a verification hold collided.
2. Easy–medium array / OOP if there is a coding hour; C++ ownership if the JD is imaging.
3. Design: PACS / image routing with checksums, downtime, and audit trail — not a social feed.
4. STAR: Lean mindset on a defect that reached a clinician.
5. Questions: imaging vs digital, live AI, site, IEC 62304 vs skip.
