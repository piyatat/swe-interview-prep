# Boeing engineering track

Sits beside [ge-aerospace.md](ge-aerospace.md) and [lockheed-martin.md](lockheed-martin.md): **commercial + defense + space airframer** (737 / 787 / BDS / Phantom Works / satellites), not an engine OEM loop and not a FAANG feed. Official [Working here](https://jobs.boeing.com/working-here/): mission to **connect, protect and explore**. Recruiter confirms **Commercial vs BDS vs space**, C++ vs Java / .NET, **onsite vs hybrid vs virtual**, and **clearance** on the req.

Typical timeline **~3–5 weeks** of active eval (Dataford); background / clearance can stretch the calendar. Embedded: [../roles/embedded.md](../roles/embedded.md). OA: [../general/online-assessments.md](../general/online-assessments.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (five values)

Do **not** invent Amazon LPs. Official [People & Culture](https://www.boeing.com/company/people-and-culture) + [Working here](https://jobs.boeing.com/working-here/). Map **your** stories.

| Official value | Behaviors they publish |
| --- | --- |
| **Safety & Quality** | Keep people safe; respect consequences; **speak up** |
| **Trust** | Customer priorities; follow through; do the right thing |
| **People Focus** | Look out for each other; ask for / give help; collaborate respectfully |
| **Ownership** | Give a damn; accountable and decisive; pursue excellence |
| **Innovation** | Do cool things; curious and courageous; shape the future |

“Why Boeing?” that only says “planes / I like aerospace” fails. Name a **program** (airliner vs BDS vs space) and a **speak-up / safety** story. Culture language on the same page is **restore trust** after quality misses — do not dodge it.

## Official + reported process

Official [FAQ](https://jobs.boeing.com/Faq): apply only at **boeing.com/careers**; recruiter tells you if a **standardized assessment** is required; clearance = DCSA when the req says so. Official [Interview Preparation Guide (PDF)](https://tbcdn.talentbrew.com/company/185/v3_0/pdfs/Boeing_InterviewPrepGuide_2025.pdf): panel of **2–4**; **STAR**; possible case / presentation / **coding playground or whiteboard** (recruiter warns ahead); virtual = **Microsoft Teams**. **Ask** CodeVue / HackerRank vs panel-only.

| Stage | Official / reported |
| --- | --- |
| Apply | [Careers](https://jobs.boeing.com/) / boeing.com/careers |
| Recruiter | Fit, site / Role Type, **citizenship / clearance** |
| Assessment (if told) | Standardized test; reported HireVue / HackerRank / CodeVue on some SWE reqs |
| Panel | Official 2–4 people, 45–60 min: STAR + role knowledge; some teams add coding |
| Offer + start | Background; clearance can **delay start** |

Live-AI rules are **not** published on careers — ask. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md). JDs for flight software name **DO-178C** — only prep that if the req says so.

## How this track differs

| vs GE Aerospace / Lockheed | vs FAANG |
| --- | --- |
| Official **five values** + STAR PDF; airframer + BDS + space | Loop is often **one panel**, not five DSA hours |
| Design is **avionics / VMS / factory / SATCOM**, not a social feed | Clearance / export is a **gate** on many BDS reqs |
| “Why Boeing?” must name **program + Safety & Quality** | Comp is bands + Total Rewards — not public RSUs |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** airplane / BDS / space program — Safety & Quality when you **spoke up**.
2. OOP pillars + ArrayList vs LinkedList; C++ memory if the JD is embedded.
3. Design: ingest aircraft / factory telemetry without dropping a safety alert.
4. STAR: overload or conflict mapped to **Ownership / People Focus** (PDF example is prioritization).
5. Questions: assessment vs skip, coding playground, live AI, hybrid vs site, clearance.
