# T-Mobile engineering track

Sits beside [att.md](att.md) and [verizon.md](verizon.md): **Un-carrier / Magenta software** (subscriber platforms, billing, Core & IP automation, T-Ads) — not “AT&T with a different logo.” Official [culture](https://careers.t-mobile.com/culture-and-benefits/page/231) names five **Un-carrier values**. Recruiter confirms **consumer vs network / Core vs T-Ads**, Java vs C++ / Angular, Bellevue / Frisco / remote, assessment vs skip, and live AI.

Typical timeline **~2–4 weeks** (TechPrep 2026). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). Notifications: [../answers/system-design-notification.md](../answers/system-design-notification.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (Un-carrier values)

Do **not** invent extra LPs. Official [Culture & Benefits](https://careers.t-mobile.com/culture-and-benefits/page/231): map **your** stories. Official military toolkit tells interviewers to use **STAR** and asks Un-carrier “why Magenta” prompts.

| Official value | What they publish |
| --- | --- |
| **Love our customers** | Customer love, not generic “service” |
| **One team, together** | Listen, include, win as one org |
| **Dream big and deliver** | Aim high, take smart risks, own results |
| **Do it the right way. Always.** | Customers, shareholders, society, each other |
| **We won’t stop** | Relentless; make change, don’t wait for it |

“Why T-Mobile?” that only says “telecom / 5G” fails. Name a **subscriber, billing, or network-adjacent** problem you have lived. Official Core & IP SWE JDs ask you to **review and validate AI-generated code** — that is job skill, not a free pass to Copilot in the pad. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md).

## Official + reported process

**Official** ([FAQ](https://www.t-mobile.com/careers/for-applicants/faq) + [how to apply](https://www.t-mobile.com/content/dam/t-mobile/assets/pdf/Military_Career_Toolkit_2.pdf)): apply (often under 10 min) → some roles get an **assessment** (up to ~1 hour; results valid **6 months**) → review up to **two weeks** → interview (could be one week to three months) → decision. Professional / exec roles **require a resume**. Intern loops are **virtual**, Fall through March ([internships](https://careers.t-mobile.com/internship)).

**SWE (TechPrep 2026, treat as reported):** recruiter 30 min → HackerRank or Zoom coding 45–60 min (1–2 mediums, sometimes **debug** or talk AI tooling) → HM + senior 1–2 h (resume deep-dive, architecture, STAR). Some teams split the closer.

| Stage | Official / reported |
| --- | --- |
| Apply | [careers.t-mobile.com](https://careers.t-mobile.com/) / Candidate Home |
| Assessment (some roles) | Official; 6-month reuse; not every SWE posting |
| Recruiter | Fit, Un-carrier, location, live AI |
| Coding (guides) | Medium arrays / strings / hashes; OOP / SOLID review shows up |
| Closer | Defend **why that stack**; STAR vs the five values |
| Offer | Official: they may keep the resume for other reqs |

## How this track differs

| vs AT&T / Verizon | vs FAANG |
| --- | --- |
| Five **Un-carrier** lines, not AT&T pillars or Verizon Culture OS | Leaner loop; **resume audit** beats olympiad DP |
| Assessment is **role-gated** and reused 6 months | Design is **billing / notify / HA APIs**, not a social feed |
| Comp is carrier bands; Bellevue / Frisco hubs | Frame wins as **subscriber impact**, not query latency alone |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** T-Mobile org — Love our customers when a release and a billing outage collided.
2. Valid palindrome / Two Sum / debug a small REST handler if there is a screen.
3. Design: push notify or a high-throughput **billing API** with retries.
4. STAR: One team, together across consumer + network orgs.
5. Questions: assessment vs skip, HackerRank vs Zoom, live AI, site.
