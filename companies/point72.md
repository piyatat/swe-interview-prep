# Point72 engineering track

Sits beside [quant.md](quant.md) and [citadel.md](citadel.md): **multi-manager / Cubist systematic SWE** (NYC / Stamford / London / Warsaw / …) — not Citadel Securities’ one-problem day and not Jane Street’s official pair loop. Official [Our Values](https://point72.com/our-values/): premier asset manager via **risk-adjusted returns, ethics, talent**. Recruiter confirms **Cubist vs firm Technology vs Academy**, language (**Python / C# / Java / C++**), city, and AI.

Typical reported path **~3–5 weeks** (Dataford, Sep 2026): OA → tech screen → Superday. Behavioral from the official recruiter playbook. ## Official culture (five values)

Do **not** invent Amazon LPs. Official [Our Values](https://point72.com/our-values/) + [Working Here](https://point72.com/working-here/): flat, entrepreneurial, mentorship. Map **your** stories.

| Official value | Published line |
| --- | --- |
| **Ethics & Integrity** | Conduct ethically, always; resume lies are a **deal breaker** |
| **Firm First** | One firm; succeed together |
| **Innovation & Excellence** | Not satisfied with the status quo |
| **Growth & Development** | Advance professional and personal development |
| **Community** | Contribute where you live and work |

“Why Point72?” that only says “hedge fund / Steven Cohen” fails. Name **this** seat: [Cubist](https://point72.com/cubist/) systematic (research + quant developers) vs **Technology** (cloud, data, AI, tax / controller / trade-processing platforms). Official mission: superior **risk-adjusted** returns — not “I want to trade.”

## Official interview stance (recruiters, Dec 2025)

Official [Interview Tips from Point72 Recruiters](https://point72.com/blog/interview-tips-from-point72-recruiters/). Applies across businesses; SWE still gets a coding bar on top.

| They score | Prep |
| --- | --- |
| **How you think, learn, decide** | Intention behind school / role choices; not a script |
| Resume **trust** | Current, complete, no omitted jobs; tools + quantified impact |
| Curiosity | “Why of the why”; extra-curriculars / independent research help |
| Learning on the job | How you would pick up a missing skill |
| Ambiguity | “I don’t know” **plus** how you would find out; 30 seconds to think is allowed |
| Motivation | Why **this** firm and role; later rounds: cite something you learned in process |

Official: they will educate you on the firm; they will **not** talk you into joining. Academy podcast + events are the published prep. Ask real questions — interviews are two-way.

## Official + reported process

No public SWE stage list. Treat stages as **reported** (Dataford 2026; Glassdoor 2026). Recruiter wins on the week-of slate.

| Stage | Official / reported |
| --- | --- |
| Recruiter | Background, why Point72, **Cubist vs Tech**, location, compensation band |
| OA (reported) | HackerRank-class: DSA and often **SQL** / parsing |
| Tech screen | Live coding or practical parse (paginated JSON API → aggregates) |
| Superday | 2–3 virtual hours: coding, design or OOD, behavioral / HM |
| Variant | Some teams: take-home; some 2026 reports: **AI-assisted coding** + ML design — **ask** |

[../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md): live-AI is **not** a published FAQ line. Confirm.

## How this track differs

| vs Citadel LLC / Jane Street | vs FAANG |
| --- | --- |
| Official **ethics + curiosity** bar before the pad | Design is **OMS / research / cloud / risk**, not a social feed |
| Cubist wants **hands-on coding + research**; Tech wants platforms (K8s, data, AI) | SQL + messy JSON shows up more than at most product loops |
| Superday is short vs Securities’ 4–5 hour one-problem | Comp is bonus-heavy — price it after a **written** offer |

## Coding and design flavor

Reported: mediums (arrays, BFS, custom hash maps), spiral / parsing, **REST pagination + filters**, SQL indexes, quote-handler / last-tick design, sometimes RAG / ML system design on AI teams. Related: [../answers/coding-spiral-matrix.md](../answers/coding-spiral-matrix.md), [../answers/system-design-metrics.md](../answers/system-design-metrics.md).

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** Point72 team (Cubist vs Data Platform vs Cloud) — portable “markets are interesting” is weak.
2. OA / screen: medium + a SQL or paginated-API parse; narrate edge cases.
3. Design: last-quote aggregator across venues, or a research feature store.
4. Recruiter-style: how you would learn a stack you do not have; a time you were wrong.
5. Questions: live AI, OA vs take-home, NYC vs Stamford vs Warsaw, bonus structure.
