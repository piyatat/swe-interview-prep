# GitHub engineering track

Sits beside [product-companies.md](product-companies.md) and [atlassian.md](atlassian.md): **AI-powered developer platform** (git hosting, PRs, Actions, Copilot), not a generic FAANG slate. Official [Experienced Professionals](https://www.github.careers/experienced-professionals): Talent conversation → hiring manager → **tool-based assessment** (coding exercise or writing assignment) → panel that scores skills **and** values. Official careers home: **remote-first**; 150M+ developers. Recruiter confirms **take-home vs live pad**, Copilot / Actions vs platform loop, and AI policy.

Typical timeline **4–6 weeks** (2026 guides). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). Pair: [../general/pair-programming.md](../general/pair-programming.md). Review: [../general/code-review-rounds.md](../general/code-review-rounds.md). Take-home: [../general/take-homes.md](../general/take-homes.md). ## Official culture (six values)

Do **not** recite posters. Map **your** stories. Official [GitHub Careers](https://www.github.careers/careers-home/):

| Official value | What they score |
| --- | --- |
| **Customer-obsessed** | Developer / org success; validate assumptions with feedback |
| **Ship to learn** | Ship often; calculated risk; pivot when wrong |
| **Growth mindset** | Curiosity; team learning speed over current knowledge |
| **Own the outcome** | Success **and** failure; the world depends on the platform |
| **Better together** | Kindness; others’ strengths; every ship is a team ship |
| **Diverse & inclusive** | Teams that reflect the global developer community |

“Why GitHub?” that only says “I use git / Copilot” fails. Name a **permissions, CI, or review-at-scale** problem you have lived.

## Official + reported process

Official experienced-professionals page is the skeleton. 2026 guides (TechPrep) stretch it — treat take-home hours and round counts as **reported**.

| Stage | What they score |
| --- | --- |
| Talent conversation (official) | Interests, competency stories; recruiter is your guide |
| Hiring manager (official) | Skills vs the posting; impact you owned |
| Tool-based assessment (official) | Guides: 48–72h take-home — Git hygiene, README, tests, not only “it runs” |
| Interviews (official) | Knowledge + **values**; guides: pair, code review, developer-infra design |
| Behavioral / HM close (guides) | Remote collaboration, feedback, knowledge sharing |

Official prep: review **values + leadership / manager fundamentals**; tell a story; spell out **your** contribution; ask clarifying questions; highlight impact you can measure.

## How this track differs

| vs FAANG | vs Atlassian / Microsoft-shaped loops |
| --- | --- |
| Official: **practical assessment** + values on the panel | Atlassian: values + Team Anywhere SaaS; Microsoft is in [faang-big-tech.md](faang-big-tech.md) |
| Design is **git, Actions, search, permissions**, not “design Twitter” | Same collaboration bar; GitHub is **developer workflow** |
| Remote-first written + Git fluency is scored | Puzzle-hard DSA is not the brand |

## Coding and design flavor

DSA: medium, **readable + tested**. Guides: REST-shaped tasks and small game/API logic more than olympiad graphs. Design: Actions / job fan-out, code search, repo storage + refs, notifications, rate limits. Related: [../answers/system-design-search.md](../answers/system-design-search.md), [../answers/system-design-notification.md](../answers/system-design-notification.md), [../answers/system-design-rate-limiter.md](../answers/system-design-rate-limiter.md).

## Sample prompts (shapes, not leaked puzzles)

1. “Ship to learn — you shipped, it was wrong, you pivoted.”
2. Take-home: small API + tests; commit history reads like a PR.
3. Live pair: extend an existing module; narrate before you type.
4. Design GitHub Actions: queue, runners, secrets, blast radius of a malicious workflow.
5. Better together: how you share context on a distributed team.

## Prep checklist

- [ ] Read [Experienced Professionals](https://www.github.careers/experienced-professionals) + [values](https://www.github.careers/careers-home/)
