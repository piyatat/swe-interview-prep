# Riot Games engineering track

Sits beside [epic-games.md](epic-games.md) and [unity.md](unity.md): **player-first live games (League, VALORANT, TFT, Wild Rift, 2XKO)**, not an engine-license house. Official [Who we are](https://www.riotgames.com/en/who-we-are): **We Are Player First**; **4,500+** Rioters, **20+** offices, LA HQ. Recruiter confirms **gameplay / backend / tools / client**, C++ vs C# vs Go, and **home-office hybrid** (most Rioters live in the same state / country as the office).

Typical timeline **~4–8 weeks** (2026 guides). Take-homes: [../general/take-homes.md](../general/take-homes.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official hire bar (do not invent extra pillars)

Official [Who we are](https://www.riotgames.com/en/who-we-are) + [Interviewing at Riot](https://www.riotgames.com/en/work-with-us/interviewing-at-riot). Stories use **S.A.O.** (Setting, Action, Outcome) — official FAQ, not STAR-by-name.

| Official signal | What they score |
| --- | --- |
| **Player First** | A craft call that served players, not “I main Challenger” |
| **Hyper-serve the core** | You designed for the people who care most, then expanded |
| **Be part of the community** | Empathy in a live-ops or support-adjacent decision |
| **Foster a thriving ecosystem** | Fair / safe / welcoming — anti-cheat, toxicity, economy |
| **Support players everywhere** | Latency, locale, or access you actually shipped |
| **In for the long term** | A choice that cost a quarter and paid off later |

“Why Riot?” that only says “I play League / VALORANT” fails. Name a **live-ops, matchmaking, anti-cheat, or client-perf** problem you have lived. Official FAQ: applying to **every** req is a negative signal; pick the craft.

## Official + reported process

Official [Interview Process](https://www.riotgames.com/en/work-with-us/interviewing-at-riot/interview-process) + Interviewing at Riot. Whiteboard is **diagrams.net**; Hangouts; casual dress. Treat OA *contents* as **reported**.

| Stage | Official / reported |
| --- | --- |
| Recruiter | Experience, interests, role; Hangouts or phone |
| Early Hangouts (official: generally **two**) | Past work, **craft**, skills, value alignment |
| Take-home (role-dependent, official) | Engineering is named; flexible due date; ask for more time |
| Panel (official: remote “onsite”) | Meet the team same day; ~10 min Q&A each hour |
| Offer | Mission: make it better to be a player; confirm **site / hybrid** |

Guides (TechPrep 2026; official intern [tech-assessment guide](https://www.riotgames.com/en/news/technical-assessment-internship-study-guide-vol-4)): HackerRank **or** live pad; themed game-state OA; craft hour; mid+ design (matchmaking / leaderboard / store); values hour can veto strong DSA. Confirm AI-in-pad.

## How this track differs

| vs Epic Games / Unity | vs FAANG web |
| --- | --- |
| Official **Player First + S.A.O.** | Design is **live-service game infra**, not a social feed |
| Take-home is **published** for many eng roles | Coding is **simulation / grid / state**, not only Blind 75 |
| Hybrid + live near the office (official FAQ) | “I only grind LeetCode” misses player stories |

## Coding and design flavor

Simulation, grids, hashes, pathfinding, game-state machines. Design: matchmaking, presence, inventory, anti-cheat. Related: [../answers/coding-rotting-oranges.md](../answers/coding-rotting-oranges.md), [../answers/system-design-chat.md](../answers/system-design-chat.md). Official intern guide: practice timed HackerRank; pick the language the **team** uses.

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** player-first studio — a feature you would change in League or VALORANT **and why it is an eng problem**.
2. Value: hyper-serve the core — a time you disappointed a casual flow to protect the dedicated.
3. Live / OA: grid or state sim; name the invariant before you code.
4. Design: skill + ping matchmaking; what you relax last when the queue is starving.
5. Questions for them: gameplay vs platform vs tools, take-home vs live, office rhythm, AI policy.
