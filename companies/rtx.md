# RTX engineering track

Sits beside [lockheed-martin.md](lockheed-martin.md) and [ge-aerospace.md](ge-aerospace.md): **three-business aerospace / defense** (Collins Aerospace, Pratt & Whitney, Raytheon) under **RTX** — not a FAANG feed and not “Raytheon-the-old-company” as if Collins / P&W did not exist. Official [Values](https://www.rtx.com/who-we-are/our-values): safer, more connected world. Recruiter confirms **which business + site** (Tucson missiles vs East Hartford engines vs Collins avionics), C++ vs Python / Java, and **clearance**.

Typical timeline **~3–5 weeks** of active eval (Dataford); some reqs run longer. Embedded: [../roles/embedded.md](../roles/embedded.md). Behavioral: [../general/behavioral.md](../general/behavioral.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (six values)

Do **not** invent Amazon LPs. Official [Our Values](https://www.rtx.com/who-we-are/our-values). Map **your** stories.

| Official value | Behaviors they publish |
| --- | --- |
| **Safety** | Follow policy; **speak up** and support those who do |
| **Trust** | Ethical decisions; open and honest |
| **Respect** | Different viewpoints; courteous and fair |
| **Accountability** | Deliver; clear goals; own the outcome |
| **Collaboration** | One team across the enterprise; share knowledge |
| **Innovation** | Experiment, learn, adapt; stay curious |

“Why RTX?” that only says “missiles / I like defense” fails. Name **Collins vs Pratt vs Raytheon** and a **safety / integrity** story. Do **not** reuse a Honeywell Aerospace (HONA) or GE Aerospace story as if it were this tenant.

## Official + reported process

Official careers / fraud pages: apply at **careers.rtx.com**; review → interview(s) → **role-specific background check** → offer. Mail is `@rtx.com` (also `@hirevue.com` / Workday). Three businesses are named on the same fraud page. Raytheon [Software Engineering](https://careers.rtx.com/global/en/raytheon-software-engineering/) lists real-time, DSP, ML / autonomy, cyber, DevOps — **Raytheon BU only**. **Ask** HireVue vs live, take-home vs panel.

| Stage | Official / reported |
| --- | --- |
| Apply | [Careers](https://careers.rtx.com/) — Collins / P&W / Raytheon reqs |
| Screen (reported) | Recruiter or HireVue: background, site, salary band, **clearance** |
| Panel (reported) | 2–5: resume, C++ / OOP, project; some teams add a snippet or take-home |
| Offer + start | Background / drug screen; clearance can **delay start** |

Live-AI rules are **not** published on careers — ask. Default in a cleared room is unaided. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md).

## How this track differs

| vs Lockheed / GE Aerospace | vs FAANG |
| --- | --- |
| Official **six values**; three BUs on one careers tenant | Loop is **resume + OOP panel**, not five DSA hours |
| Design is **radar / engine control / avionics**, not a social feed | Clearance / ITAR is a **gate** on many reqs |
| “Why RTX?” must name **Collins / P&W / Raytheon** | Comp is program bands — not public RSUs |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** RTX business — Safety when you spoke up on a bad test.
2. OOP + virtual dispatch + stack vs heap if the JD is C++.
3. Design: ingest radar / FADEC / avionics samples without dropping a track.
4. STAR: disagreement mapped to **Respect / Collaboration**; a miss mapped to **Accountability**.
5. Questions: which BU, HireVue vs skip, take-home, live AI, hybrid vs site, clearance.
