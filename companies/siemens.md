# Siemens engineering track

Sits beside [cadence.md](cadence.md) and [synopsys.md](synopsys.md): **industrial software + OT** (Digital Industries, Smart Infrastructure, Mobility) and **Siemens EDA** — not a pure EDA house and not a FAANG cloud loop. Official [Jobs](https://www.siemens.com/en-us/company/jobs/): *technology with purpose*; **top-10 software company, #1 in industrial software**. Recruiter confirms **DI / Xcelerator vs EDA vs Mobility vs Smart Infrastructure vs cloud**, C++ vs Java / .NET, site, and **AI-off live**.

Typical timeline **~4–6 weeks** (Dataford). Embedded / PLC-adjacent: [../roles/embedded.md](../roles/embedded.md). OA: [../general/online-assessments.md](../general/online-assessments.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (purpose + priorities)

Do **not** invent Amazon LPs. Official [strategy](https://www.siemens.com/en-us/company/about/strategy/): purpose is **We create technology to transform the everyday, for everyone**. Company presentation (same purpose page family) names **four** strategic priorities. Map **your** stories. DEGREE is a **sustainability scorecard**, not an interview rubric — do not treat it as LPs.

| Official language | What they score |
| --- | --- |
| **Customer impact** | You thought customer-first on a factory / grid / train miss |
| **Technology with purpose** | A real-world constraint (safety, uptime), not a demo |
| **Empowered people** | A decision you took in the company’s interest |
| **Growth mindset** | Try / learn / improve — a bet you reversed with data |
| **Official AI hiring rules** | You stayed authentic; live pad is **yours** |

Official [Jobs](https://www.siemens.com/en-us/company/jobs/): **2–3 days mobile working** is the worldwide hybrid standard. Scam line (same page): Siemens **never** asks for financials in hiring; interviews come from an **official Siemens email**, never Gmail.

“Why Siemens?” that only says “Germany / industry 4.0 / I like AI” fails. Name a **PLC, SCADA, EDA, or rail** problem you have lived.

## Official + reported process

Official how-to-apply is **three** buckets (find/apply → contact/meet → offer). Dataford (2026-10) fills SWE detail — treat extra OA / panel steps as **reported**. **Ask** HackerRank vs live.

| Stage | Official / reported |
| --- | --- |
| Apply | [Jobs](https://www.siemens.com/en-us/company/jobs/) / [job portal](https://jobs.siemens.com/); skill-based CV match (AI **does not** decide hire) |
| Contact | Dashboard / inbox; interview invite if experience matches |
| HR screen (reported) | Background, site, motivation |
| OA / tech screen (reported) | CS MCQs + 1–2 coding (HackerRank / HackerEarth) |
| Technicals (reported) | 1–3 live: DSA, C++ / Java internals, resume |
| Manager / panel + HR | Fit, logistics; then offer + onboarding |

**Official AI policy:** polish CV / research is welcome. **No AI** in live interviews or assessments unless the round is explicitly scoring AI skill. Do not submit AI content that misrepresents you. Pair: [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md).

## How this track differs

| vs Cadence / Synopsys / FAANG | vs Garmin / TI |
| --- | --- |
| Official **purpose + AI-off live**; industrial software at global scale | Still **C++ / Java** shops; confirm EDA vs factory software |
| Design is **OT / MES / rail / EDA**, not a social feed | Less watch-firmware, more **plant / tool / grid** |
| Hybrid 2–3 days named on jobs | Divisions diverge — **ask** Siemens EDA vs DI |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** Siemens business — Customer impact on a safety or uptime miss.
2. OA: medium DSA **plus** OS / OOP MCQs; then live C++ ownership or Java concurrency.
3. Design: roll a controller image to a plant without bricking the line.
4. When you would **reject** a Copilot suggestion in safety-critical code.
5. Questions: DI vs EDA vs Mobility, site, OA vs skip, AI-off (official).
