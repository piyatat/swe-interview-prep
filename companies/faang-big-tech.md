# FAANG / big tech track

Structured loops, **committee or bar-raiser gatekeeping**, heavy DSA + system design, and consistent behavioral rubrics. Timeline typically **4–8 weeks**.

## Standard pipeline

1. **Recruiter screen** (30 min) — leveling, logistics, visa, comp range
2. **Technical phone** (45–60 min) — 1–2 coding or early design
3. **Virtual onsite** (4–6 h) — 2–3 coding, 1–2 design, 1–2 behavioral
4. **Debrief / hiring committee** — you are not in the room; wait 1–2 weeks
5. **Team matching** (Google, some others) — separate hurdle after hire decision

## Company nuances (2026)

| Company | Distinctive signal |
| --- | --- |
| **Google** | Hiring Committee reviews packet; “Googleyness”; 2–3 coding + design (L5+) |
| **Meta** | Fast coding rounds; product sense for some tracks; E5+ design |
| **Amazon** | **16 Leadership Principles in every round**; Bar Raiser veto; 15–20 STAR stories |
| **Apple** | Depth on domain; longer onsite days possible |
| **Microsoft** | “As Appropriate” interviewer (bar-raiser-like); culture + potential |

## Amazon-specific prep

- Map **15–20 STAR stories** to LPs: Customer Obsession, Bias for Action, Dive Deep, Earn Trust, Deliver Results, Ownership, Invent and Simplify…
- Expect **2–4 LP questions per round**, including coding rounds (2024–2026 shift).
- Bar Raiser probes **depth and consistency** — “team delivered” fails; “I did X → Y metric” passes.
- Rubric includes **AI literacy** — how you verify tool output, not just use it.

## Google-specific prep

- HC never met you — **written feedback consistency** across interviewers matters.
- Strong **hire** in coding but weak behavioral can still fail packet review.
- Ambiguity tolerance — clarify, then proceed without perfect specs.

## What interviewers score

| Round | Rubric focus |
| --- | --- |
| Coding | Correctness, complexity, communication, edge cases, clean code |
| System design | Requirements, estimations, tradeoffs, failure modes — not buzzwords |
| Behavioral | Ownership, collaboration, leadership at level |
| Bar raiser / AA | “Better than median in role” — veto if inconsistent signals |

## 2026 shifts

- Bar **~1σ higher** than 2021 for same level (Pragmatic Engineer survey).
- More **debugging / comprehension** and AI-collaboration rounds at some companies.
- **Downleveling** more common — pass bar but lower level than expected.

## Prep checklist

- [ ] 40+ mediums solved with **spoken narration**
- [ ] 6+ full system design mocks with estimations
- [ ] Behavioral bank sized for Amazon if applying there (15–20)
- [ ] Recruiter asks: AI policy, round types, leveling target
- [ ] Same story **never** contradicts across interviewers

## Sample big-tech-only questions

1. “Tell me about a time you disagreed with your manager’s technical decision.” (LP / Googleyness)
2. Design **YouTube** / **Twitter** / **Dropbox** — pick one, full 45-min framework.
3. Coding: **merge k sorted lists**, **serialize BT**, **word break II** — senior favorites.
