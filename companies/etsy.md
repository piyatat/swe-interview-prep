# Etsy engineering track

Sits beside [ebay.md](ebay.md) and [shopify.md](shopify.md): **Keep Commerce Human — unique / handmade / vintage marketplace**, not a SKU catalog or generic commerce platform. Official [Careers](https://careers.etsy.com/): mission in three words; hubs in **Brooklyn, Mexico City, Dublin**. Official [Guiding Principles](https://careers.etsy.com/guiding-principles) are the hire bar. Official [Engineering](https://careers.etsy.com/engineering): **continuous deployment**; primary languages **PHP and JavaScript**, also Java, Go, Swift. Recruiter confirms **track**, pad language, hub vs remote, and **AI-in-pad** (official People page: humans stay central to hiring decisions).

Typical timeline **3–5 weeks** (2026 guides). Search / rank: [../answers/system-design-search.md](../answers/system-design-search.md), [../answers/system-design-recommendation.md](../answers/system-design-recommendation.md). Payments: [../answers/system-design-payment.md](../answers/system-design-payment.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official guiding principles (do not invent extra pillars)

Official [Guiding Principles](https://careers.etsy.com/guiding-principles). Map **your** stories.

| Official principle | What they score |
| --- | --- |
| **We commit to our craft** | Continuous learning; excellence — code is craft ([Code as Craft](https://codeascraft.com/)) |
| **We minimize waste** | Time / energy on the highest-impact work |
| **We embrace differences** | Seek other perspectives; inclusive products and panels |
| **We dig deeper** | Curious; intuition **plus** evidence; decide with confidence |
| **We lead with optimism** | Mission + teammates; ambitious goals without fake cheer |

Official [People](https://careers.etsy.com/People): **competency-based** rubrics, **same question order** per candidate, trained panels, diversity of thought on the loop. AI in hiring: “smooth and transparent” while **keeping real human connection central to every decision**. “Why Etsy?” that only says “I buy there / I like handmade” fails. Name a **unique-inventory search, seller-tool, or marketplace-trust** problem you have lived.

## Official + reported process

Official pages describe **mission, principles, and how panels are run**, not a universal stage list. 2026 guides (techinterview.org; CleverPrep) — treat counts as **reported**.

| Stage | Official / reported |
| --- | --- |
| Recruiter | Mission fit, hub (Brooklyn / Mexico City / Dublin), level |
| Technical phone (guides: ~60) | One DSA medium; hash maps / two pointers / light graphs |
| Onsite coding (guides: 2) | Clean mediums; narration; complexity before you type |
| System design (guides: mid+) | Listing search, cold-start recs, checkout / escrow |
| Craft deep-dive (guides) | How you work — CD, tests, a migration you would still defend |
| Behavioral + HM | Principles + ownership; team roadmap |

Guides: design is **one-of-a-kind inventory**. Popularity and item-CF that assume a SKU returns next week **break**. Lean on content (tags, image, shop, style) and seller quality. Stack reality: older surfaces PHP; newer services Java/Scala; ML in Python — interview in your strongest language, but reason about a legacy-to-service cut.

## How this track differs

| vs eBay / Shopify | vs FAANG |
| --- | --- |
| Official **Keep Commerce Human** + five principles; eBay is DNA / BrightHire | Practical marketplace design over puzzle hardness |
| Inventory is **unique and can sell out forever** | Official **consistent rubrics**; not a sports-draft HC |
| Craft / CD culture ([Code as Craft](https://codeascraft.com/)) | Hybrid hubs are official, not a footnote |

## Coding and design flavor

Coding: medium DSA; occasionally strings / graphs dressed as listings. Design: search over highly variable listings (cold start, freshness, seller trust), recommendations when the item never restocks, payment + dispute / chargeback with ledger vs provider consistency. Related: [../answers/system-design-search.md](../answers/system-design-search.md), [../answers/system-design-recommendation.md](../answers/system-design-recommendation.md), [../answers/system-design-payment.md](../answers/system-design-payment.md).

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** marketplace — unique goods, not “I like e-commerce.”
2. Design: rank listings with almost no engagement history.
3. Design: recs after a one-of-a-kind item sells — what signal is left?
4. Principles: minimize waste — the project you **stopped**.
5. Questions for them: hub days, PHP vs service migration, AI coding policy.
