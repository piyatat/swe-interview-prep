# EA / Electronic Arts engineering track

Sits beside [riot.md](riot.md) and [epic-games.md](epic-games.md): **multi-studio interactive entertainment (EA Sports / Respawn / BioWare / …)**, not Riot’s Player-First Hangouts and not Epic’s Unreal house. Official [Why EA](https://www.ea.com/careers/why-ea): **create next-level entertainment experiences that inspire players and fans**. Recruiter confirms **studio and craft** (gameplay / engine / live / platform), C++ vs C# vs backend, and any **test before the Zoom day**.

Typical reported path **~3–5 weeks** (2026 guides). Take-homes: [../general/take-homes.md](../general/take-homes.md). CS: [../general/cs-fundamentals.md](../general/cs-fundamentals.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (Purpose & Beliefs)

Do **not** invent extra pillars. Official January 2026 [Global Code of Conduct](https://s204.q4cdn.com/701424631/files/doc_downloads/gov_doc/EA-Code-of-Conduct_IR_January-2026.pdf) publishes **six beliefs**. Official Why EA frames the same idea as **Play Big / Play with Passion / Play Together**.

| Official belief | Code one-liner |
| --- | --- |
| **Creativity** | Imagination and original ideas in the work |
| **Pioneering** | Curiosity and courage to experiment and lead |
| **Passion** | Pursue what you love; have fun doing it |
| **Determination** | Focus, drive, conviction; excellence on the journey |
| **Learning** | Humility, new thinking, inclusion lens; grow the company |
| **Teamwork** | Accountability and integrity as a diverse team |

“Why EA?” that only says “I play FIFA / Apex” fails. Official recruiter write-up: you do **not** need to be an avid gamer — name a **live-ops, engine-perf, or player-community** problem you have lived, and pick **one** studio. Applying to every req is a weak signal.

## Official process

Official [Interviewing with Electronic Arts](https://www.ea.com/careers/interviewing-with-ea): apply → recruiter call (background, role, team) → **hiring-manager** call (you should ask questions) → talent coordinator books **Zoom** interviews → recruiter tells you about any **technical test, case study, or whiteboard** (sometimes **before** the loop) → feedback. Official tips: no dress code (most people business casual); you meet **several teammates in one day**. Early-career FAQ: first reply often **2–4 weeks**.

Official does **not** publish a SWE puzzle list. 2026 guides (TechPrep, Dataford) + candidate reports — treat stage *contents* as **reported**.

| Stage | Official / reported |
| --- | --- |
| Recruiter | Official first call. Guides: ~15–30 min; studio, why this title |
| Hiring manager | Official second call; role fit / career goals |
| Assessment | Official: recruiter names it. Guides: HackerRank **or** C++ / SQL timed paper **or** a short take-home |
| Zoom day | Official: several teammates. Guides: 2–3 × 45–60 — live coding, C++ / systems, design, beliefs |
| Decision | Official: recruiter owns next steps; timelines vary |

## How this track differs

| vs Riot / Epic | vs FAANG |
| --- | --- |
| Official **HM-before-loop** + optional pre-loop test | Design is **live game / sports / engine**, not a feed |
| Six beliefs; studio identity is the “why” | Engine hours probe **C++ memory / frame budget** |
| “Come as you are” is official | “I only grind hards” misses player / craft stories |

## Coding and design flavor

Gameplay / engine: C++ lifetimes, virtual dispatch, allocators, threads, cache. Live / platform: services, events, presence. Design: matchmaking, inventory, anti-cheat, live events. Related: [../roles/embedded.md](../roles/embedded.md) (constraint reasoning), [../answers/system-design-chat.md](../answers/system-design-chat.md).

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** studio (Sports vs Respawn vs BioWare vs central tech) — portable “I like games” is weak.
2. Recruiter / HM: a shipped system you would still defend; what you would change for players.
3. Live / OA: medium DSA **or** a game-state / event system; name the invariant.
4. Engine: what happens when you call a virtual on a base pointer; why fragmentation hurts a long session.
5. Belief: Learning — a time you changed the design after player or teammate signal.
