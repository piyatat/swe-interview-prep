# GE Aerospace engineering track

Sits beside [honeywell.md](honeywell.md) and [lockheed-martin.md](lockheed-martin.md): **commercial + defense engines** (independent public company since 2024), **not** GE Vernova (energy) and **not** Honeywell Aerospace (HONA). Official [Culture](https://careers.geaerospace.com/global/en/culture): purpose is **We invent the future of flight, lift people up, and bring them home safely**. Recruiter confirms **commercial engines vs defense vs digital / Predix-era analytics vs embedded FADEC**, C / C++ vs Java, site, and **AI-off live**.

Typical timeline **~3–5 weeks** (Dataford / PracHub). Embedded: [../roles/embedded.md](../roles/embedded.md). OA: [../general/online-assessments.md](../general/online-assessments.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (FLIGHT DECK)

Do **not** invent Amazon LPs. Official culture + [FLIGHT DECK](https://careers.geaerospace.com/global/en/flight-deck): lean operating model; **safety, quality, delivery, cost — always in that order**. Three foundational behaviors. Map **your** stories.

| Official language | What they score |
| --- | --- |
| **Respect for people** | You improved a process *with* the people who run it |
| **Continuous improvement** | A small, measured change — not a rewrite manifesto |
| **Customer driven** | Airline / airframer / warfighter eyes, not a demo |
| **Passionate Innovators** | Considered risk; experiment to learn |
| **Accountable Owners** | You treated the outcome as yours |
| **Collaborative Problem Solvers** | One team across shop floor and software |
| **Developers of World-class Talent** | Feedback you sought or gave |

Official [Tips for applying](https://careers.geaerospace.com/global/en/tips-for-applying): hiring buckets are **Get to Know Us / Talk With Us / Join Us**; answers use **STAR**.

“Why GE Aerospace?” that only says “GE / jet engines / I like AI” fails. Name a **FADEC / engine-control / shop-floor / fleet-data** problem. Do **not** reuse GE Vernova or pre-2024 “GE conglomerate” stories as if they were this company.

## Official + reported process

Official how-to-apply is high-level (research → apply → Candidate Home → recruiter email). Dataford / PracHub / Glassdoor fill SWE detail — treat extra OA / HireVue / panel **count** as **reported**. **Ask** HireVue vs live.

| Stage | Official / reported |
| --- | --- |
| Apply | [Careers](https://careers.geaerospace.com/) / Workday |
| Screen (reported) | Recruiter; campus / UK placement often **HireVue** then tests |
| Technicals (reported) | Resume deep-dive, OOP (virtual / inheritance), C / C++ or Java; some loops HackerRank |
| Panel / HM | FLIGHT DECK behaviors, project, site |

**Official AI policy:** [AI Interview Policy](https://careers.geaerospace.com/global/en/ai-interview-policy) — **no** AI-generated answers, real-time assistance, or automated decision-making in interviews; unauthorized use **may disqualify**. Accessibility / accommodation is the named exception. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md).

JDs for engine-control leads name **DO-178C** / military qualification — only prep that if the req says so.

## How this track differs

| vs Honeywell Technologies / Siemens | vs Lockheed / FAANG |
| --- | --- |
| Official **FLIGHT DECK + AI-off**; engines, not BMS / OT | Often **OOP + resume**, not five Blind-75 hours |
| Independent ticker after the 2024 GE split — **not** GE Vernova | DO-178C shows up on **control** JDs, not every digital role |
| “Why GEA?” must name **flight / SQDC**, not “I like manufacturing” | Comp is public-company RSUs + bonus, not HONA |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** GE Aerospace product line — Customer driven on a safety or delivery miss.
2. OOP: polymorphism / `virtual` / encapsulation; then a medium array if there is an OA.
3. Design: stream engine sensor data without losing a red-line alarm.
4. When you would **reject** a Copilot patch in DO-178-adjacent code (AI-off is official).
5. Questions: commercial vs defense vs digital, HireVue vs skip, site, clearance.
