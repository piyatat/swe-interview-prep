# Boston Scientific engineering track

Sits beside [medtronic.md](medtronic.md), [abbott.md](abbott.md), and [johnson-johnson.md](johnson-johnson.md): **minimally invasive device software** (NYSE: BSX) — cardiology, electrophysiology, endoscopy, neuromodulation, urology — **not** a diversified J&J Credo loop and **not** a lab-instrument Thermo Fisher loop. Official [About](https://www.bostonscientific.com/en-US/about-us.html): **advance science for life**; ~**59k** employees, ~**48M** patients/year, **$20B** net sales (2025 figures on that page). Recruiter confirms **implantable / programmer vs digital health vs manufacturing test**, C++ / C# vs Java / cloud, site, and live AI.

Typical timeline **~3–6 weeks** (Dataford / Glassdoor 2026; treat extra panel / plant-tour counts as **reported**). Embedded: [../roles/embedded.md](../roles/embedded.md). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (mission + values)

Do **not** invent Amazon LPs. Official [2025 Code of Conduct](https://www.bostonscientific.com/content/dam/bostonscientific/corporate/citizenship/compliance-ethics/2025_CodeofConduct_English.pdf) lists the culture values. Map **your** stories. Patient safety beats “we shipped Friday.”

| Official line | What they publish |
| --- | --- |
| **Transforming lives** | Mission — innovative medical solutions, worldwide |
| **Caring** | Integrity and compassion for patients, customers, each other |
| **Meaningful Innovation** | Ideas → breakthrough, sustainable solutions |
| **High Performance** | Deliver what matters; learn and coach |
| **Winning Spirit** | Speed, agility, accountability — dare to try |
| **Global Collaboration** | Common purpose; assume positive intent |
| **Diversity** | Unique ideas and experiences; include others |

Official student [interviewing tips](https://www.bostonscientific.com/content/dam/bostonscientific/corporate/careers/interviewing-tips.pdf): research the company, speak to **every** resume line, STAR dry-run, 30–60s pitch, questions for **each** interviewer, thank-you in 24h. [Working here](https://www.bostonscientific.com/en-US/careers/working-here.html): healthcare is a **calling**; belonging on mutual respect.

“Why Boston Scientific?” that only says “medtech / Marlborough / implants” fails. Name a **cardiac, endoscopy, neuromod, or quality** problem you have lived. Do **not** reuse a Medtronic Mission tenet as if it were this company.

## Official + reported process

**Official** pages do not publish a SWE slate. Careers: join the talent network or apply. Interviewing tips are STAR + authenticity. Accommodations: `GlobalTalentAcq@bsci.com` (that mailbox is for accommodations **only**).

**SWE (Dataford / Glassdoor 2026, treat as reported):** HR / talent screen → hiring manager → team **panel with live coding** in your language → behavioral + offer review. Some campus loops are a single-day site visit. Fundamentals (OOP, stack vs heap, C++ ownership) beat puzzle DP. IEC 62304 language helps on device teams; it is **not** required on every IT req. **Ask**.

| Stage | Official / reported |
| --- | --- |
| Apply | [bostonscientific.com/careers](https://www.bostonscientific.com/en-US/careers.html) |
| Screen | Reported HR / talent (~fit, “why BSC”) |
| Technical | Reported live coding + OOP / memory |
| Loop | Reported panel; some plant / lab tours |
| Offer | Recruiter; site days are live |

Live AI: **ask**. Implantable / programmer software is a reason many teams keep the pad AI-off. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md).

## How this track differs

| vs Medtronic / J&J | vs FAANG |
| --- | --- |
| **BSX values + implants / EP**, not Credo order or six Mission tenets | Medium DSA optional; **memory / quality / FMEA** stories are first-class |
| Cardiology / endoscopy / neuromod are the product, not a hospital IT shop | Design is **closed-loop, programmer, or telemetry**, not a feed |
| Comp is medtech bands; MA / MN / CA / Galway sites | Speed without a verification story reads as a miss |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** BSX franchise — Caring vs Winning Spirit when a date and a quality hold collided.
2. Official tips: 30–60s pitch + a question for **this** interviewer.
3. OOP / pointers / two-pointers if firmware; Java + SQL if digital.
4. Design: device programmer or telemetry with checksums, hold-and-release, and audit trail.
5. Questions: implantable vs digital vs mfg test, live AI, IEC 62304 vs skip, onsite days.
