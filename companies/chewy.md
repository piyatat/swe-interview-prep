# Chewy engineering track

Sits beside [wayfair.md](wayfair.md) and [instacart.md](instacart.md): **pet e-commerce + autoship (Plantation / Boston / …)**, not a home-goods catalog panel and not a grocery shopper-dispatch loop. Official [mission](https://careers.chewy.com/us/en/operating-principles): **most trusted and convenient destination for pet parents and partners, everywhere**. Official [Interviewing at Chewy](https://careers.chewy.com/us/en/interviewing-at-chewy): recruiter is the source of truth for **count, format, virtual vs onsite**. Recruiter confirms **retail / fulfillment / customer-care / platform**, hub, language, and AI.

Typical reported path **~2–4 weeks** (2026 guides; official says “speed and intention”). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). Debug: [../general/debugging-rounds.md](../general/debugging-rounds.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (seven Operating Principles)

Do **not** invent Amazon LPs. Official [Operating Principles](https://careers.chewy.com/us/en/operating-principles) are the hire bar. Official interviewing page: map **your** stories in **STAR**.

| Official OP | Careers one-liner |
| --- | --- |
| **Put Customers First** | Anticipate needs; everyday moments → loyalty |
| **Act as an Owner** | Chewy’s interest; initiative; accountable for results |
| **Deliver Results** | Focus + urgency; stay ahead of risks |
| **Earn Trust** | Built in the open; backbone of relationships |
| **Debate Openly; Commit Fully** | Rigorous debate, then execute regardless of where you started |
| **Operate in the Details** | Master details **and** context |
| **Shape the Future** | Question what is; bold, calculated risk |

“Why Chewy?” that only says “I have a dog / e-comm / Florida” fails. Name an **autoship, fulfillment, or pet-parent care** problem you have lived.

## Official process

Official [Interviewing at Chewy](https://careers.chewy.com/us/en/interviewing-at-chewy): apply → auto confirm → recruiter reviews → they contact matches. **Do not reapply to the same req** after a no. Most roles are **on-site or hybrid**; remote only if the title or JD says so. Visa sponsorship is **select roles**. Some loops add a **case, assessment, or portfolio**. Virtual dress: business casual. Accommodations: CAAR@Chewy.com.

Official does **not** publish a SWE round list. 2026 guides (TechPrep, InterviewLegend) + candidate reports — treat stage *contents* as **reported**.

| Stage | Official / reported |
| --- | --- |
| Recruiter | Official next-step call. Guides: ~25–35 min; role, stack, why Chewy, band |
| Early technical | Official: optional assessment. Guides: timed **HackerRank** (~2 DSA, 50–90 min) **or** a live engineer screen |
| Final loop | Official: count varies. Guides: often **four × ~60** — coding, design, **debug / refactor**, behavioral / HM |
| Decision | Official: recruiter owns timing |

## How this track differs

| vs Wayfair / Instacart | vs FAANG |
| --- | --- |
| Official **seven OPs + STAR** named on the careers site | Pet autoship + FC, not a generic marketplace |
| Guides: a dedicated **debug / test** hour is common | “I only grind hards silently” misses OPs |
| Office / hybrid default unless the req says Remote | Recruiter walks **your** format — do not assume four hours |

## Coding and design flavor

Guides: easy–medium arrays / strings / trees; Java / Spring is a common stack color (Python / JS accepted). Design: autoship, catalog, warehouse pick/pack, customer-care tooling, inventory that is **partly wrong**. Related: [../answers/system-design-job-scheduler.md](../answers/system-design-job-scheduler.md), [../answers/system-design-search.md](../answers/system-design-search.md). Debug hour: fix broken code **and** add tests — [../general/debugging-rounds.md](../general/debugging-rounds.md).

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** Chewy surface (autoship, FC, care) — portable “I like pets” is weak.
2. OA / screen: two working mediums beat one clever unfinished hard.
3. Design: reorder a SKU when the FC is short and the pet parent expects autoship tomorrow.
4. Debug: reproduce, fix, write the test that would have caught it.
5. STAR vs **Debate Openly; Commit Fully** or **Operate in the Details**.
