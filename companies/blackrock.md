# BlackRock engineering track

Sits beside [goldman.md](goldman.md) and [jpmorgan.md](jpmorgan.md): **asset-manager + Aladdin platform (fiduciary tech)**, not a Superday investment-bank loop. Official purpose ([students & graduates](https://careers.blackrock.com/students-and-graduates)): **help more and more people experience financial well-being**. Recruiter confirms **campus vs experienced**, **Aladdin vs other platform**, location (4-day hybrid on current JDs), and whether the first gate is the **coding + video** pack.

Typical reported path **~3–6 weeks** (2026 guides). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). SQL: [../general/sql-interviews.md](../general/sql-interviews.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (five Principles)

Do **not** invent extra pillars. Official careers pages hire against the **BlackRock Principles**. Map **your** stories.

| Official principle | Careers one-liner |
| --- | --- |
| **Fiduciary to our clients** | Client interest first; unbiased advice; bedrock identity |
| **One BlackRock** | No silos / turf; Aladdin as a common language |
| **Passionate about performance** | Relentless better ways; lifelong students of markets and tech |
| **Emotional ownership** | Responsibility to clients **and** colleagues; high standards |
| **Committed to a better future** | Long-term; run the firm sustainably |

“Why BlackRock?” that only says “largest AUM / finance pays” fails. Name a **correctness, audit, or risk-number** problem you have lived.

Official JD **Guidance on AI**: use AI to **learn and prepare**; during the interview they want **your** experience, thinking, and judgment. Current JDs: hybrid **≥4 days in office** (some groups more).

## Official process (campus is published)

Official [How we hire](https://careers.blackrock.com/students-and-graduates) + [EMEA candidate FAQs](https://careers.blackrock.com/en/candidate-faqs-emea) (2026 cycle):

| Stage | Official |
| --- | --- |
| Apply | Resume / CV. Rolling; earlier is better. Apps open summer 2026 for that campus year |
| Pre-interview video | After apply: ~**3 min** prep + **≤90 s** answer per prompt; whole pack **<10 min**, **one sitting**, **five days**. Incomplete = withdrawn. **No retake**. Miss deadline → cannot reapply to the **same** req |
| Coding test (SWE + Analytics & Modelling) | Series of coding questions (~**60 min**) + **one video** question. Five calendar days for the coding portion; video is one sitting. One pack **per function** if you apply to several |
| Interviews | Principles + experience / capabilities. May include group exercise, presentation, or case. SWE: **problem-solving or technical questions** |

Experienced-hire **round list is not official**. 2026 guides (TechPrep, techinterview.org) — treat as **reported**: recruiter, HackerRank / live coding (+ sometimes a video explanation), 1–2 technical screens, then a virtual Superday (coding, practical design, Principles).

## How this track differs

| vs Goldman / JPMC | vs FAANG |
| --- | --- |
| Official **campus OA + video are hard gates** | Design is **positions / risk / Aladdin**, not a social feed |
| Five Principles; fiduciary is a veto | Guides: correctness and messy input over olympiad graphs |
| 4-day hybrid is on the JD | “I only grind hards” misses SQL + ownership stories |

## Coding and design flavor

Campus OA: finish clean mediums; you may have to **narrate on video**. Experienced guides: easy–medium DSA, SQL windows / joins, Java or C++ LLD, ingest / reconcile / EOD positions. Related: [../answers/system-design-payment.md](../answers/system-design-payment.md), [../answers/system-design-metrics.md](../answers/system-design-metrics.md).

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** platform (Aladdin vs another book) — portable “I like fintech” is weak.
2. Video: a time you put the client / user outcome over your team’s convenience (fiduciary / ownership).
3. Coding: group / reconcile messy IDs; tests on duplicates and late arrivals.
4. Design: intraday trades → auditable EOD positions; how a missed print is repaired next morning.
5. One BlackRock: a time you crossed a silo instead of throwing the ticket.
