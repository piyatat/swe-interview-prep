# Veeva engineering track

Sits beside [salesforce.md](salesforce.md) and [epic-systems.md](epic-systems.md): **life-sciences industry cloud** (Vault, CRM, clinical / regulatory / safety), not a generic CRM loop and not an EHR generalist hour. Official [Why Veeva](https://careers.veeva.com/why-veeva/): help life sciences **innovate, run efficiently, get to market faster**. Recruiter confirms **Vault vs CRM vs Platform vs new product**, Java vs Python, **Work Anywhere hub**, sponsorship, and **AI-in-pad**.

Typical path (official on current JDs): apply → third-party personality assessment → hiring-manager conversation → technical / coding exercise → final panel. Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (core values)

Do **not** invent Amazon LPs. Official [Why Veeva](https://careers.veeva.com/why-veeva/). Map **your** stories.

| Official value | Careers one-liner |
| --- | --- |
| **Do the Right Thing** | Honesty, decency; customers, industry, employees, and shareholders in the decision |
| **Customer Success** | Individuals enjoy the product; company sees ROI; the **industry** gets more efficient |
| **Employee Success** | “Captain their own ship”; respect + support to do the best work |
| **Speed** | Important things **today**; retain startup speed as the company grows |

Official differentiators on the same page: first public company to convert to a **Public Benefit Corporation** (2021); **Work Anywhere** (office or home **any given day**, with **core hours** — not “work any time”); **no employee non-competes**; 1% salary **Veeva Giving** (employee-chosen nonprofits). Product teams live **within a time zone of a hub** (Pleasanton, Columbus, Boston, Kansas City, NYC, Raleigh, Toronto).

“Why Veeva?” that only says “healthcare SaaS / remote” fails. Name a **regulated workflow, audit trail, or clinical-document** problem you have lived. JDs: high work ethic; engineering is **code and communication**.

## Official process

Senior JD (Lever, current): transparent stages. Campus / associate JDs publish a **compressed** variant — **ask**.

| Stage | Official (experienced JD) |
| --- | --- |
| Apply | Resume |
| Personality assessment | Link within **3 days** (third party; skip if you already took it) |
| Decision on package | Email after they review assessment + resume |
| If advancing | (1) hiring manager (2) technical / coding exercise (3) **final panel** with teammates + senior leaders |
| Close | Manager sends the decision |

Associate / new-grad JDs: personality test → notify within a week → **1-hour** Java or Python coding challenge → **single 2-hour** interview (coding in Java, JavaScript, or Python) → offer or no within a week; **one week to accept**; accepting while still interviewing elsewhere is an **ethical violation** in their view; team assignment **after** join.

Reports (Dataford 2026): ~3–5 weeks; some loops add a Java OA and a virtual “Team Day.” Treat extra OA / Team Day as **reported**. Pair / OA: [../general/online-assessments.md](../general/online-assessments.md), [../general/low-level-design.md](../general/low-level-design.md).

## How this track differs

| vs Salesforce / generic SaaS | vs Epic Systems |
| --- | --- |
| **Industry cloud** for pharma / biotech / devices, not a horizontal CRM | Cloud multi-tenant + **compliance**, not Verona / on-prem EHR |
| Official PBC + **no non-competes** | Personality assessment is a **named** first gate |
| Work Anywhere + hub time zone | New-grad: one long interview after OA, not a Superday slate |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** life-sciences cloud — a GxP, audit, or trial-document constraint, not “I like healthcare.”
2. Java collections / streams / a concurrency bug in a snippet; narrate the fix.
3. Practical coding: merge sorted files under a memory cap; parse nested expr; valid parentheses — [../answers/coding-valid-parentheses.md](../answers/coding-valid-parentheses.md).
4. SQL join + index story — [../general/sql-interviews.md](../general/sql-interviews.md).
5. Values: Speed without skipping Do the Right Thing (a ship/no-ship call).
