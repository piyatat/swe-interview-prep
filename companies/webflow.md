# Webflow engineering track

Sits beside [figma.md](figma.md) and [canva.md](canva.md): **visual web canvas + hosted CMS**, not a design-file editor and not a template marketplace. Official [Careers](https://webflow.com/company/careers): “bring development superpowers to everyone”; **Remote Together** (remote-first, no RTO mandate). Recruiter confirms **frontend / platform / infra / AI**, pay zone (US A/B/C), and whether your coding hour is **Codeflow**.

Typical timeline **~3–5 weeks** (guides; confirm). AI policy: [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md). Practical repo: [../general/debugging-rounds.md](../general/debugging-rounds.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official hire bar (do not invent extra pillars)

Official [Careers](https://webflow.com/company/careers) lists **four** core behaviors. Map **your** stories. Official [About](https://webflow.com/company/about) names the same first three; its fourth line is **Deliver with speed, quality, and craft** — ask which wording your loop uses.

| Official behavior | What they score |
| --- | --- |
| **Build lasting customer trust** | Customer-trust first; you changed a ship date rather than ship a lie |
| **Win together** | Team win, not a solo hero story |
| **Reinvent ourselves** | Imagined a new path, not a 2% polish |
| **Own it all the way** | Speed **and** accountable outcomes |

Official [AI hiring principles](https://webflow.com/company/careers/ai-hiring-principles): **every hiring decision is made by a human**. Use AI to refine a real resume, prep, and (when invited) take-homes. **Do not** fabricate experience, bulk-submit, ghostwrite live answers, or run your own recorder — **BrightHire only**. Codeflow is the exception they name: AI is **allowed so they can score how you use it**.

“Why Webflow?” that only says “no-code / I like AI” fails. Name a **visual editor, CMS, or hosted-site** problem you have lived.

## Official + reported process

Official current signal is [Codeflow](https://webflow.com/blog/codeflow-interviews) (open-sourced April 2026): clone a React shell, drop a zip into `src/interviews/`, work in **your** IDE with screen share. Exercises start from an existing multi-file app (rough edges on purpose). They score fundamentals, product/UX, and “how this scales or breaks” — not a blank-slate puzzle.

| Stage | Official / reported |
| --- | --- |
| Recruiter | Role, remote vs geo-tied, pay zone; ask AI + Codeflow vs older loop |
| Practical screen | Official: **Codeflow** (AI on, visible). Older 2024 playbook: Byteboard project — **ask**; do not assume both |
| HM / project | Guides: one project walkthrough — challenges, diagnosis, what you learned |
| Loop | Guides: second practical / design + **Core Behaviors**. Senior: clarify before coding; name risks the prompt hides |

Vague prompts, paste-without-read, or “I cannot explain the diff” fail the official AI bar immediately.

## How this track differs

| vs Canva / Figma | vs FAANG web |
| --- | --- |
| Official **Codeflow** + published **AI hiring rules** | Design is **canvas / CMS / publish**, not a feed |
| Remote-first; pay **zones** | “I only grind LeetCode” is the wrong sport |
| AI as collaborator **on screen** | Silent overlay tools are an official fail |

## Coding and design flavor

Official product: visual builder, CMS, hosting, localization, AI in the product. Live work: render performance, component state, publish/rollback, multi-tenant sites. Related: [../answers/system-design-collab-editor.md](../answers/system-design-collab-editor.md), [../general/pair-programming.md](../general/pair-programming.md).

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** visual-development platform — portable “design tool” is weak.
2. Codeflow-style: fix a re-render storm, then add a feature without breaking existing state.
3. Design: publish a site to a global CDN — preview vs live, rollback, custom domains.
4. Behavior: Own it all the way — you kept a customer-trust outcome after a bad week.
5. Questions for them: Codeflow vs Byteboard, when AI is invited, pay zone.
