# Bosch engineering track

Sits beside [nxp.md](nxp.md) and [siemens.md](siemens.md): **Mobility + industrial + consumer + energy software** (ECU / SDV, factory, appliances, building) — not an MCU-vendor silicon hour and not a FAANG feed design. Official [FAQ](https://www.bosch.com/careers/faq/): four sectors **Mobility, Industrial Technology, Consumer Goods, Energy and Building**. Recruiter confirms **Mobility vs Industrial vs consumer vs energy**, C / AUTOSAR vs Java / cloud, country language, and **coding task vs skip**.

Typical timeline **2–6 weeks** (official FAQ); Dataford ~3–5. Embedded: [../roles/embedded.md](../roles/embedded.md). OA: [../general/online-assessments.md](../general/online-assessments.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

US software careers: Work **#LikeABosch** (Grow / Enjoy / Inspire); software treated as **primary IP**, not an afterthought on a manufacturing floor.

## Official culture (no Amazon LPs)

Do **not** invent LPs. Official FAQ culture line: **trust, ownership, collaboration**; actions guided by **openness, respect, fairness, diversity, sustainability**. Map **your** stories.

| Official language | What they score |
| --- | --- |
| **Trust / ownership** | You took a decision in the product’s interest |
| **Collaboration** | Hardware + firmware + QA in the same argument |
| **Openness / respect / fairness** | Disagreement without politics |
| **Diversity / sustainability** | A perspective or energy/safety constraint you used |
| **Grow / Enjoy / Inspire** | Learning + craft, not “I grinded LeetCode” |

“Why Bosch?” that only says “cars / German engineering / I like IoT” fails. Name a **CAN / FOTA / HIL, plant, or appliance** problem you have lived. US SWE quotes: ECU integration at a customer site; hand-code vs model-based; software-with vs without an OS.

## Official + reported process

Official FAQ is **four** steps. Dataford fills SWE detail — treat extra OA / assessment-center steps as **reported**. **Ask** coding task vs live.

| Stage | Official / reported |
| --- | --- |
| Apply | [jobs.bosch.com](https://jobs.bosch.com/) via SmartRecruiters; CV required; cover letter recommended |
| Screening | Feedback often **1–3 weeks** |
| Interviews | One or more, **video or onsite**; some roles add assessments / case studies / presentations |
| Close | Overall **2–6 weeks** by country / role |

**Official AI in recruiting (FAQ):** in some countries, AI reads **work experience and education you entered** (or parsed from the CV) to flag skill fit. It is a **preliminary indication**; **recruiters and hiring managers decide**. Data is **not** used to train the model. That is **ATS assist**, not “use Copilot in the pad” — **ask** live-AI rules separately. Pair: [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md).

**Scam line (official):** applications only through **SmartRecruiters**; recruiters use **Bosch email**. Bosch **never** asks candidates to pay fees, transfer money, or buy equipment.

## How this track differs

| vs NXP / Infineon | vs Siemens / FAANG |
| --- | --- |
| Product is **Bosch module in a vehicle / plant / home**, not a catalog MCU | Official **4-step hire + AI-in-ATS** named on FAQ |
| Mobility still **C / AUTOSAR / HIL**; industrial / energy may be Java / OT | Design is **ECU / FOTA / plant**, not a social feed |
| Confirm **which of the four sectors** | Coding may be **assessment or case**, not only Blind-75 |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** Bosch sector — ownership on a safety or quality miss.
2. OOP + threads in Java/C++; mutex vs deadlock; heap vs stack on a microcontroller.
3. CAN / UDS / FOTA **or** SIL vs HIL — only if the JD is Mobility embedded.
4. Design: roll firmware to a fleet of ECUs without bricking a customer line.
5. Questions: sector, language, coding task vs skip, live AI, visa / hybrid (official FAQ).
