# Broadcom engineering track

Sits beside [qualcomm.md](qualcomm.md) and [cisco.md](cisco.md): **semiconductor plus infrastructure software under one ticker** — not a phone-modem house and not a pure networking OEM. Official [careers](https://www.broadcom.com/company/careers): semiconductor and infrastructure software that **connects everything** (mobile/home, cloud, AI, security). Recruiter **must** name the **division**: custom/networking silicon vs **VMware by Broadcom** vs Symantec/CA/Brocade enterprise software. Loops, culture, and comp **diverge**.

Typical path (reported): recruiter / hiring-manager screen → technical phone or OA → virtual or onsite loop. Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md). Official culture page: equity awards **target the top tier of the market**; bonus targets competitive with base + core benefits.

## Official culture

Do **not** invent Amazon LPs. Broadcom’s [culture](https://www.broadcom.com/company/careers/culture) page does **not** publish a numbered value list. Official language to map stories to:

| Official theme | Where it is published |
| --- | --- |
| **R&D + efficient operating model** | Careers / culture: invest in R&D; productive, focused environment |
| **Execution / clarity of ownership** | Engineering spotlight: “this is your lane, these are your metrics” |
| **Innovation that ships** | Same: innovation is tied to the business, not a hobby side project |
| **Engineers first** | Same: engineers treated as the most important employees; small teams |
| **Customer value over generations** | CEO/product essays: co-create; R&D for the next product cycle |

“Why Broadcom?” that only says “AVGO / VMware” fails. Name a **hypervisor, ASIC, SerDes, or enterprise-security** problem you have lived — and **which portfolio** you are joining. Post-2023 VMware is **Broadcom’s** VMware: cost-disciplined, large-customer roadmap. Confirm on-site vs remote; official engineering write-up treats **in-office serendipity** as a feature, not a footnote.

## Process (official + reported)

No public “How we hire” checklist like NXP. [Hiring policies](https://www.broadcom.com/company/legal/hiring-policies) cover EEO, E-Verify, and **application accommodations** — not round count.

| Stage | What to expect |
| --- | --- |
| Apply | [Careers](https://www.broadcom.com/company/careers) / Broadcom career site |
| Recruiter | Division, level, location, comp — **wrong portfolio = wrong loop** |
| HM (reported) | Domain depth; two or three projects with constraints and outcomes |
| Technical (reported) | 45–90 min coding/design **or** HackerRank; C/C++ / OS for silicon; practical over puzzles |
| Loop (reported) | **3–6** sessions, 45–60 min; software: coding + design + domain; hardware: RTL / verification / architecture |
| Close (reported) | Packet / committee on some teams; treat **count and HC** as reported |

Reports (Dataford + techinterview 2026): ~2–8 weeks; VMware track often **faster** than semiconductor. Pair: [../roles/embedded.md](../roles/embedded.md), [../general/system-design.md](../general/system-design.md), [../general/behavioral.md](../general/behavioral.md).

## How this track differs

| vs Qualcomm wireless / Snapdragon | vs Cisco networking / People Deal |
| --- | --- |
| **Two companies in one**: custom silicon **and** VMware / Symantec software | Infrastructure software here is **VMware / CA / Symantec**, not IOS-XE |
| No published LP list — execution + ship-to-customer | Ask silicon vs VMware **before** you prep DSA vs RTL |
| Practical systems / domain depth over brain-teasers | Post-acquisition VMware is not 2022 VMware culture |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** division — a NIC, hypervisor, or enterprise-security constraint, not “I want AVGO stock.”
2. C / OS: user vs kernel allocators; producer–consumer with mutex + condvar — [../roles/embedded.md](../roles/embedded.md).
3. Design a rate limiter or a multi-thread scheduler — [../answers/system-design-rate-limiter.md](../answers/system-design-rate-limiter.md).
4. Culture: a time you owned a metric end-to-end (execution) or killed a side project that would not ship.
5. Questions: silicon vs VMware vs Symantec, on-site policy, OA vs live, AI-in-pad.
