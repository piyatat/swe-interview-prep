# AT&T engineering track

Sits beside [verizon.md](verizon.md) and [cisco.md](cisco.md): **carrier-scale software** (customer platforms, 5G / fiber ops, TDP early-career) — not “Verizon with a different logo.” Official Code of Business Conduct (effective 2026-09-01) names five **culture pillars**. Recruiter confirms **Technology vs Network vs cyber / Labs**, Java vs Python / JS, Dallas / Atlanta / Middletown / Bothell, campus **TDP vs experienced**, and live AI.

Typical timeline **~3–8 weeks** (TechPrep; official campus copy says **4–6 weeks** for some programs). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). SQL: [../general/sql-interviews.md](../general/sql-interviews.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (five pillars)

Do **not** invent extra LPs. Official [Human Capital Management](https://sustainability.att.com/priority-topics/human-capital-management) + [Code of Business Conduct](https://about.att.com/content/dam/pages/ethics/COBC.pdf): the Integrated Leader Model is how they say they hire and promote. Map **your** stories.

| Official pillar | What they publish |
| --- | --- |
| **Serve Customers First** | Real customer needs and market data, not internal convenience |
| **Move Faster** | Simplify; stay on strategy; deliver quickly |
| **Act Boldly** | Own the call; speak up; learn from a miss |
| **Win as One** | Enterprise over silo; open communication |
| **Develop Talent** | High bar, honest feedback, lead from where you are |

Integrity / speak-up / respect sit **beside** the pillars in the Code. “Why AT&T?” that only says “telecom / 5G” fails. Name a **reliability, customer-journey, or network-adjacent** problem. Official SWE TDP copy: you will use **modern practices and AI-assisted tools** on the job — that is **not** a free pass to use Copilot in the OA. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md).

## Official + reported process

**US early-career / internship** (official [Technology programs](https://www.att.jobs/technology-programs-and-internships)): apply → **virtual assessment & on-demand interview** (async) → **technical assessment** → **business-unit interview(s)** → offer. Check email **and spam**. STEM degree rules and mid-July / 10-week intern calendars are on that page. Sites: Dallas, Atlanta, Middletown (NJ), Bothell (WA); Network track is Dallas / Atlanta.

**Israel TDP** ([il.att.com/tdp](https://il.att.com/tdp/)) is a **different** funnel (timed HackerRank, homework, in-person). Do not quote it as the US loop.

**Experienced SWE** (TechPrep 2026, treat as reported): recruiter → HackerRank (2 easy–medium + SQL, sometimes debug) → live coding / OOP / REST → design or HM for mid+ → STAR closer on Teams.

| Stage | Official / reported |
| --- | --- |
| Apply | [att.jobs](https://www.att.jobs/) |
| Async assessment (campus) | Official on-demand interview + technical exercise |
| OA (guides / some geos) | HackerRank; SQL shows up more than at FAANG |
| Live | Coding + Java/React theory; STAR vs the five pillars |
| Offer | Official campus article: ask the decision date in the room |

Official [interview advice](https://life.att.jobs/job-interview-advice/): STAR on the resume, research the **program**, prepare questions. Official [applicant resources](https://www.att.jobs/applicant-resources) still lists “At Your Service” customer commitments — use pillars for 2026 behavioral mapping.

## How this track differs

| vs Verizon | vs FAANG |
| --- | --- |
| Five **named pillars**, not Culture OS Trust / Care / Excellence | Easy–medium + **SQL / OOP / REST**, not contest graphs |
| Official **TDP 5-step** for campus; experienced is team-owned | Design is **location, portals, network-adj.**, not a social feed |
| Comp is carrier bands; hubs are Dallas / Atlanta more than Bay | Async HireVue-class screen is a first-class campus gate |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** AT&T track — Serve Customers First when a release and a customer outage collided.
2. Reverse a list / valid parentheses / a JOIN + GROUP BY if there is an OA.
3. Design: alert fan-out or a tiny URL / location service without drowning on-call.
4. STAR: Win as One across wireless + a software org.
5. Questions: TDP vs experienced, HackerRank vs skip, live AI, site.
