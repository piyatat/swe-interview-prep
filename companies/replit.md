# Replit engineering track

Sits beside [vercel.md](vercel.md) and [github.md](github.md): **agentic software-creation platform (browser IDE + Agent)**, not a deploy/CDN loop or a git host. Official [Careers](https://replit.com/careers): mission is to help **one billion creators** turn ideas into working software; **50M+** people already use it. Recruiter confirms **Agent / editor vs runtime / infra vs growth**, TypeScript vs Go/Rust, and **Foster City MWF hybrid vs remote**.

Typical timeline **~2–4 weeks** (2026 guides). Pair / live build: [../general/pair-programming.md](../general/pair-programming.md). Take-homes: [../general/take-homes.md](../general/take-homes.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official hire bar (do not invent extra pillars)

Official [Operating Principles](https://replit.com/blog/operating-principles) (updated 2026-03-05) + [What We Look for When We Interview](https://replit.com/blog/get-hired). Map **your** stories.

| Official signal | What they score |
| --- | --- |
| **Mission first** (principles) | Why **creators / Agent**, not “I like AI coding tools” |
| **Think radical** (principles) | Contrarian bet you **shipped**, not a hot take in the room |
| **Work with intensity** (principles) | Single strong owner; bias to prototype + demo |
| **Seek pain** (principles) | Harsh metric / user no; you changed the plan, not the story |
| **Act like an owner** (get-hired) | Drive a real-world Replit-shaped problem; refuse to be blocked |
| **Present clearly** (get-hired) | Remote-first: written + verbal; you **listen** to feedback |
| **Point of view** (get-hired) | Opinion on the product, explained — not “whatever the team wants” |

“Why Replit?” that only says “Cursor / Copilot competitor” fails. Name a **sandbox, collab, Agent, or first-ship** problem you have lived. Official get-hired: they often ask you to **solve a true-to-Replit problem** as if you own the project.

## Official + reported process

Official [Interview Process](https://replit.com/interview-process): **no gotchas** — authentic challenges. Four published seats. Guides add pace; treat round *contents* as **reported**.

| Stage | Official / reported |
| --- | --- |
| Recruiter | Career journey + goals; they share mission and **operating principles** |
| Hiring manager | Deep dive on experience vs **this** role’s bar |
| Technical | Live **or** take-home, then review: walkthrough, coding challenge, or assignment |
| Panel | Teammates + partners: technical, problem-solving, behavioral |
| Offer | Confirm **Foster City MWF** vs remote; level and equity |

Guides (2026): some loops include **building in Replit itself**. Confirm AI-in-pad; do not assume a LeetCode-only hour.

## How this track differs

| vs Vercel / GitHub | vs FAANG web |
| --- | --- |
| Official **principles + owner-shaped** tech hour | Design is **Agent / collab / sandbox**, not “design Twitter” |

## Coding and design flavor

Practical TypeScript / Python / Go: parse, collab (OT / CRDT cousin), sandbox isolation, Agent tool-loop. Related: [../answers/system-design-collab-editor.md](../answers/system-design-collab-editor.md), [../general/low-level-design.md](../general/low-level-design.md). Bring a **live Replit / GitHub** you can walk.

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** creator platform — a time you unblocked a first-time builder, not “I use Agent.”
2. Principle: seek pain — a metric that killed your favorite design.
3. Live: own a small product slice (scope, tests, what you would cut).
4. Design: multiplayer REPL or Agent sandbox that cannot escape the box.
5. Questions for them: Agent vs editor vs infra, take-home vs live, HQ days.
