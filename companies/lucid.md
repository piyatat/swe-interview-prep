# Lucid Motors engineering track

Sits beside [tesla.md](tesla.md) and [rivian.md](rivian.md): **luxury EV + energy software** (Air / Gravity, in-house powertrain, 2025 Uber / Nuro robotaxi partner) — not a volume-Tesla loop and not an adventure-truck Compass hour. Official [Careers](https://lucidmotors.com/careers): *an electric future that is better for our communities and the planet*; refuse the false choice between performance and sustainability. Recruiter confirms **ADAS vs BMS vs infotainment vs data / AV infra**, C++ vs Python, Newark CA / Southfield MI / other hubs, and **in-person default**.

Typical timeline **~3–5 weeks** (Dataford). Embedded: [../roles/embedded.md](../roles/embedded.md). LLD: [../general/low-level-design.md](../general/low-level-design.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (six values)

Do **not** invent Amazon LPs. Official [Life at Lucid](https://lucidmotors.com/careers/life-at-lucid) lists **six** values. Map **your** stories.

| Official value | What they score |
| --- | --- |
| **One Team** | Hardware + software + manufacturing in the same argument |
| **Ownership Mindset** | You owned the outcome past your ticket |
| **Passion For Excellence** | A craft / quality bar you refused to ship under |
| **Breakthrough Innovation** | A design that was not a copy of the last OEM |
| **Act with Urgency** | You moved without being asked; named the risk |
| **Integrity in Action** | Safety / customer / community — not a slogan |

“Why Lucid?” that only says “Air has great range / nicer Tesla” fails. Name an **OTA, thermal, CAN, or HIL** problem you have lived. Data infra JDs: Python, AWS, Kubernetes, sensor / telemetry pipelines for AV development.

## Official + reported process

No public numbered SWE stage list on careers. Dataford (2026) + reports. Treat stages as **reported**. **Ask** presentation vs live code.

| Stage | Official / reported |
| --- | --- |
| Apply | [Careers](https://lucidmotors.com/careers) |
| Recruiter screen | Why Lucid, site / relocation, org, compensation |
| Technical screen | HM or senior: DSA **or** domain (C++ / Python, embedded, data) |
| Panel loop | Several technical + behavioral; often a **15–30 min** past-project presentation first |
| Close | HM / stakeholder; most engineering desks expect **regular on-site** (HIL / vehicle) |

Guides: first-principles over templated LeetCode; they drill **failure modes** (what happens when the sensor lies). Pair: [../general/behavioral.md](../general/behavioral.md), [../general/cs-fundamentals.md](../general/cs-fundamentals.md).

## How this track differs

| vs Tesla / Rivian | vs FAANG |
| --- | --- |
| Official **six values**; luxury + range craft, not FSD-only or adventure Compass | Design is **OTA / BMS / ADAS / cabin**, not “design Twitter” |
| Vertical integration: motor, pack, and software in one argument | Coding is **applied** (parse, concurrency, vehicle state) |
| 2025 **Uber / Nuro** robotaxi line on careers timeline | Confirm ADAS vs BMS vs cloud — the desks diverge |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** EV house — One Team + Integrity on a safety or thermal miss.
2. Live: medium DSA **or** a serial / CAN parse; working solution first.
3. Design: OTA when half the fleet is in a garage; canary + rollback.
4. LLD: charge / drive-state machine; illegal transitions named.
5. Questions: ADAS vs BMS vs data infra, site, AI-in-pad, presentation vs pad.
