# CACI engineering track

Sits beside [leidos.md](leidos.md) and [booz-allen.md](booz-allen.md): **national-security software** (enterprise to the edge) — not a FAANG feed and not “the same loop as every Beltway integrator.” Official [Our Culture](https://www.caci.com/our-culture): **Ever Vigilant**; character plus informed innovation. Careers [Life at CACI](https://careers.caci.com/life-at-caci): **27,000+** employees, **150+** offices, **74%** hold clearances, **40%** veterans; HQ **Reston, VA**. Recruiter confirms **program / customer**, Java vs C# / Python / networking, site vs hybrid, and **clearance / poly** (poly level is **not** on the public posting).

Typical timeline **~2–4 weeks** of active eval (Dataford; some guides ~4–6). Clearance can delay start. Behavioral: [../general/behavioral.md](../general/behavioral.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (Ever Vigilant)

Do **not** invent Amazon LPs. Official [Our Culture](https://www.caci.com/our-culture) + [Life at CACI](https://careers.caci.com/life-at-caci) (ethics, integrity, doing the right thing). Map **your** stories.

| Official line | What they publish |
| --- | --- |
| **Outcome mindset** | Keep the end goal front and center |
| **Intrinsic knowledge** | What works on this mission, not a generic stack recitation |
| **Purposeful acceleration** | High-value capability with flexibility |
| **Informed innovation** | Stay ahead of threats **with** mission insight |
| **Rapid responsiveness** | Urgency; software in the right place on time |
| **Enduring commitment** | Character; nation’s strategic interests |

“Why CACI?” that only says “defense / I want a clearance” fails. Name a **capability** from the [engineering careers](https://careers.caci.com/engineering) page (cyber, Agile apps, modernization / sustainment, EW / SIGINT, test) and an **Enduring commitment / Outcome mindset** story.

## Official + reported process

Official [Careers FAQ](https://careers.caci.com/faq) + [Interviewing at CACI](https://caci.phenompro.com/global/en/interviewing-at-caci): apply on the careers tenant → recruiter contacts matches → interviews mix **prescreen**, behavioral / interpersonal, and **in several cases technical**. Official: they want hands-on experience, workplace scenarios, complex-problem handling, and career goals. Official clearance FAQ: you **cannot** apply for a clearance yourself; some reqs allow CACI to sponsor before start; **polygraph level is not advertised** — recruiter discloses it if you qualify. Official: watch **recruitment fraud** (`@caci.com` / `@recruiting.caci.com` only; never pay fees).

| Stage | Official / reported |
| --- | --- |
| Apply | [searchcareers.caci.com](https://careers.caci.com/faq) |
| Recruiter | Fit, program, **clearance / poly**, salary |
| Panel (reported) | Often **one** HM + leads hour: resume, OOP / language, STAR |
| Coding | **Ask** — some teams add a short pad / take-home; many stay practical (palindrome, maps), not puzzle-hard |
| Offer + start | Background; clearance / poly can **delay start** |

[../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md): **ask** live-AI rules (not a published FAQ line).

## How this track differs

| vs Leidos / Booz Allen | vs FAANG |
| --- | --- |
| Official **Ever Vigilant** six lines; **74%** already cleared | Loop is **panel + resume**, not five DSA hours |
| Design is **mission app / network / EW**, not a social feed | Poly / program site is a **gate** on many reqs |
| “Why CACI?” must name **this contract class** | Comp is program bands — not public RSUs |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** CACI program — Outcome mindset when the end goal and the ticket queue disagreed.
2. OOP pillars + `==` vs `.equals` / overloading vs overriding if the JD is Java.
3. Design: modernize a legacy mission app without breaking the operational window.
4. STAR: shifting requirements under a deadline (Rapid responsiveness).
5. Questions: panel vs extra coding, live AI, clearance vs poly, Reston vs program site.
