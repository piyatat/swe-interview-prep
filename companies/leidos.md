# Leidos engineering track

Sits beside [bae-systems.md](bae-systems.md) and [lockheed-martin.md](lockheed-martin.md): **mission IT / systems integrator** across defense, intel, civil, health — not a FAANG feed and not “the F-35 OEM.” Official [Who We Are](https://www.leidos.com/company/who-we-are): digital and mission innovations for government and commercial customers; **~50,000** employees. Recruiter confirms **sector + program** (defense / intel / civil / health), C++ vs Java / Python / .NET, site vs hybrid, and **clearance / US-person** on the req.

Typical timeline **~2–4 weeks** of active eval after contact (Dataford; some guides say ~4–6). Clearance can delay start. Embedded: [../roles/embedded.md](../roles/embedded.md). Behavioral: [../general/behavioral.md](../general/behavioral.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (six values)

Do **not** invent Amazon LPs. Official [Who We Are](https://www.leidos.com/company/who-we-are) + [Our Culture](https://www.leidos.com/careers/life/culture). Map **your** stories.

| Official value | What they publish |
| --- | --- |
| **Integrity** | Tough ethical calls; transparent with the team; respectful |
| **Inclusion** | Belonging; all perspectives; equal access |
| **Innovation** | Tenacious / curious; not limited to “the scientists” |
| **Agility** | Flexible, creative, resilient; think small, use scale |
| **Collaboration** | Shared objectives; stay connected |
| **Commitment** | Ownership, servant leadership, urgency for customer and team |

“Why Leidos?” that only says “I like defense / I want a clearance” fails. Name a **sector or customer class** (civil health vs C4ISR vs cyber) and an **Integrity / Commitment** story. Culture page: they “wear purple”; environment is non-hierarchical — talking to your boss’s boss is encouraged.

## Official + reported process

Official US careers + [virtual-interview tips](https://www.leidos.com/insights/how-prepare-and-nail-virtual-interview): recruiter gives **Webex** instructions, joins first, then brings the hiring manager. Official agile-software hiring note: they may hand you a **block of code to optimize** and score whether you keep asking what else you missed. Treat round *count* and puzzle lists as **reported**.

| Stage | Official / reported |
| --- | --- |
| Apply | [careers.leidos.com](https://careers.leidos.com/) |
| Recruiter | Fit, sector, **clearance / citizenship**, compensation band |
| Panel (reported) | HM + leads: resume walkthrough, OOP / CS, STAR |
| Coding | **Ask** — some loops add a short logic / array hour; many stay conversational |
| Offer + start | Background; clearance can **delay start** |

Do not copy the **Australia** “Our Recruitment Process” page onto a US req — different tenant. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md): **ask** live-AI rules (not published as a US FAQ line).

## How this track differs

| vs Lockheed / BAE | vs FAANG |
| --- | --- |
| Official **six values**; integrator across **civil + defense**, not one airframe | Loop is **resume + panel**, not five DSA hours |
| Design is **mission system / telemetry / DevSecOps**, not a social feed | Clearance is a **gate** on many reqs |
| “Why Leidos?” must name **sector + program class** | Comp is program bands — not public RSUs |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** Leidos sector — Integrity when shipping faster would hide a defect.
2. OOP pillars + stack vs heap; RAII / smart pointers if the JD is C++.
3. Design: ingest radar / health telemetry without dropping a track.
4. STAR: shifting sprint priorities (Agility) or a disagreement you resolved (Collaboration).
5. Questions: sector vs program, Webex vs on-site, coding vs panel, live AI, clearance.

## Prep checklist

- [ ] Read [values](https://www.leidos.com/company/who-we-are) + [culture](https://www.leidos.com/careers/life/culture) + the **program** SWE JD
- [ ] Recruiter: sector, language, coding vs panel, live AI, clearance
- [ ] Three STAR mapped to **Integrity / Collaboration / Commitment** (first-person, measurable result)
- [ ] One OOP / CS refresh + one mission-system or DevSecOps sketch
- [ ] Comp after written offer: [../general/offer-negotiation.md](../general/offer-negotiation.md)
