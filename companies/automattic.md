# Automattic engineering track

Sits beside [github.md](github.md), [gitlab.md](gitlab.md), and [linear.md](linear.md): **WordPress.com / Woo / Tumblr (and other Automattic apps) + paid async trial**, not GitHub Actions and not a 2–5 day onsite trial. Official [How we hire developers](https://automattic.com/work-with-us/how-we-hire-developers/): four parts on **Slack, GitHub, and P2s** — **no whiteboarding**. Recruiter confirms **frontend vs backend vs mobile vs full-stack**, PHP / JS vs Calypso, and trial hours.

Typical developer path is **application → Slack intro → timeboxed take-home → paid trial (2–8 weeks calendar, ~15–35 hours of work)**. Take-homes / trials: [../general/take-homes.md](../general/take-homes.md). Async writing: [../general/pair-programming.md](../general/pair-programming.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official hire bar (do not invent extra pillars)

Official developer hire page + [The Automattic Creed](https://automattic.com/creed/) (public domain; last updated 2025-10-29). Map **your** stories. Do not invent FAANG LPs.

| Official signal | What they score |
| --- | --- |
| **Written communication** | Creed: communication is **oxygen** of a distributed company; cover letter and P2 posts are the product |
| **Security / performance / problem solving** | Take-home on a **near-real** unfamiliar codebase (plugin-shaped), not a puzzle |
| **Adapt to an unfamiliar codebase** | Same as day-to-day WordPress / Calypso work |
| **Async collaboration** | P2 for decisions (“P2 or it didn’t happen”); Slack `hi-NAME` not DMs |
| **Creed themes** | Keep learning; help colleagues; open source; marathon not sprint; impact over money |

Company-wide [Work with us](https://automattic.com/work-with-us/) adds: anti-bias training, **standardized rubric**, written evidence. Some roles use video instead of Slack; some have a later exec / CEO review — **ask**; the developer page’s closer is the trial + HR offer.

“Why Automattic?” that only says “I love WordPress / remote” fails. Name a **plugin, Gutenberg, Woo, or distributed-docs** problem you have lived.

## Official process (developers)

Developer hire page is the skeleton. Trial guide has extra logistics.

| Stage | Official |
| --- | --- |
| Application | Resume / answers; they read **communication**, not keyword stuffing |
| Intro | Private Slack channel with an engineer — questions about role, culture, process |
| Coding challenge | Take-home on near-real code; **~one week** (ask for more if needed); **timeboxed**; own tools; score security, performance, problem solving, communication |
| Trial | **Paid**, part-time, **2–8 weeks**, about **15–35 hours** (developer page). Trial guide: non-Happiness often **25–40 hours**, **$25 USD/hour** (not your future salary) |
| Offer | HR; you help with **team assignment** |

Trial guide: work happens on **P2** plus Slack / GitHub / Figma. Track hours, post progress, use the trial lead, take feedback. Format headings; put a summary on long posts.

## How this track differs

| vs GitHub / GitLab | vs Linear |
| --- | --- |
| Official **Slack intro + week take-home + multi-week paid trial**; no whiteboard | Trial is **async hours over weeks**, not a 2–5 day paid sprint |
| Creed + P2 writing is the culture hour | Product is **WordPress.com / Woo / Tumblr**, not issue-tracker craft |
| $25/h trial rate is published and **not** offer comp | “I only grind LeetCode” misses the plugin take-home |

## Coding and design flavor

Official: web frontend, backend, mobile, full-stack. Live work: WordPress plugins / REST, Gutenberg blocks, Calypso JS, Woo checkout, performance and XSS. Related: [../general/take-homes.md](../general/take-homes.md), [../answers/system-design-web-crawler.md](../answers/system-design-web-crawler.md).

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** distributed open-source house — portable “I want remote” is weak.
2. Slack intro: a time you documented a decision so others could replay it.
3. Take-home: fix a plugin; name the XSS / N+1 you would not ship.
4. Trial: P2 update with what you tried, what you skipped, what you need.
5. Questions for them: trial hours vs $25/h, AI-on-take-home, which app (WP.com vs Woo vs Tumblr).
