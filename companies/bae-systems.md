# BAE Systems engineering track

Sits beside [rtx.md](rtx.md) and [lockheed-martin.md](lockheed-martin.md): **US Inc. subsidiary of UK plc** — air / land / sea / space / cyber plus electronics. Not a FAANG feed and not “BAE-the-UK-graduate-scheme” as if Nashua Electronic Systems or the US shipyards did not exist. Official [Our Mission](https://jobs.baesystems.com/global/en/our-mission): **We Protect Those Who Protect Us®**. Recruiter confirms **Inc vs plc site** (US ES / I&S vs Warton / Barrow), C++ vs Java / Python, and **DoW / national-security clearance**.

Typical timeline **~4–6 weeks** of active eval (Dataford); some US SWE reqs move faster. Embedded: [../roles/embedded.md](../roles/embedded.md). Behavioral: [../general/behavioral.md](../general/behavioral.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (three values)

Do **not** invent Amazon LPs and do **not** reuse a UK-only eight-value list on a **US Inc.** req. Official [Our Mission](https://jobs.baesystems.com/global/en/our-mission) + [Our Culture](https://jobs.baesystems.com/ourculture). Map **your** stories.

| Official value | Behaviors they publish |
| --- | --- |
| **Trusted** | Committed; do what you say; do the right thing |
| **Innovative** | Curious; learn from successes **and** failures; turn ideas into action |
| **Bold** | Speak up; step forward; seize the opportunity |

“Why BAE?” that only says “Tempest / I like defense” fails. Name a **US program or UK site** that matches the req and a **Trusted / Bold** story. Official culture page: people stay for camaraderie as much as the mission.

## Official + reported process

Official [Application resources](https://jobs.baesystems.com/global/en/applicationresources): apply on the careers tenant → TA + HM review → email / phone / text; scheduler **Calen** may book you. Interviews are virtual **or** on-site. Official: use **STAR**; research newsroom + values; follow up after the window they named (often 1–2 weeks). Official SWE / ES pages: **AI tools are not permitted during interviews**; application and resume should reflect your skills.

| Stage | Official / reported |
| --- | --- |
| Apply | [jobs.baesystems.com](https://jobs.baesystems.com/global/en/applicationresources) |
| Screen | TA; clearance / citizenship; some early-career reqs add HireVue / a digital assessment |
| Panel | Official virtual or on-site; reported 1–2 h with 2–6 engineers + HM: STAR + OOP / resume |
| Extra (reported) | Short self / project deck, or a live snippet — **ask** |
| Offer + start | TA extends; onboarding + clearance can **delay start** |

## How this track differs

| vs RTX / Lockheed | vs FAANG |
| --- | --- |
| Official **Trusted / Innovative / Bold**; **Inc vs plc** is a real split | Loop is **STAR panel + clearance**, not five DSA hours |
| Design is **EW / combat vehicle / shipyard / rad-hard**, not a social feed | Most posted US SWE reqs need **DoW clearance** up front |
| “Why BAE?” must name **this country + program** | Comp is program bands — not public RSUs |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** BAE Inc. or plc site — Trusted when you refused a shortcut.
2. OOP pillars + C++ vs Python / Java if they ask the published-style language pick.
3. Design: hardware–software integration or a high-reliability control path.
4. STAR: speak up (Bold) or a failure you turned into a process change (Innovative).
5. Questions: Inc vs plc, Calen / HireVue vs skip, coding vs panel, live AI (official no), clearance.
