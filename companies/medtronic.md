# Medtronic engineering track

Sits beside [veeva.md](veeva.md) and [../roles/embedded.md](../roles/embedded.md): **healthcare-technology / device software** (cardiac, surgical, patient monitoring, imaging algorithms) — not a life-sciences **SaaS** CRM loop. Official [Mission](https://www.medtronic.com/en-us/our-company/mission.html): contribute to human welfare through biomedical engineering that **alleviates pain, restores health, and extends life**. Recruiter confirms **firmware vs cloud / algorithms vs quality**, C / C++ vs Python / C#, Minneapolis vs site, 4-day onsite, and live AI.

Typical timeline **~3–6 weeks** (guides; official pages do not publish a clock). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). Embedded: [../roles/embedded.md](../roles/embedded.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (Mission + Mindset)

Do **not** invent Amazon LPs. Official [Mission](https://www.medtronic.com/en-us/our-company/mission.html) is six tenets (unchanged since 1960 in company history). Official [Culture](https://www.medtronic.com/en-us/our-company/careers/culture.html) is the **Medtronic Mindset**. Map **your** stories. Quality and ethics beat “we shipped Friday.”

| Official line | What they publish |
| --- | --- |
| **Alleviate pain, restore health, extend life** | Patient outcome is the why |
| **Greatest possible reliability and quality** | Mission tenet 3 — unsurpassed standard |
| **Personal worth of employees** | Mission tenet 5 |
| **Act boldly** | Mindset — calculated risk, not recklessness |
| **Compete to win** | Customer / market need, then act |
| **Move with speed and decisiveness** | Cut delay without skipping verification |
| **Foster belonging** | Inclusion is a published cultural norm |
| **Deliver results…the right way** | Results without cutting ethics or quality |

“Why Medtronic?” that only says “medtech / Minneapolis” fails. Name a **patient-safety, V&V, or reliability** problem you have lived. Official JDs: **~95,000** employees; many US roles **4 days onsite**.

## Official + reported process

**Official** ([Engineer your career](https://www.medtronic.com/en-us/our-company/careers/engineering.html) + UK [application tips](https://www.medtronic.com/en-gb/our-company/careers/engineering.html), published process): apply / profile → **telephone** screen(s) → interview(s) → feedback after each round → offer + AskHR contract. Official interview advice: **be authentic and prepared**; show passion for **technology, the industry, and making a difference**; treat it as two-way (role, manager, team); ask questions.

**SWE (Dataford / Cohesyve 2026, treat as reported):** recruiter → technical (CS fundamentals, sometimes hardware comms / real-time) → design or project deep-dive on **your** device / platform work → STAR vs Mission + Mindset. Quality / IEC 62304 / risk-file language helps on device teams; enterprise IT roles look more like Java + SQL.

| Stage | Official / reported |
| --- | --- |
| Apply | [medtronic.com/careers](https://www.medtronic.com/en-us/our-company/careers.html) / Workday |
| Screen | Official phone interview(s) |
| Loop | Resume systems + coding or take-home on some teams; STAR |
| Closer | Fit vs Mission; onsite days; quality bar |
| Offer | Official: AskHR emails the contract |

Live AI: **ask**. A regulated product is a reason many teams keep the pad AI-off even if Copilot is used on the job. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md).

## How this track differs

| vs Veeva / Optum | vs FAANG |
| --- | --- |
| **Device + Mission**, not commercial-cloud CRM or payer IT | Medium DSA optional; **safety / V&amp;V** stories are first-class |
| Mindset “the right way” is a **quality** gate | Design is **telemetry, closed-loop, or imaging pipeline**, not a feed |
| Comp is medtech bands; site (MN / Boston / Memphis / …) is live | Speed without a verification story reads as a miss |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** therapy / OU — Mission when a deadline and a quality hold collided.
2. C memory / ISR / two-pointers if firmware; Java + SQL if IT.
3. Design: device telemetry upload with checksums, hold-and-release, and audit trail.
4. STAR: Deliver results the right way when a skip-test was proposed.
5. Questions: firmware vs cloud, live AI, V&amp;V bar, onsite days.
