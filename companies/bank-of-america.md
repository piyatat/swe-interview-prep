# Bank of America engineering track

Sits beside [citi.md](citi.md) and [wells-fargo.md](wells-fargo.md): **U.S. universal-bank technology** (eight lines of business, Merrill, Global Markets) — not a FAANG feed and not “the same Super Day as JPMC.” Official [values](https://careers.bankofamerica.com/en-us/company/values): **Responsible Growth** plus four core values. ## Official culture (core values)

Do **not** recite 16 Amazon LPs. Official [Mission & values](https://careers.bankofamerica.com/en-us/company/values). Map **your** stories.

| Official line | What they score |
| --- | --- |
| **Deliver together** | Person-to-person; discipline under a date; not “the team shipped” |
| **Act responsibly** | Integrity + **risk**; a decision that was clear and fair |
| **Realize the power of our people** | You grew someone (or yourself) without erasing them |
| **Trust the team** | Shared ownership; one-company, not org-chart theater |

Official [Technology](https://careers.bankofamerica.com/en-us/company/organization/technology): platforms across **eight lines of business**; cyber, AI/ML, third-party risk. They publish **responsible AI** (Harvard Kennedy School council; 40k+ SDLC teammates in AI skills). “Why BofA?” that only says “finance / Charlotte” fails. Name a **client journey, controls, or responsible-AI** problem.

## Official + reported process

Official [hiring process](https://careers.bankofamerica.com/en-us/hiring-process): find role → apply → mix of phone / video / in-person with HR, managers, peers → **exercises and assessments** → written contract. Official technology join path: Discover → Apply → Interview with the **hiring manager** if invited → Join.

| Stage | Official / reported |
| --- | --- |
| Apply | [careers.bankofamerica.com](https://careers.bankofamerica.com/en-us/hiring-process) — confirmation email |
| Recruiter | ~30 min Webex: stack, authorization, band — usually **no** live coding |
| OA / HireVue (guides) | TechPrep (2026): two easy–medium coding + recorded **explain complexity**; plus ~3 behavioral videos. Programmer HireVue can require a **PC** |
| Tech | Two live videos: (1) DSA + SQL (2) OOP / Spring / LLD, or design for SE II/III |
| Final | HM / HR: Responsible Growth + the four values |

[../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md): **ask**. Official values page trains AI **on the job**; that is not a live-interview license.

## How this track differs

| vs Wells Fargo | vs FAANG |
| --- | --- |
| Official **four** values + Responsible Growth; HireVue explain-your-code | Medium strings / arrays / heaps, not contest graphs |
| Design is **txn monitoring / payments / REST**, with risk named early | Behavioral is a **full** final, not a five-minute closer |
| Java + Spring + multithreading show up on Global Markets JDs | Comp is bank bands — not public RSUs |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** BofA Technology org — Act responsibly when a control and a client date disagreed.
2. HireVue-style: two easy–medium (string / heap) then **say** the complexity on camera.
3. SQL: second-highest salary / join + window; then Abstract class vs interface.
4. Design: payment or trade-alert API — idempotency key in the first sketch.
5. Deliver together: you inherited a partner team’s defect the week of release.
