# Wiz engineering track

Sits beside [palo-alto.md](palo-alto.md) and [crowdstrike.md](crowdstrike.md): **code-to-cloud-to-runtime security graph (CNAPP / AI security)**, not a firewall loop or a pure EDR shop. Official [Careers](https://www.wiz.io/careers) + [homepage](https://www.wiz.io/): protect everything orgs **build and run** by connecting **code, cloud, and runtime**. Google **completed the acquisition on 2026-03-11**; official [Wiz blog](https://www.wiz.io/blog/google-closes-deal-to-acquire-wiz) + [Google Cloud](https://cloud.google.com/blog/products/identity-security/google-completes-acquisition-of-wiz): **brand stays**, **multi-cloud stays** (AWS / Azure / GCP / OCI). Recruiter confirms **graph / sensor / cloud vs detection research**, Go / Python, NYC / Tel Aviv / other, and whether the loop is still Wiz-run vs Google Cloud.

Typical timeline **~2–7 weeks** (2026 guides; candidate reports as short as two weeks). Security: [../roles/security.md](../roles/security.md). Graphs: [../answers/coding-course-schedule.md](../answers/coding-course-schedule.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official hire bar (do not invent extra pillars)

Official Careers **Wiz Values**. Map **your** stories. Do **not** paste Googleyness as if it replaced these.

| Official value | What they score |
| --- | --- |
| **Be truthful** | Bad news early; you do not sandbag a risk |
| **Win together** | Cross-cloud / cross-team help, not a lone-hero scanner |
| **Lead by example** | Standard you hold yourself to when nobody is watching |
| **Execute with excellence** | Shipped bar — “highest possible standards of execution” (Careers) |
| **Act confident, stay humble** | Strong call + you can be wrong in public |

“Why Wiz?” that only says “Google acquired you / cloud security is hot” fails. Name a **graph, IAM, runtime, or multi-cloud** problem you have lived. Official blog: mission is still **protect everything they build and run**, now **at AI speed**.

## Official + reported process

Careers publishes values, hybrid policy, and **@wiz.io-only** recruiting (jobs on wiz.io/careers + LinkedIn). It does **not** publish a SWE stage list. 2026 guides (TechPrep; candidate write-ups) — treat stages as **reported**.

| Stage | Official / reported |
| --- | --- |
| Recruiter (~30) | Background, cloud/security fit; confirm **Google vs Wiz** loop + site |
| HM (~45, guides) | Projects, why **this** graph / sensor team |
| Tech screen (~60, guides) | Live coding in a shared editor; DSA with a cloud twist |
| Loop (guides: 4–5) | Coding, **security-flavored design**, cloud-internals depth, behavioral |
| Offer | Google-owned; ask **level, refresh, which payroll / site** |

Guides: design is **scan a billion resources / attack-path graph**, not Twitter. Domain hour: IAM, KMS, metadata, blast radius. Confirm AI-in-pad; do not assume Google’s Gemini coding pilot.

Phishing: official Careers — Talent mail is **@wiz.io** only; they will not ask for SSN / cards.

## Coding and design flavor

Graphs, trees, hash maps; concurrency in a later coding hour (reported). Design: multi-tenant scanner, attack-path graph, least-privilege identity. Related: [../answers/system-design-metrics.md](../answers/system-design-metrics.md). Talk **effective permissions**, not a tool logo.

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** CNAPP (graph + multi-cloud + Google scale) — not “I want cybersecurity.”
2. Value: be truthful — a time you killed a ship over a real blast radius.
3. Live: graph / tree medium; say what a false negative costs.
4. Design: daily scan of a multi-cloud estate; who owns the fix in code.
5. Questions for them: graph vs sensor vs research, Google loop vs Wiz, AI policy.
