# GE Vernova engineering track

Sits beside [ge-aerospace.md](ge-aerospace.md) and [siemens.md](siemens.md): **electrify + decarbonize** (Power, Wind, Electrification / grid software) after the 2024 GE split — **not** GE Aerospace (engines) and **not** a generic “GE Digital” brand. Official purpose: **The Energy to Change the World**. Recruiter confirms **Power vs Wind vs Electrification Software vs digital controls**, C++ / Java / Python, site (Cambridge HQ vs Hyderabad / Romania / field), campus vs experienced, and live AI.

Typical timeline **~3–5 weeks** (guides; campus can compress). Embedded: [../roles/embedded.md](../roles/embedded.md). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (GE Vernova Way)

Do **not** recycle FLIGHT DECK or pre-2024 GE Leadership Behaviors as if they were this company. Official [Life at GE Vernova](https://careers.gevernova.com/life-at-ge-vernova) + CPO write-up: five principles. Form 10 names them **Innovation, Customers, Lean, One Team, Accountable**. Map **your** stories.

| Official line | What they score |
| --- | --- |
| **Innovation** | Electrify / decarbonize — a better way, not a demo |
| **Customers** | Utility / ISO / grid operator eyes; mutual success, long-term |
| **Lean** | Better every day; safety, quality, delivery, cost as the operating system |
| **One Team** | Cross border / function; you broke a silo, not “I like collaboration” |
| **Accountable** | Individual **and** collective delivery on a named commitment |

“Why GE Vernova?” that only says “GE / energy / I like AI” fails. Name a **grid, generation, wind, or industrial-software** problem. Do **not** reuse GE Aerospace FADEC stories as if they were this ticker.

## Official + reported process

Official [Electrification Software careers](https://www.gevernova.com/software/careers): **six steps** — find role → apply → recruiter → hiring manager → **key stakeholders** (collaboration + problem solving) → offer. Apply via [careers.gevernova.com](https://careers.gevernova.com/). They say they usually **cannot** give individual reject feedback.

| Stage | Official / reported |
| --- | --- |
| Apply | Workday / careers.gevernova.com — Power vs Wind vs Software is a real org split |
| Recruiter | Role detail, site, stack |
| Hiring manager | Specific examples vs the JD (official) |
| Stakeholders | Team + decision makers; culture fit |
| OA / campus (guides) | India campus often **AMCAT / Cocubes** aptitude + 2 coding; some software reqs **HackerRank / HackerEarth**. US experienced reports are thinner: recruiter + HM, sometimes a coding hour |
| Offer | Background as applicable |

Treat OA vendor and campus GD as **reported** — ask. Unlike [ge-aerospace.md](ge-aerospace.md), this run found **no** published “AI-off live” policy page; confirm before you assume Copilot is allowed. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md).

JDs for grid / EMS software name **C++ or Java, SQL, utilities / ISO domain**. Only prep power-systems domain if the req says so.

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** Vernova product line — Customers when a utility constraint killed the elegant design.
2. OOP / resume: defend every skill on the page; then a medium array or tree if there is an OA.
3. Design: ingest SCADA / historian points without dropping a red-line alarm.
4. Lean: a small measured change you made with the people who run the process.
5. Questions: Power vs Wind vs Electrification Software, OA vs skip, site, live AI.
