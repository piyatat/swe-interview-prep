# Expedia Group engineering track

Sits beside [booking.md](booking.md) and [airbnb.md](airbnb.md): **OTA / travel marketplace** (Expedia, Hotels.com, Vrbo, …), not Booking.com’s official Java/experiment loop and not Airbnb’s Core Values + DP slate. Official [interview guide](https://careers.expediagroup.com/interview-guide/) + [tech careers](https://careers.expediagroup.com/technology/): purpose is **help travelers explore the world, one journey at a time**. Recruiter confirms **SDE vs mobile vs security vs applied science**, brand / org, emerging-talent vs experienced, and **AI policy** (official: **do not** use AI to answer interview questions).

Typical timeline **varies by team** (official). New-grad / intern path is the most fully published. Coding: [../general/coding-patterns.md](../general/coding-patterns.md). SQL / search: [../general/sql-interviews.md](../general/sql-interviews.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (five Behaviors)

Do **not** invent Amazon-style LPs. Official [interview guide](https://careers.expediagroup.com/interview-guide/) and [SDE prep hub](https://careers.expediagroup.com/emergingtalent-prephub-sde/) publish **five Behaviors**. Map **your** stories. Tech careers: they will ask **competency and strength-based** questions against these.

| Official Behavior | Careers one-liner |
| --- | --- |
| **Traveler First** | Traveler in every action and decision |
| **Think Big** | Ambitious; see the bet others miss; long-term value |
| **Operate with Excellence** | Tenacious; improve the system day after day |
| **Ownership Mindset** | The business is yours; think past your metric |
| **Succeed Together** | Candor, hard debate, then **commit** as one team |

“Why Expedia Group?” that only says “I like travel / Seattle / brands” fails. Name a **search, availability, or partner-inventory** problem you have lived. Official purpose language beats “OTA is like Uber for hotels.”

## Official process

Two official tracks. **Ask which one you are on.** Tech careers: apply to **at most 5** reqs in **45 days**. Dress is casual; camera **on** for virtual hours (emerging-talent FAQ). Interviewers are trained Expedians on the **role profile** — they may **not** be your future team. Completing one profile does **not** skip another.

### Emerging talent (official prep hubs)

Official [HackerRank hub](https://careers.expediagroup.com/emergingtalent_hackerrank/) + [SDE final-stage hub](https://careers.expediagroup.com/emergingtalent-prephub-sde/):

| Stage | Official |
| --- | --- |
| Application | Recruiter match from the req |
| Strengths-based assessment | Gate before HackerRank |
| HackerRank (SDE / security / mobile) | **~90 min**, one sitting, no save-and-return; language of choice (editor defaults to C — **switch**). Sample questions first. Applied science is a separate **120–150 min** notebook-style test |
| Review | They keep strong OA scores active if a slot is not open yet |
| Final stage | **Two** virtual interviews: **Problem Solving & Algorithms** + **Data Structures**, plus Behaviors (Traveler First / Think Big / Succeed Together on the algo hour; Operate with Excellence / Ownership / Succeed Together on the DS hour) |
| AI | Official FAQ: **do not** use AI to answer questions; ask if a tool is an approved accommodation |

### Experienced (official interview guide)

| Stage | Official |
| --- | --- |
| Application | Same 5-in-45 cap |
| Skills / experience assessment | Technical test, **business case**, and/or **work sample** — role-dependent |
| Cultural assessment | Work style vs the five Behaviors |
| Interviews | Conversation + STAR behavioral; recruiter names who and how long |

## How this track differs

| vs Booking.com / Airbnb | vs FAANG |
| --- | --- |
| Official **five Behaviors** + **AI-off** live answers | Emerging-talent slate is **OA + two** virtual hours, not a six-hour Superday |
| Design is **OTA inventory / search / partner**, not a social feed | “I only grind hards silently” misses STAR vs Behaviors |
| Strengths-based + HackerRank published for campus | Experienced may be a **case / work sample**, not only DSA |

## Coding and design flavor

Official tech careers: scalable apps, search, personalization, auctions, partner integrations. Live DSA: arrays / maps / graphs / heaps with a **travel costume** (itineraries, rooms, flights). Design: availability, overbook, multi-brand catalog, price freshness. Related: [../answers/system-design-search.md](../answers/system-design-search.md), [../answers/system-design-ticketmaster.md](../answers/system-design-ticketmaster.md).

Narrate out loud. Official SDE hub: if a prompt is unclear, **ask**. STAR is the published behavioral shape.

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** EG brand / platform — a traveler or partner friction, not “I like hotels.”
2. HackerRank: finish the function; edges; switch off the default C template.
3. Algo hour: optimal approach + a Behavior story if they ask mid-problem.
4. Design: hotel search + room availability across Brands when a partner feed is stale.
5. Succeed Together: you disagreed, then committed.
