# Verizon engineering track

Sits beside [cisco.md](cisco.md) and [akamai.md](akamai.md): **carrier-scale software** (5G / edge, customer platforms, network orchestration) — not a FAANG feed and not “Cisco but wireless.” Official [Our Culture](https://www.verizon.com/about/our-company/our-culture): **Culture OS** with three values; **~100,000** employees; purpose is to **power and empower how people live, work and play**. Recruiter confirms **Technology Solutions vs Product vs Network Engineering**, Java / Spring vs React, and site vs hybrid.

Typical timeline **~3–5 weeks** (Dataford / TechPrep). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). Networking / OS: [../general/cs-fundamentals.md](../general/cs-fundamentals.md). SQL: [../general/sql-interviews.md](../general/sql-interviews.md). ## Official culture (Culture OS)

Do **not** invent Amazon LPs. Official [Our Culture](https://www.verizon.com/about/our-company/our-culture): values and V Team principles apply **internally and externally**. Map **your** stories.

| Official value | What they publish |
| --- | --- |
| **Trust** | Build trust every day for customers and each other |
| **Care** | People, and connecting them to what matters |
| **Excellence** | Highest standards of performance and quality |

“Why Verizon?” that only says “telecom / 5G is hot” fails. Name a **reliability, customer-journey, or network-adjacent** problem from the [technology careers](https://mycareer.verizon.com/career-paths/technology/) page (Technology Solutions, Product & Strategy, Network Engineering, Data & Analytics).

## Official + reported process

Official [How we hire](https://mycareer.verizon.com/life-at-verizon/how-we-hire/): apply in Candidate Home → some roles take an **assessment** → phone / video / in-person interview → offer + pre-employment screening. Official [Interviewing](https://mycareer.verizon.com/life-at-verizon/how-we-hire/interviewing/): **structured behavioral** is the foundation; mix of behavioral, situational, and **knowledge** questions; they will **repeat** a question but will **not** interpret it. Official [Assessments](https://mycareer.verizon.com/life-at-verizon/how-we-hire/assessments/): job-specific; MCQ, personality, simulation, or situational; EEOC / OFCCP aligned.

| Stage | Official / reported |
| --- | --- |
| Apply | [mycareer.verizon.com](https://mycareer.verizon.com/life-at-verizon/how-we-hire/) Candidate Home |
| Assessment (some roles) | Official invite subject “Take Assessment…”; campus OA often aptitude + CS MCQs + 1–2 coding |
| Recruiter | Fit, location, stack, salary |
| Tech (guides) | 1–3 virtuals: practical DSA, Java / Spring or resume stack, LLD + HLD mix |
| HM / HR | STAR vs Trust / Care / Excellence; team + comp |

TechPrep (2026): some loops add a **non-eliminatory AI-tool** conversation (how you prompt / verify Copilot-class output). [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md): **ask** live-AI rules (not a published FAQ line).

## How this track differs

| vs Cisco | vs FAANG |
| --- | --- |
| Official **three** Culture OS values, not People Deal | Medium DSA + **Java / SQL / networks**, not olympiad graphs |
| Design is **alerts, portals, orchestration**, not a social feed | Structured STAR is the **default** hour, not a bolt-on |
| OA / HireVue is **role-specific** | Comp is telecom bands — not public RSUs |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** Verizon org — Trust when a customer-impacting outage and a release date disagreed.
2. Reverse a list / cycle, SQL join on a large table, or HashMap internals if the JD is Java.
3. Design: real-time **network-alert** fan-out without drowning on-call.
4. STAR: cross-functional deadline (Excellence) without burning the partner team (Care).
5. Questions: OA vs HireVue, live AI, Java vs other stack, site vs hybrid.
