# Flow Traders engineering track

Sits beside [optiver.md](optiver.md) and [imc.md](imc.md): **ETP / digital-asset market-making SWE (Amsterdam HQ + global offices)**, not Optiver’s published “how you think” pair day and not IMC’s OA-then-trading-system assessment. Official [Technology careers](https://www.flowtraders.com/careers/technology): Technology is **>40%** of the firm; Product Development builds the **in-house** suite (C++ / Java / Python / data + QA); IT covers systems, network, security, trading support. Recruiter confirms **SWE vs Trading Ops Eng vs trader / research**, **C++ vs Java**, office, and AI (ask — they do not publish a live-AI rule on the careers pages).

Typical official Technology path: **apply (CV + cover letter) → HackerRank → recruiter → technical / team + final**. Graduate Software Development is a **five-stage** variant with an explicit **Codepair**. Culture: [../general/behavioral.md](../general/behavioral.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (four values)

Do **not** invent extra pillars. Official [careers](https://www.flowtraders.com/careers/) + [Annual Report 2025](https://www.flowtraders.com/media/2s2pdl01/flow-traders-annual-report-2025.pdf):

| Official value | What they score |
| --- | --- |
| **We are one team** | Shared incentives; honest dialogue; firm success over local empire |
| **We are entrepreneurial** | Critical thinkers; ideas from anyone |
| **We are driven** | Excel and continuously improve; collective strength |
| **We are responsible** | Governance; market integrity |

Official C++ JD: **non-hierarchical**, short feedback loops (traders / researchers a walk away), **shared libraries**, code reuse, evolving architecture. “Why Flow?” that only says “HFT / Amsterdam / ETF” fails — name a **venue connectivity, pricing, or risk-control** problem you have lived.

Official FAQ: grads / interns need **interest** in markets more than commercial experience; senior roles prefer finance industry experience. Visa sponsorship is **open** for hires (not interns). They book interview travel if you are not local.

## Official process

Experienced Technology — official [Technology careers](https://www.flowtraders.com/careers/technology):

| Stage | Official |
| --- | --- |
| Apply | CV **and** cover letter for the role |
| Online assessment | HackerRank (MCQ **or** open-ended; role-shaped) |
| Recruiter | Business knowledge, motivation, cultural fit |
| Technical + final | Meet the team: experience, technical skills, relevant knowledge |

Graduate Software Development — official [graduates](https://www.flowtraders.com/careers/graduates) (do **not** confuse with the trader numerical-test path):

| Stage | Official |
| --- | --- |
| Apply | CV + cover letter; rolling until the class fills |
| HackerRank | **C++ or Java** coding / proficiency |
| Recruiter | Motivation + culture |
| Codepair | Senior developer; problem-solving + coding |
| Final | Team Lead; team compatibility + values |

Official: new SWE placement uses **your** technical strengths **plus** business knowledge **and** what you want to work on. Grads rotate teams, then pick with a mentor. Do **not** prep the trader brainteaser / case path unless that is the req.

## How this track differs

| vs Optiver / IMC | vs FAANG |
| --- | --- |
| Official **HackerRank + team meet**; grads add **Codepair + TL** | Four named values, not LPs |
| Product is **ETP / digital-asset liquidity** | In-house modular platform, not “design Twitter” |
| Cover letter is an official first step | “I only grind Blind 75 silently” misses values + markets interest |

## Coding and design flavor

Official platform: pricing and trading, market-data processing, pre-trade risk, compliance tools; **modular** so they can ship enhancements fast. Live: C++ / Java fluency, structures, correctness under load. Design: feed handler / order gateway, what you lock, what happens when a venue dies. Related: [../general/cs-fundamentals.md](../general/cs-fundamentals.md), [../general/low-level-design.md](../general/low-level-design.md).

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** Flow desk or platform (ETP, digital assets, risk) — portable “I like trading” is weak.
2. HackerRank: C++ or Java; they say MCQ **or** open-ended — ask which.
3. Codepair / team hour: working code + how it sits next to a trader.
4. Values: one-team vs local optimization, or a responsible-markets call.
5. Questions: Product Dev vs IT, language, city, rotation, AI in **your** hour.
