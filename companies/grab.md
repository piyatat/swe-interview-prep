# Grab engineering track

Sits beside [doordash.md](doordash.md) and [uber.md](uber.md): **Southeast Asia super-app** (rides, food, deliveries, GrabPay / GrabFin), not a US marketplace loop and not a payments-only hour. Official [Careers](https://www.grab.careers/en/): **AI-first company with heart**. Recruiter confirms **city / hub** (SG, ID, MY, VN, TH, PH, …), **backend vs mobile vs data**, language (Java / Go / Swift / Kotlin reports), and remote vs office.

Typical timeline **~3–5 weeks** (Dataford 2026). Dispatch / geo: [../answers/system-design-ride-sharing.md](../answers/system-design-ride-sharing.md). Ledger: [../answers/system-design-payment.md](../answers/system-design-payment.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (4Hs)

Do **not** invent Amazon LPs. Official [Our values](https://www.grab.careers/en/life-at-grab/our-values/): the 4Hs are **the hire bar**. Map **your** stories.

| Official H | Careers one-liner |
| --- | --- |
| **Heart** | Fiercely user-first; do what is right for the user even when it is hard |
| **Hunger** | Build fast, test early, pivot; master tools because “good enough” is not |
| **Honour** | Radical ownership; debate hard, commit, follow through |
| **Humility** | Not there yet; own mistakes; 1% better every day; coach, don’t only criticise |

“Why Grab?” that only says “SEA Uber / I like super-apps” fails. Name a **three-sided marketplace, last-mile, or wallet** problem you have lived. Official tips: **Stay AI-Ready** — discuss how you use tools **and** ethical limits, not “I never touch AI.”

## Official + reported process

Official [How we hire — Engineering](https://www.grab.careers/en/how-we-hire/engineering/): live coding, system design, culture fit. Leadership seats add a **how you lead through others** hour.

| Stage | Official / reported |
| --- | --- |
| Recruiter | Background, hub, team, next steps |
| Live coding | Official: **1–2** DSA questions on an online pad; think out loud |
| System design | Official: scalable systems — architecture, **security, monitoring**; whiteboard / brainstorm |
| Culture fit | Official: collaboration vs the **4Hs** |
| Leadership (leads) | Official: lead, inspire, results through others |
| Timeline | ~3–5 weeks, ~3 named stages (Dataford) — **ask** your recruiter |

Reports (Dataford): coding is often **easy–medium**; some teams add Codility / take-home. Treat extra OA as **reported**. Pair / OA: [../general/online-assessments.md](../general/online-assessments.md), [../general/pair-programming.md](../general/pair-programming.md).

## How this track differs

| vs DoorDash / Uber | vs generic FAANG |
| --- | --- |
| Design names **driver + merchant + e-wallet**, not a US-only marketplace | Official **AI-first** prompt in the how-we-hire tips |
| 4Hs are scored culture, not a vibe check | Live DSA + design + values; not a work-trial |
| Hub and product (GrabFood vs GrabBike vs GrabFin) change the loop | Security + monitoring called out in the design hour |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** super-app — a SEA constraint (cash, multi-country, partner SMEs), not “I like rides.”
2. Live coding: medium array / hash / string; narrate complexity; they score the **path**.
3. Design: city-scale dispatch **or** wallet top-up; say consistency vs availability; where fraud / refunds sit.
4. 4Hs: a time you owned a miss (Honour + Humility) or shipped a user-first cut (Heart).
5. Questions: hub vs remote, AI-in-pad, Java vs Go, Food vs Mobility vs Fin.
