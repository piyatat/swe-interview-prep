# Synopsys engineering track

Sits beside [nvidia.md](nvidia.md) and [qualcomm.md](qualcomm.md): **EDA / silicon-to-systems software** (design, IP, simulation), not a CUDA kernel loop and not a FAANG feed design. Official [About](https://www.synopsys.com/company.html): **empower innovators to drive human advancement**; leader in engineering solutions from **silicon to systems**. Recruiter confirms **EDA vs IP vs software-integrity vs full-stack**, C++ vs Python vs Java, site vs remote, and **AI-in-pad**.

Typical path: Talent Acquisition screen → hiring-manager + job-based interviews (official FAQ). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). Systems: [../general/cs-fundamentals.md](../general/cs-fundamentals.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (core values)

Do **not** invent Amazon LPs. Official interview FAQ names four values. Map **your** stories.

| Official value | Careers one-liner |
| --- | --- |
| **Agility** | Handle unexpected change; ship when the node / customer moves |
| **Courage** | Say the hard technical thing; take feedback without theater |
| **Excellence** | Precision on graphs, memory, and correctness — chips do not forgive |
| **Trust** | Own the module; the designer’s tape-out depends on it |

“Why Synopsys?” that only says “semiconductors are hot” fails. Name a **graph, geometry, compiler, or verification** problem you have lived — they write the software that **other** chip teams run.

## Official process

Official [FAQ for Your Synopsys Interview](https://careers.synopsys.com/InterviewProcessFAQ).

| Stage | Official |
| --- | --- |
| Pre-screen | Talent Acquisition reviews the req; shortlist → phone screen |
| Phone screen | ~**30** minutes |
| Formal / job-based | Hiring manager on **values**; peers on job skills + behavioral; **45–60 min** each; time for **your** questions |
| Virtual | Zoom; test camera / mic; life noise is OK |
| AI policy | **Prep with AI is fine** (research, practice, clarity). Interviews must show **your** thinking. Unapproved live AI / transcription / coaching **may pause or end** the process unless a documented accommodation |

Official sample prompts (behavioral, not puzzles): unexpected change; tight deadline; constructive feedback.

Reports (Dataford 2026): ~3–5 weeks; often an OA or C++/logic screen; then several technicals (C++ / DSA / optional RTL or UVM by team). Treat extra OA and round **count** as **reported**. Pair / OA: [../general/online-assessments.md](../general/online-assessments.md).

## How this track differs

| vs NVIDIA / Qualcomm product silicon | vs generic FAANG |
| --- | --- |
| Product is **tools + IP** for other designers, not a consumer SoC | Official **ACE+T** values hour, not Leadership Principles |
| Graphs / geometry / STA / netlists show up more than social-feed design | Official: **live AI off**; coach ≠ substitute |
| C++ memory + RAII are baseline on many EDA teams | Job-based interviews, not a centralized bar-raiser slate |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** EDA house — a synthesis, place-and-route, or verification constraint you have lived.
2. Cycle in a directed netlist / topo order — [../answers/coding-course-schedule.md](../answers/coding-course-schedule.md).
3. Overlapping rectangles or interval merge on a layout — [../answers/coding-merge-intervals.md](../answers/coding-merge-intervals.md).
4. C++: RAII, move vs copy, vtable — say when a smart pointer actually helps.
5. Values: a time you changed plan (Agility) or pushed back on a wrong shortcut (Courage / Excellence).
