# Citi engineering track

Sits beside [jpmorgan.md](jpmorgan.md) and [goldman.md](goldman.md): **global-bank technology** (payments / markets / cards / cyber) — not a FAANG feed and not “the same Super Day as JPMC.” Official mission ([About Us](https://www.citigroup.com/global/about-us)): trusted partner by **responsibly** providing financial services that enable growth. Leadership Principles: **we take ownership, we deliver with pride, we succeed together**. Recruiter confirms **campus Tech vs experienced**, **Karat vs HackerRank**, Java vs other stack, and NYC / NJ / other hub.

Typical timeline **a few weeks to several months** (TechPrep; compliance is the long pole). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). ## Official culture (Leadership Principles)

Do **not** recite 16 Amazon LPs. Official [About Us](https://www.citigroup.com/global/about-us) + [Careers About Us](https://jobs.citi.com/about-us). Map **your** stories.

| Official line | What they score |
| --- | --- |
| **Take ownership** | You named the hole, the control, and the date — not “the team shipped” |
| **Deliver with pride** | Quality under a deadline; you would put your name on the release |
| **Succeed together** | Cross-border / cross-function; you made someone else look good |

Official [Technology](https://jobs.citi.com/about-us) line: engineer the **financial services platform** (customer/colleague solutions, infrastructure, data, cyber). “Why Citi?” that only says “finance pays / I want NYC” fails. Name a **cross-border, controls, or platform-simplification** problem.

## Official + reported process

**Early career (official [five steps](https://jobs.citi.com/early-career-programs)):** Apply (Workday) → **skills evaluation** (coding assessment for Tech; skills-discovery survey for EMEA / Services) → one-on-one first interview (background + aspirations) → final stage (**multiple interviews, an assessment, or a case** — program/location) → written offer. Official 2027 Tech analyst JD: pass technical interviews with **basic algorithmic programming exercises**; GenAI as a problem-solving tool is listed as a plus — **ask** whether the live hour is AI-off.

**Experienced (guides, not a published step list):** recruiter → often **Karat ~60 min** (resume + multi-part coding / debug) → 2–3 team technicals (Java / Spring / Kafka, live debug) → Superday (coding + design + behavioral) → hiring committee + **background / compliance**.

| Stage | Official / reported |
| --- | --- |
| Apply | Citi Workday — new account even if you have Workday elsewhere |
| Tech coding eval | Official for early-career Tech; experienced often Karat (TechPrep / PracHub) |
| First interview | Official: background + how aspirations **align with Citi** |
| Final / Superday | Official: interviews **or** assessment **or** case; guides add Java + payments design |
| Offer | Official: recruiter explains; **always in writing** |

[../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md): **ask**. Do not paste a model into Karat unless the invite says so.

## How this track differs

| vs JPMorganChase | vs FAANG |
| --- | --- |
| Official **three** Leadership Principles, not four JPMC tenets | Medium DSA + **Java internals + SQL**, not olympiad graphs |
| Early career is **eval → 1:1 → variable final**; JPMC is cohort Super Day then match | Design is **ledger / pub-sub / cards**, with **controls** in the first sketch |
| Karat is a common **experienced** gate | Compliance can **outlast** the technical bar |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** Citi Technology org — ownership when a control and a launch date disagreed.
2. Karat-style: sliding window / coin-change family, then a harder constraint.
3. Live debug a Java snippet: racy map, missing idempotency key, unbounded query.
4. Design: retry-safe posting API or trade-alert pub-sub — exactly-once vs at-least-once.
5. Succeed together: you inherited a partner team’s outage — what you did.
