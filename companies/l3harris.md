# L3Harris engineering track

Sits beside [rtx.md](rtx.md) and [northrop-grumman.md](northrop-grumman.md): **Trusted Disruptor** defense-tech software (air / land / sea / space / cyber), not a FAANG feed and not “Harris-the-radio-company” as if Space & Mission Systems did not exist. Official [About us](https://www.l3harris.com/about-us): three strategic segments; HQ **Melbourne, FL**. Recruiter confirms **segment + site** (SMS vs Communications & Spectrum Dominance vs Missile Solutions), C++ vs Java / Python, onsite vs 9/80, and **clearance**.

Typical timeline **~3–5 weeks** of active eval (Dataford). Embedded: [../roles/embedded.md](../roles/embedded.md). Behavioral: [../general/behavioral.md](../general/behavioral.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (three values)

Do **not** invent Amazon LPs. Official [About us](https://www.l3harris.com/about-us). Map **your** stories.

| Official value | Behaviors they publish |
| --- | --- |
| **Integrity** | Ethical, honest, accountable decisions |
| **Excellence** | Flawless execution, customer focus, constant innovation |
| **Respect** | Sustainable, community-minded approach to hard problems |

“Why L3Harris?” that only says “radios / I like defense” fails. Name a **segment** (space vs spectrum vs missiles) and an **Integrity / Excellence** story. Mission line on the same page: innovate relentlessly and deliver capability at the speed customers demand.

## Official + reported process

Official [Careers](https://careers.l3harris.com/en) + [Engineering](https://careers.l3harris.com/en/engineering): apply on the careers tenant; many SWE reqs run through **virtual hiring events** (Texas / Fort Wayne-style blitzes) as well as the ordinary pipeline. Dataford: recruiter or career-fair screen → HM / senior-engineer technical (Teams) → **panel or blitz** with leads + cross-functional engineers. Live LeetCode is **uncommon**; resume OOP / C++ and a project walk-through are the bar.

| Stage | Official / reported |
| --- | --- |
| Apply | [Careers](https://careers.l3harris.com/en) — or a posted hiring-event req |
| Screen (reported) | Recruiter or fair: background, site, salary band, **citizenship / clearance** |
| Technical (reported) | 30–60 min HM / peer: resume, OOP, stack vs heap, concurrency |
| Panel / blitz (reported) | 2–5: STAR + project; some teams add a snippet or take-home |
| Offer + start | Background / drug screen; clearance can **delay start** |

Live-AI rules are **not** published on careers — ask. Default in a cleared room is unaided. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md).

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** L3Harris segment — Integrity when you stopped a bad test or a shortcut.
2. OOP pillars + abstract class vs interface + stack vs heap if the JD is C++.
3. Design: ingest RF / ISR / payload samples without dropping a track.
4. STAR: disagreement mapped to **Respect**; a miss mapped to **Excellence**.
5. Questions: which segment, hiring-event vs ordinary loop, coding vs panel, live AI, hybrid vs site, clearance.
