# Lowe's technology track

Sits beside [home-depot.md](home-depot.md) and [walmart.md](walmart.md): **#2 home-improvement retailer software** (eCommerce, store systems, supply chain, Charlotte Tech Hub) — not “Home Depot with blue.” Official [Technology](https://talent.lowes.com/us/en/tech): curiosity + a 100-year retail footprint; CDIO copy is **scale and depth without staying stagnant**. Recruiter confirms **store / supply-chain vs digital vs security**, Java vs front-end, Charlotte vs Mooresville vs Bengaluru, Luci vs human screen, and live AI.

Typical timeline **~2–4 weeks** (CleverPrep / Glassdoor; treat extra round counts as **reported**). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). Pair: [../general/pair-programming.md](../general/pair-programming.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (values + Core Behaviors)

Do **not** invent Amazon LPs. Official [Culture](https://talent.lowes.com/us/en/culture) is winning attitude + serving others. Named **values** and **Core Behaviors** are in the [2023 CR report](https://corporate.lowes.com/sites/lowes-corp/files/2024-10/Lowes_2023_CRR_Tagged.pdf) and restated in the [2024 Impact and Culture Report](https://corporate.lowes.com/sites/lowes-corp/files/2025-07/2024%20Reports/Lowes_2024_ICR_6.30.25.pdf). Map **your** stories. Official second-round tech interviews ask Core Behaviors.

| Official line | What they publish |
| --- | --- |
| **Service-minded** | Meet others’ needs |
| **Collaborative** | Combine resources and know-how |
| **Inclusive** | Welcome people and ideas |
| **Respectful** | Dignity for teammates, customers, communities |
| **Driven to win** | Be the best in the work |
| **Focus on customers** | Core Behavior — tailored value, not a catalog demo |
| **Deliver results** | Accountable through change |
| **Take action** | Urgency without theater |
| **Show courage** | Hard calls, not silence |
| **Continue learning** | Grow yourself and others (official tech page repeats this) |

“Why Lowe’s?” that only says “DIY / Charlotte / I like retail” fails. Name an **inventory, BOPIS, associate-tool, or checkout** problem. Do **not** reuse a Home Depot orange story as if it were this ticker.

## Official + reported process

**Official Technology** ([Getting Hired](https://talent.lowes.com/us/en/getting-hired) + [Technology](https://talent.lowes.com/us/en/tech)): apply (site, text `lowesjobs` to 37000, or Luci) → **30-minute** recruiter or HM phone screen → **technical assessment** (coding challenges **or** a technical project) → first-round (phone / video / onsite; experience, skills, projects) → second-round with HM / tech lead / team (**deeper technicals + Core Behaviors**) → offer + pre-employment screens + orientation.

Official **tips** for tech: show how you **break a problem down**; talk past work that proves you keep learning. Corporate (non-tech SSC) skips the assessment — do not prep the store Luci loop for an SWE req.

**SWE (CleverPrep Dec 2025 + Glassdoor, treat as reported):** ~90-minute OA (Java / OOP MCQs + a few coding problems) → live Java / Spring / HashMap internals → retail system design → manager + HR. **Ask** whether your req uses the official project **or** a timed OA. Stack on JDs: Java, Spring, microservices, sometimes GCP / Kafka.

| Stage | Official / reported |
| --- | --- |
| Apply | [talent.lowes.com](https://talent.lowes.com/us/en/tech) / Workday / Luci |
| Screen | Official 30 min recruiter or HM |
| Assessment | Official coding **or** project; CleverPrep OA is **reported** |
| Loop | Official two interview rounds; Core Behaviors on round 2 |
| Offer | Screens; Charlotte Tech Hub vs Mooresville vs site is live |

Live AI: **ask**. A take-home project is not permission to paste Copilot unseen. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md).

## How this track differs

| vs Home Depot / Walmart | vs FAANG |
| --- | --- |
| Named **values + Core Behaviors**; official tech loop includes an **assessment** | Easy–medium + **retail domain**, not contest graphs |
| Charlotte Tech Hub is the SWE gravity well | Design is **store-fulfill, inventory, associate app**, not a feed |
| Comp is retail-tech bands | “I shipped a catalog” without a **customer or associate** is weak |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** Lowe’s product team — Focus on customers when eCom inventory and the store disagreed.
2. Easy–medium array / Java collections if there is a live hour; narrate as if pairing.
3. Design: BOPIS / tool-rental hold without drowning store associates.
4. STAR: Show courage or Continue learning when a skip-test was proposed.
5. Questions: OA vs project, Charlotte days, live AI, Core Behaviors vs values.
