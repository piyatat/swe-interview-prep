# Charles Schwab engineering track

Sits beside [fidelity.md](fidelity.md) and [robinhood.md](robinhood.md): **public discount-brokerage + bank + RIA custody** (Austin / Denver / Phoenix / Westlake-class tech hubs) — not a private asset manager and not a commission-free app-only loop. Official [About](https://www.schwabjobs.com/aboutschwab): **champion individuals’ goals with passion and integrity**. Recruiter (Talent Advisor) confirms **brokerage vs bank vs advisor-platform vs infra**, Java vs .NET vs JS, hub, NERD vs experienced, and live AI.

Typical timeline **~3–5 weeks** to verbal, then **2–4 weeks** background (official How We Hire). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). SQL: [../general/sql-interviews.md](../general/sql-interviews.md). LLD: [../general/low-level-design.md](../general/low-level-design.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (four values)

Do **not** invent Amazon LPs. Official [About Us](https://www.schwabjobs.com/aboutschwab) names four values. Map **your** stories. Official interviews are **behavioral-based**: past behavior predicts future behavior; answers use **S.T.A.R.** (situation/task, action, result) — [STAR guide](https://www.schwabjobs.com/how-to-prepare-for-a-behavioral-based-interview). They want **specific, relevant, recent**.

| Official line | What they score |
| --- | --- |
| **Trust** | Ethical, empathetic, proactive client service — you named a risk |
| **Innovation** | Client-centric improvement, not a rewrite for its own sake |
| **Teamwork** | You made another Schwabbie (or analog) successful |
| **Stewardship** | Human-centric finance; you protected the brand / client, not a metric |

“Why Schwab?” that only says “Austin / disruptor / I like stocks” fails. Name a **brokerage, custody, or client-tooling** problem. Official [How We Hire](https://www.schwabjobs.com/how-we-hire): a finance degree is **not** required unless the req says so; they ask you to apply at ~90% match.

## Official + reported process

Official five steps: find fit → candidate profile → apply → interview → offer (background + drug screen where applicable). Interview: Talent Advisor phone, then HM; **count varies by team**. Official AI (How We Hire): people stay at the center of hiring decisions; application AI for brainstorm / proofread is OK if the **final voice is yours**; **do not** use AI to generate or influence answers **during interviews or assessments**.

| Stage | Official / reported |
| --- | --- |
| Apply | [schwabjobs.com](https://www.schwabjobs.com/how-we-hire) — Talent Network status is the source of truth |
| Talent Advisor | ~30 min: role, stack, pay, qualifying questions |
| Coding (guides) | TechPrep 2026: live **or** HackerRank / HireVue, 45–60 min, strings / arrays / hashmaps |
| Tech deep dive | Java / .NET / JS + **OOP pillars** + SQL; NERD / new-grad often a **panel** |
| Design (mid+) | Reported: trade ingest / Kafka / fault-tolerant money path |
| Offer | Verbal or written; then background (criminal, education, residence, credit if applicable, fingerprints, FINRA if licensed) |

Treat HackerRank vs live vs HireVue as **reported**. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md): official “no AI in the interview” is the default — confirm anyway.

New-grad tech: **NERD** (New Employee Rapid Development) is the named associate path — ask the TA; it is not the experienced loop.

## How this track differs

| vs Fidelity | vs FAANG / Robinhood |
| --- | --- |
| Official **four values + S.T.A.R.**; public broker | Easy–medium + **OOP + SQL**, not five Blind-75 hours |
| Official **no AI in live eval**; background/drug named | Design is **trades / custody**, with client-trust in v1 |
| NERD is the new-grad tech academy | Comp is public-company RSUs + bonus; ask hybrid days |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** Schwab tech org — Trust when a client-visible number and a ship date disagreed.
2. Easy–medium: first unique character / two pointers; then a SQL join.
3. OOP: interface vs abstract class; overloading vs overriding; walk a Spring / .NET piece from **your** resume.
4. Design: idempotent trade request or quote fan-in that stays correct when Kafka lags.
5. STAR: Teamwork — you changed the plan because a partner’s constraint was real.
