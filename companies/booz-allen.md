# Booz Allen Hamilton engineering track

Sits beside [leidos.md](leidos.md) and [caci.md](caci.md): **consulting + mission software** for public-sector, defense, intel, and commercial clients — not a FAANG product loop and not “just a clearance mill.” Official [Purpose and Values](https://www.boozallen.com/about/our-values-and-ethics/leading-with-purpose-and-values.html): **Empower people to change the world.** Recruiter confirms **account / customer** (DoD vs civilian vs commercial), stack (React / Java / Python / C++), site vs hybrid, and **clearance** (many SWE JDs list Secret as a basic qualification).

Typical timeline **~3–5 weeks** of active eval (Dataford). Clearance can delay start. Behavioral: [../general/behavioral.md](../general/behavioral.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (five values)

Do **not** invent Amazon LPs and do **not** treat these as a published scoring rubric. Official [Purpose and Values](https://www.boozallen.com/about/our-values-and-ethics/leading-with-purpose-and-values.html). Map **your** stories.

| Official value | What they publish |
| --- | --- |
| **Unflinching Courage** | Bold thinking; speak truth to power; conviction |
| **Ferocious Integrity** | Do right; hold yourself and each other accountable |
| **Passionate Service** | Empathy; community; **embrace the mission** |
| **Collective Ingenuity** | Resourceful; biggest difference per problem; devoted to the team |
| **Champion's Heart** | Joy in the pursuit; learn from failure; compete with passion |

“Why Booz Allen?” that only says “consulting / I want clearance” fails. Name a **mission class** (cyber, CNO, cloud modernization, modeling) and a **Ferocious Integrity / Passionate Service** story. [Life at Booz Allen](https://www.boozallen.com/careers/life-at-booz.html): SI / cyber / defense tech “in our code.”

## Official + reported process

Official [Candidate Resources](https://www.boozallen.com/careers/candidate-resources.html) is a **five-step** hire: application → review and screening → **technical assessment** (some roles; you must meet the proficiency threshold) → interviews (technical screens **and** individual or panel; virtual or in-person) → decision and offer. Official: camera **on** for virtual; they may **screenshot** to validate identity. In person: photo ID. Official sample stories: greatest challenge; technology that improved an outcome; how you chose a tool.

| Stage | Official / reported |
| --- | --- |
| Apply | [careers.boozallen.com](https://careers.boozallen.com/) |
| Recruiter | Fit, customer, **clearance**, skills-assessment requirement |
| Skills assessment | Official on many SWE JDs — **gate**, not optional homework |
| Interviews | Official combo of technical + panel; reported resume / OOP / CS more than puzzle-hard DSA |
| Offer + start | Background; clearance can **delay start** |

[../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md): **ask** live-AI rules (not a published FAQ line).

## How this track differs

| vs Leidos / CACI | vs FAANG |
| --- | --- |
| Official **five values + skills assessment**; consulting posture | Loop is **assessment + panel**, not five DSA hours |
| Design is **cleared DevSecOps / CNO / client cloud**, not a feed | You will talk to **client-facing** engineers |
| “Why BAH?” must name **mission + customer class** | Comp is contract / level bands — not public RSUs |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** Booz Allen account — Ferocious Integrity when a shortcut would hide risk.
2. Official: greatest challenge; a tool you selected and the result.
3. OOP pillars + React reconciliation **or** C++ smart pointers if the JD names them.
4. STAR: speak truth to power (Unflinching Courage) or a failure you learned from (Champion's Heart).
5. Questions: assessment vs skip, camera / ID, coding vs resume panel, live AI, clearance.
