# Honeywell Technologies engineering track

Sits beside [siemens.md](siemens.md): **pure-play automation** (buildings, industrial, process) after the **2026-06-29** Aerospace spin — not an avionics DO-178 loop and not a FAANG feed design. Official [Careers](https://www.honeywell.com/us/en/careers): *Make an impact, make real connections, make the best you*; global leader of the industrial transition **from automation to autonomy**. Recruiter confirms **Building vs Industrial vs Process Automation & Technology**, C# / Java / cloud vs embedded C, site, and OA vs live.

**Two companies now.** Official investor release (2026-06-29): remaining automation business is **Honeywell Technologies (Nasdaq: HON)**; **Honeywell Aerospace (Nasdaq: HONA)** is a separate careers / loop. Avionics / AERO JDs belong on the Aerospace site — do not reuse HON stories there. Solstice Advanced Materials (SOLS) spun earlier (2025-10) and is **not** this SWE track.

Typical timeline **~2–4 weeks** (Dataford). Embedded: [../roles/embedded.md](../roles/embedded.md). OA: [../general/online-assessments.md](../general/online-assessments.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (six behaviors)

Do **not** invent Amazon LPs. Official [Life at Honeywell](https://www.honeywell.com/us/en/careers/life-at-honeywell) — employees are **Futureshapers**. Map **your** stories.

| Official behavior | What they score |
| --- | --- |
| **Innovate and create value for customers** | Customer-eyes problem, not a demo |
| **Embrace transformation** | Digitalize / simplify; a decision from data |
| **Win together** | One Honeywell across businesses / geos |
| **Build exceptional talent** | Feedback you sought or gave |
| **Drive accountability culture** | Fearless ownership of the outcome |
| **Be courageous** | A measured risk; you owned a miss in public |

Three pillars on the same page: **Make an Impact / Make Real Connections / Make The Best You**. Integrity and ethics sit under “global mindset.”

“Why Honeywell?” that only says “Fortune 100 / aerospace / I like AI” fails — Aerospace **left**. Name a **BMS / SCADA / OT / Forge** problem you have lived.

## Official + reported process

No public numbered SWE stage list on careers. Dataford (updated 2026-10) still mixes **Aerospace Technologies** into the SWE write-up — treat stages as **reported** and **ask** which legal entity. **Ask** HackerRank vs live.

| Stage | Official / reported |
| --- | --- |
| Apply | [Careers](https://www.honeywell.com/us/en/careers) (HON). Aerospace ≠ this tenant |

| Technicals (reported) | 1–2: resume, OOP / memory, live coding or design, troubleshooting |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** Honeywell Technologies BU — customer value on an uptime miss.
2. OOP + memory (Java/C#/C++); then a medium array / graph if there is an OA.
3. Design: ingest sensor time series without losing a plant alarm.
4. Accountability + courage on the same incident (named behaviors).
5. Questions: HON vs HONA, BU, OA vs skip, live AI, hybrid.
