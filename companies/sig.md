# Susquehanna (SIG) engineering track

Sits beside [hrt.md](hrt.md) and [optiver.md](optiver.md): **market-making + decision-science SWE (Philadelphia / London / Dublin / Sydney / …)**, not HRT’s official take-home-plus-systems day and not Jane Street’s “no LeetCode / no mental math” pair loop. Official [Tech careers](https://sig.com/careers/technology/): technologists build **high-performance trading systems** with trading and quant partners. Recruiter confirms **Software Developer vs Quant Strategy Dev vs infra**, **C++ / C# / Python**, office, and AI (usually **off** unless they say otherwise).

Typical campus path is published on official-style grad JDs. Pair: [../general/pair-programming.md](../general/pair-programming.md). CS fundamentals: [../general/cs-fundamentals.md](../general/cs-fundamentals.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (six values + games)

Do **not** invent Amazon LPs. Official [Who We Are](https://sig.com/who-we-are/): founded 1987 from floor traders who used **quant skills and poker**. Strategy games and decision science are how they **teach**. Map **your** stories.

| Official value | Careers one-liner |
| --- | --- |
| **Good Decision Making** | Rigorous, analytical; reflection and practice |
| **Teamwork** | Smart people together beat the lone genius |
| **Belonging** | Ask questions; question assumptions; diversity of thought |
| **Growth Mindset** | Constantly learning; development + hard work |
| **Expertise** | Hire experts; each person can have meaningful impact |
| **Integrity** | Dependability and honesty; respect for people and work |

“Why Susquehanna?” that only says “HFT / I like poker” fails. Name a **latency, correctness, or decision-under-uncertainty** problem you have lived. Official: they are **not** a typical trading-firm costume — casual, non-hierarchical, classroom + desk for campus hires.

## Official + campus process

Campus Software Developer JDs (AU / UK / IE, 2026 cycle) publish a stage list. Experienced-hire **round list is not on the tech careers page** — ask.

| Stage | Official campus JD |
| --- | --- |
| Application | Careers / campus board |
| Online assessment | Timed coding / OA |
| Recruiter conversation | Track, office, start date |
| Technical screen | **Live coding** |
| Office interview | **Design + team fit** (in-person on many reqs) |
| Offer | Rolling campus; apply early |

London graduate posting variant: Apply → Technical Screen → Recruiter → Technical Interview → Final → Offer. Same idea, slightly different labels. Official [Tech](https://sig.com/careers/technology/) also runs **Discovery** programs as an early look at the internship interview (puzzles that emulate trading). SWE ≠ trader: trader loops add probability / games; confirm the **Software Developer** track.

## How this track differs

| vs HRT / Optiver / Jane Street | vs FAANG |
| --- | --- |
| Official **six values + game/decision culture** | Design is **trading-system + fit**, not “design Twitter” |
| Campus: OA then **live code** then **office design** | Guides: C++ / C# / Python + OOP, not olympiad graphs |
| Immediate-impact + classroom for new grads | “I only grind Blind 75 silently” misses teamwork stories |

## Coding and design flavor

Official JD skills: algorithms, data structures, **OOP** in an object-oriented language (they use C#, C++, Python). Live work: ingest, matching, risk, research ETL, low-latency connectivity. Related: [../general/low-level-design.md](../general/low-level-design.md), [../answers/system-design-metrics.md](../answers/system-design-metrics.md).

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** SIG seat (core systems vs trading-adjacent tools) — portable “I like HFT” is weak.
2. Values: a time you changed your mind after someone else’s analysis (decision making / teamwork).
3. Live coding: medium structure + edges; narrate; they score collaboration.
4. Office design: a component that must stay correct when a feed stalls.
5. Integrity: you were asked to ship without a test on a money path.
