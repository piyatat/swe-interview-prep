# Squarespace engineering track

Sits beside [webflow.md](webflow.md) and [wix.md](wix.md): **design-centric website / commerce platform** (editor, domains, payments, CDN edge), not a visual-CMS canvas and not a template marketplace. Official [Engineering careers](https://www.squarespace.com/careers/engineering): **founded and run by an engineer**; grow a large-scale architecture that serves millions while keeping a startup attitude. Recruiter confirms **frontend / backend / platform / infra / mobile / data**, Java vs JS, NYC / Dublin / Aveiro / hybrid, and take-home vs live DSA.

Official early-career loops are published. Experienced loops are **reported**. Coding: [../general/coding-patterns.md](../general/coding-patterns.md). ## Official culture (About Us)

Do **not** invent extra pillars. Official [About](https://www.squarespace.com/about/company): vision is a future where **everyone can be an entrepreneur**; design is the ultimate competitive advantage. Five published beliefs:

| Official belief | Prep one-liner |
| --- | --- |
| **Be the customer** | Empathy for a merchant / creator you would use yourself |
| **Design is not a luxury** | You shipped polish that users actually saw, not a dark-mode toggle |
| **Build the ideal** | A big bet plus the iteration after it was wrong |
| **Learn fast, act fast** | Fastest path to a measured learning, then a decision |
| **Protect creativity** | You made space for a fragile idea (Hack Week energy, not a 2% polish) |

“Why Squarespace?” that only says “I like pretty websites / NYC” fails. Name a **site editor, checkout, domain, or edge-cache** problem you have lived. Official platform note (early-career teams): Product Platform processes **1.5B+ requests/day** and ingests close to **2 TB/day**.

## Official + reported process

Official [Early Career](https://www.squarespace.com/careers/early-career) — intern and new-grad only. All interviews **virtual** (phone or Google Hangouts). Recruiter keeps you posted.

| Track | Official |
| --- | --- |
| Intern | Paid **12-week** summer, 40 h/week, Intern Lead + weekly 1:1. Loop: **take-home + technical + soft skills** (non-tech varies) |
| New grad | Full-time, salaried, discipline hire (FE/BE/…). Loop: **take-home + 3 technical**. Team placement **closer to start date**. One start date per month |

Official engineering page does **not** publish the experienced SWE loop. 2026 Glassdoor write-ups (treat as **reported**): HR screen → 60-min DSA gate → virtual loop of **DSA + system design + code review + culture/behavioral** (~1 h each). Some Aveiro / NYC loops add team match after the bar. Confirm.

## How this track differs

| vs Webflow / Wix | vs FAANG web |
| --- | --- |
| Official **design-is-not-a-luxury** + take-home on early-career | No published “GIA / written packet” |
| Design is **editor + commerce + edge**, not a social feed | Webflow Codeflow / Wix home-assignment vs **Squarespace take-home + review** |
| Founded-by-engineer craft bar | “I only grind LeetCode” misses the reported **code-review** hour |

## Coding and design flavor

Official early-career take-home is unspecified — ask what they score (correctness vs product taste). Reported experienced DSA: medium arrays / lists / LRU. Design: video upload + transcode, site publish, checkout, multi-tenant custom domains. Review: existing service, impact-first comments. Related: [../roles/frontend.md](../roles/frontend.md), [../roles/backend.md](../roles/backend.md), [../answers/system-design-video-streaming.md](../answers/system-design-video-streaming.md).

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** Squarespace surface (editor, domains, commerce, platform) — portable “I like design systems” is weak.
2. Be the customer: a merchant checkout or publish-path bug you would have hated.
3. Take-home: what you would cut if time-boxed; how you would A/B it.
4. Design: custom-domain TLS + cache invalidation when a site publishes.
5. Questions: which discipline vs team, take-home rubric, hybrid days in NYC / Dublin / Aveiro.
