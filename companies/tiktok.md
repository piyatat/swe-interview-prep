# TikTok / ByteDance engineering track

Sits beside [product-companies.md](product-companies.md): **short-video / recsys / live**, not a generic FAANG slate. Official ByteDance careers: talk to your recruiter **before** the interview so you know **that team’s** loop; an **assessment / test / task** is common for technical roles; apply on the **careers site** (no email apps). TikTok’s published culture page: mission **Inspire Creativity & Bring Joy**, plus **ByteStyle** and leadership principles.

Typical timeline **about one month** resume → offer (official FAQ; volume can stretch it). Guides often describe a **knockout** cadence (pass this round, unlock the next) rather than a single-day onsite. Confirm **TikTok vs other ByteDance product**, **level**, and AI policy.

## Official culture (ByteStyle)

ByteDance lists six **ByteStyle** values — use these, not a stale “Always Day 1 only” slogan. Do **not** recite the table; map **your** stories to the behaviors.

| Official value | Careers one-liner |
| --- | --- |
| **Always Day 1** | Entrepreneurial; agile / simple; reject complacency |
| **Inclusion** | Unique strengths; think global; assume good intent |
| **Be Candid and Clear** | Speak up; concise; data over “managing up” |
| **Seek Truth and Be Pragmatic** | Independent; first-hand facts; real impact |
| **Be Courageous** | Calculated risk / ROI; alternatives; high standards |
| **Grow Together** | Mission; resilience; mutual growth |

TikTok [Life at TikTok — philosophy](https://lifeattiktok.com/philosophy) repeats ByteStyle and adds leadership language: hire for **capabilities and potential** (not brand-name resumes), stay hands-on, no territorial ownership.

## Official process (careers FAQ)

| Official note | Takeaway |
| --- | --- |
| Process **varies by team and role** | Recruiter writes the slate — do not memorize a blog’s four-box diagram |
| Technical roles often include an **assessment, test, or task** plus several interview rounds | Treat the OA as a **hard filter** when you get one |
| Rolling; **~one month** typical | Tell them competing-offer dates early |
| Early-careers OA: pass → they invite when interviewer capacity exists (not a fixed SLA) | A silent inbox after a pass is **queue**, not always a reject |
| Reapply / sponsorship / accommodations: ask recruiter; ASL and other accomms exist | Use the careers portal status, not a third-party listing |

## How this track differs (guides; confirm)

| vs FAANG | vs NVIDIA / late-stage product |
| --- | --- |
| **Sequential** rounds (Lark / Feishu common) — one fail can stop the chain | Coding **pace** is the brand: mediums done **fast**, not a 40-minute think-aloud only |
| OA (HackerRank / CodeSignal / Nowcoder) especially **new-grad / intern** | Design frames **For You, Live, video store, notifications at burst** |
| ByteStyle hour can sink a clean code score | Experienced hires sometimes skip OA and go recruiter → live code |

Exponent: 2–3 technical hours (CoderPad / HackerRank), design for experienced, final with a senior / lead. Same-day is preferred; splitting days can lose a faster candidate. IGotAnOffer: recruiter → technical screen → virtual loop → HR → offer.

## Coding and design flavor

Problems are standard DSA in **feed / live / ranking** costume. Speed + clean code beat a clever incomplete hard. CS fundamentals (OS, networks) show up in intern writeups on the official blog.

Design: For You freshness vs latency, Live burst, multi-region video, notification fan-out. Lead with **what must stay correct under a spike**, not seven microservices. Related: [../answers/system-design-notification.md](../answers/system-design-notification.md), [../answers/system-design-video-streaming.md](../answers/system-design-video-streaming.md).

## Sample prompts (shapes, not leaked puzzles)

1. “Why TikTok / this team?” — a product or systems opinion; generic “I like short video” is weak.
2. Timed OA: 2–4 mediums; practice **with a clock**, not only untimed.
3. Live graph / DP / heap in 45 minutes; execute early.
4. Design Live or For You — consistency, fan-out, and a degraded mode.
5. ByteStyle: spoke up with data; shipped under ambiguity; taught someone across time zones.
