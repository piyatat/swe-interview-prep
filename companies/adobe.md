# Adobe engineering track

Sits beside [product-companies.md](product-companies.md): **Creative Cloud + Document Cloud + Experience Cloud + Firefly**, not a generic FAANG slate. Official [How we hire](https://careers.adobe.com/us/en/hiring-process): Talent Partner → hiring manager → **coding / system design / portfolio** for technical roles; assessments are possible. Official [AI and your hiring experience](https://careers.adobe.com/us/en/ai-and-your-hiring-experience): use AI to **sharpen** ideas, not replace your voice; **Be Genuine**; no live scribing / prompting tools unless invited. Recruiter confirms **HackerRank vs machine-coding**, **MTS level**, and AI policy (resume AI ≠ permission in the coding hour).

Typical timeline **3–6 weeks** (2026 guides). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). CS: [../general/cs-fundamentals.md](../general/cs-fundamentals.md). ## Official culture (four values)

Do **not** recite slogans. Map **your** stories. CEO memo + [Adobe for All](https://www.adobe.com/adobe-for-all.html):

| Official value | What they score |
| --- | --- |
| **Create the Future** | Customer-centric invention; unmet needs; Firefly / Creative Cloud curiosity |
| **Own the Outcome** | Bias to action; end results, not “my ticket” |
| **Raise the Bar** | First / only / best; honest about what is not working |
| **Be Genuine** | Your voice, not an LLM; inclusion + directness |

“Why Adobe?” that only says “I use Photoshop” fails. Name a **media pipeline, document collab, or responsible-AI** problem you have lived.

## Official + reported process

Official How-we-hire is the skeleton. 2026 guides (TechPrep, ClavePrep) stretch it — treat round names as **reported**.

| Stage | What they score |
| --- | --- |
| Talent Partner (official) | Fit, location, level, Firefly / product interest |
| Hiring manager (official) | Project depth; tradeoffs; Own the Outcome |
| Assessment (official: possible) | Guides: HackerRank — **2 mediums + 10–15 OS/DBMS/network MCQs** |
| Virtual loop (guides: 4–5) | Live coding, HLD (MTS-2+), LLD / machine-coding, values, director |

Guides: coding bar is **clean production code + tests**, not puzzle hardness (LRU, rain water, validate BST). Design is Adobe-shaped: asset store, transcode, Firefly API, collab document. Some loops add a **60–120 min machine-coding** mini-app (parking lot / Splitwise-shaped) — confirm.

## How this track differs

| vs FAANG | vs Figma / Intuit |
| --- | --- |
| Official **CS-fundamentals MCQs** still bite seniors | Figma: canvas / multiplayer hour; Intuit: Craft Demonstration |
| Design is **assets + docs + gen-AI**, not “design Twitter” | Same craft bar; Adobe is **suite + Firefly infra** |
| Be Genuine + no live AI overlays (official) | Pair [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md) |

## Coding and design flavor

DSA: medium arrays, trees, heaps, graphs, DP. Narrate tradeoffs before typing. LLD: classes first, working features, extensibility. Design: versioned assets, collab edit, media pipeline, autocomplete. Related: [../answers/system-design-file-storage.md](../answers/system-design-file-storage.md), [../answers/system-design-autocomplete.md](../answers/system-design-autocomplete.md), [../answers/system-design-llm-serving.md](../answers/system-design-llm-serving.md).

## Sample prompts (shapes, not leaked puzzles)

1. “Create the Future — you shipped something that was not on the roadmap.”
2. OA-style: two mediums, then explain paging vs swapping or a join vs index.
3. Machine-coding: parking-lot / logger — working path first, then extension points.
4. Design an asset library with versioning and a Firefly-style async generate job.
5. Official AI page: how you used AI to **amplify** work — and where you refused the model.
