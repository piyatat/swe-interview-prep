# Home Depot technology track

Sits beside [target.md](target.md) and [walmart.md](walmart.md): **#1 home-improvement retailer software** (store ops, supply chain, associate tools, e-commerce — official: 55% of online orders filled through a store) — not “Walmart with orange.” Official [Technology](https://careers.homedepot.com/career-areas/technology/) page: **agile, paired programming, balanced teams, customer-back** engineering; most code is written in-house. Recruiter confirms **store / supply-chain vs digital vs cybersecurity**, Java vs React / Go, Atlanta vs remote, and live AI.

Typical timeline **~1–4 weeks** (Glassdoor 2026 reports a one-week loop; treat as reported). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). Pair: [../general/pair-programming.md](../general/pair-programming.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (eight values)

Do **not** invent extra LPs. Official [Why Home Depot](https://careers.homedepot.com/about-us/): map **your** stories. Store-leader copy (~90% started hourly) is real — do not fake a store origin; a **customer-back** tech story is enough.

| Official value | What they publish |
| --- | --- |
| **Taking care of our people** | Associates first; benefits and a welcoming culture |
| **Respect for all people** | Treat people as you want to be treated |
| **Doing the right thing** | Size and footprint: every decision matters |
| **Building strong relationships** | Trust with associates, customers, communities |
| **Giving back** | Team Depot / Foundation (veterans, disaster, trades) |
| **Excellent customer service** | Help the customer finish the project |
| **Creating shareholder value** | Long-term value when the company is well run |
| **Entrepreneurial spirit** | New ideas that serve customers and grow the company |

“Why Home Depot?” that only says “I like DIY / orange” fails. Name an **inventory, store-fulfill, associate-tool, or checkout** problem you have lived.

## Official + reported process

**Official:** apply → **online assessment** (SWE II JD: ~**20 minutes**, **96-hour** window, work-style: teamwork, dependability, thoroughness, learning — **not** a LeetCode OA). [Online Assessment](https://careers.homedepot.com/online-assessment/) documents the store/supply-chain video form; technology postings still send a Workday assessment. If selected: email / phone for interviews. SWE II JD: Java preferred, SQL, microservices, CI/CD, pair with UX + PM.

**SWE (Glassdoor Sep 2026 + guides, treat as reported):** HR screen (background, auth, Atlanta vs remote, why THD) → **technical panel** (often three people, one primary) covering coding + stack (Java / Spring / React / K8s) + a retail API sketch → HM STAR vs the values. CleverPrep adds a coding OA — **ask**; do not assume it from the official 20-minute work-style test.

| Stage | Official / reported |
| --- | --- |
| Apply | [careers.homedepot.com](https://careers.homedepot.com/career-areas/technology/) / Workday |
| Assessment | Official ~20 min work-style; 96 hours |
| Recruiter / HR | Fit, site, live AI |
| Panel (guides) | Live coding + stack / API design; pair-friendly narration |
| HM | STAR vs values; non-technical stakeholders |
| Offer | Background; remote vs Atlanta is live |

Live AI: ask. Pairing is how they **write** code; that is not permission to paste Copilot in a take-home. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md).

## How this track differs

| vs Target / Walmart | vs FAANG |
| --- | --- |
| Eight **named values** + customer-back / pair | Easy–medium + **retail domain**, not contest graphs |
| Official first gate is **work-style**, not GCA | Design is **tool rental, BOPIS, associate app**, not a feed |
| Comp is retail-tech bands; Atlanta hub | “I shipped a catalog” without a **customer or associate** is weak |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** THD product team — Excellent customer service when BOPIS and store inventory disagreed.
2. Easy–medium array / SQL if there is a live coding hour; narrate as if pairing.
3. Design: tool-rental reservation or store-fulfill order without drowning associates.
4. STAR: Doing the right thing when a metric and a safety / customer outcome conflicted.
5. Questions: work-style vs coding OA, panel vs 1:1, live AI, Atlanta days.
