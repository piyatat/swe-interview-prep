# Western Digital engineering track

Sits beside [pure-storage.md](pure-storage.md) and [micron.md](micron.md): **HDD + AI-era data infrastructure** as a **standalone** storage company — not a flash-array concurrency hour and not a FAANG feed design. Official [Careers](https://www.westerndigital.com/careers): *Human Potential Meets Breakthrough Innovation*; WD is reinventing for the **AI-driven data economy**, returning to engineering / manufacturing excellence. Recruiter confirms **firmware vs host software vs test infra vs cloud tools**, C / C++ vs Python, **San Jose vs other sites**, and OA vs live.

Typical timeline **~3–5 weeks** (Dataford). Embedded: [../roles/embedded.md](../roles/embedded.md). CS: [../general/cs-fundamentals.md](../general/cs-fundamentals.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

CHRO blog (2025-06): WD stepped into a new chapter as a **standalone HDD company** and relaunched values. Dataford (2026-08) still mixes NAND / SSD prompts — treat those as **reported and possibly pre-split**. **Ask** whether the req is HDD firmware, host, or remaining flash-adjacent software.

## Official culture (five values)

Do **not** invent Amazon LPs. Official [Meet WD](https://www.westerndigital.com/careers/meet-western-digital) + [values blog](https://blog.westerndigital.com/the-power-of-culture-and-values-at-western-digital/):

| Official value | What they score |
| --- | --- |
| **Customers** | Enabling customers to succeed — a durability / latency save |
| **Results** | Progress and goals, not a demo that never shipped |
| **Connection** | One supportive team (hardware + firmware + test) |
| **Excellence** | Doing our best **and** what’s right (a quality bar you held) |
| **Innovation** | Inventing in big **and** small ways |

Employees are **Drivers**; ERGs are **Driver Resource Groups**. Official interview tips: be yourself; say **why WD**; bring questions for them.

“Why WD?” that only says “I like storage / AI data” fails. Name a **media, servo, host-stack, or reliability** problem you have lived.

## Official + reported process

Official [How We Hire](https://www.westerndigital.com/careers) is four buckets (get ready → apply → interview → hear from us) — **not** a numbered SWE stage list. Dataford fills SWE detail — treat extra OA / panel steps as **reported**. **Ask** HackerRank vs live.

| Stage | Official / reported |
| --- | --- |
| Apply | [Careers](https://www.westerndigital.com/careers); talent community; wait for recruiter contact |
| Screen (reported) | Fit, site, C vs Python, firmware vs host |
| OA / tech phone (reported) | Arrays / pointers / OS; campus often MCQ + coding |
| Technicals (reported) | C/C++ memory, linked lists, bits, storage basics |
| Panel / HM | Values + project; then offer |

**Scam line (official):** WD **never** requests payment as a condition of applying or receiving an offer. Report to Ethics Helpline or `compliance@wdc.com`.

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** WD stack (firmware vs host vs test) — a reliability miss you owned.
2. Pointers / `*p+1` vs `*(p+1)`; reverse a list; bit-mask a register.
3. HDD vs SSD architecture **only if the JD is storage-device** — do not recite NAND if the team is host software.
4. Design: stream telemetry from a drive fleet without drowning the collector.
5. Values: Excellence + Results on the same incident; questions for them (official).
