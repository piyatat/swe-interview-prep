# Cohere engineering track

Sits beside [ai-labs.md](ai-labs.md), [hugging-face.md](hugging-face.md), and [mistral.md](mistral.md): **enterprise foundation models you deploy privately** (Command / Embed / Rerank / North), not a consumer chatbot lab and not a Hub-only platform. Official [Careers](https://cohere.com/careers): “scale intelligence and serve humanity”; Toronto-founded, remote-friendly with offices in Toronto / New York / London / San Francisco / Montreal / Paris / Seoul. Recruiter confirms **SWE vs AI eng vs research vs platform**, Python / Go, and whether your loop has a take-home.

Typical timeline **~4–6 weeks** (guides; official FAQ does not pin a clock). LLM serving: [../answers/system-design-llm-serving.md](../answers/system-design-llm-serving.md). Take-homes: [../general/take-homes.md](../general/take-homes.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official hire bar (do not invent extra pillars)

Official [Careers](https://cohere.com/careers) mission + three culture lines. Map **your** stories. Official [About](https://cohere.com/about): AI should **enhance human wellbeing** and enterprise judgment — not replace it with a demo.

| Official signal | What they score |
| --- | --- |
| **Scale intelligence / serve humanity** | A shipped system that helped people do real work, not “I like LLMs” |
| **Momentum** | You moved quickly, trusted teammates, and shipped with purpose |
| **Openness** | You changed the plan after a diverse view, not a solo hero story |
| **Autonomy** | Ownership + flexibility; you delivered without a PM script |
| **Enterprise control** (product, not a fourth value) | Privacy, isolation, citations — you have lived a data-boundary problem |

“Why Cohere?” that only says “OpenAI but enterprise / Canadian” fails. Name a **RAG, rerank, private-deploy, or multi-tenant inference** problem you have lived.

## Official + reported process

Official Careers FAQ is the skeleton. 2026 guides add coding / ML-design splits — treat extra seats as **reported**.

| Stage | Official / reported |
| --- | --- |
| Application review | Official board + LinkedIn only; `@cohere.com` / `@cw.cohere` mail — they publish a scam warning |
| Recruiter | Role, site / remote, level; ask take-home vs live |
| Take-home (some roles) | Official: “you may be asked.” Guides: ~48 h exploratory notebook / demo / write-up — judgment and limits, not a puzzle |
| Hiring manager | Official next step after take-home |
| Final team interviews | Official: a few teammates; video by default, schedule-flexible |
| Offer | Equity is on Careers (“we are all co-owners”) |

Confirm AI-in-pad. Do not assume an OpenAI-style paid work trial.

## How this track differs

| vs OpenAI / Anthropic | vs Hugging Face / Mistral |
| --- | --- |
| Official **optional take-home + HM + team**; mission is **enterprise deploy** | They sell **Command / Embed / Rerank / North**, not only open weights or Hub tooling |
| Private VPC / Model Vault / data isolation is the design costume | “Why this lab” must name **retrieval + control**, not AGI slogans |
| Remote-first with listed hubs | Silent “I only grind LeetCode” misses the take-home write-up |

## Coding and design flavor

Official products: Command (generation / agents), Embed, Rerank, North (agentic workplace), Model Vault (isolated inference). Live work: RAG + citations, multi-tenant GPU SLAs, eval harnesses, noisy-neighbor isolation. Related: [../roles/data-ml.md](../roles/data-ml.md), [../answers/system-design-search.md](../answers/system-design-search.md).

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** enterprise-model company — portable “I want to work on LLMs” is weak.
2. Take-home-style: a small retrieval pipeline + what you would **not** ship.
3. Design: three tenants share GPUs — 50 ms chat, overnight embed batch, strict isolation.
4. Value: Autonomy — you owned an outcome without waiting for a spec.
5. Questions for them: take-home vs live, SWE vs AI eng, North vs model-API team, AI-in-pad.
