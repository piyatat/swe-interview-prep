# Fidelity Investments engineering track

Sits beside [schwab.md](schwab.md) and [capital-one.md](capital-one.md): **privately held asset manager + brokerage + workplace savings** (Boston HQ; Westlake / Merrimack / Durham hubs) — not a Super Day bank and not a public-brokerage NERD loop. Official [About](https://about.fidelity.com/): help customers **achieve their financial goals** and **strengthen financial wellbeing**. Recruiter confirms **workplace vs brokerage vs asset-management vs associate-facing tech**, Java / Angular vs other, hub, Leap vs experienced, and live AI.

## Official culture (no LP list)

Do **not** invent Amazon LPs. Fidelity does not publish a numbered value set. Official [About](https://about.fidelity.com/) + [Life at Fidelity](https://jobs.fidelity.com/en/life-at-fidelity/) + recruiter [interview tips](https://jobs.fidelity.com/en/life-at-fidelity/our-stories/hiring-at-fidelity/winning-interview-tips-from-a-fidelity-recruiter/) (24 Mar 2026). Map **your** stories.

| Official line | What they score |
| --- | --- |
| **Financial wellbeing** | A customer / participant outcome, not “I like fintech” |
| **People and relationships first** | Cross-team delivery; you made someone else successful |
| **Integrity** | You named a control / data issue and made it right |
| **Intelligent risk** | Founding quote: take intelligent risks rather than follow the crowd — a measured bet, not a rewrite |
| **Behavior-based stories** | Specific situation → what **you** did → result; not a slogan |

Privately held since **1946**; ~80k associates. “Why Fidelity?” that only says “Boston / stable / Magellan” fails. Name a **retirement, brokerage, workplace, or controls** problem. Official [tech careers](https://jobs.fidelity.com/en/life-at-fidelity/our-stories/tech-careers/fidelity-has-the-right-technology-role-for-you/): customer-facing **or** associate-facing; full-stack, cloud, data, quant-dev, architect.

## Official + reported process

Official [FAQs](https://jobs.fidelity.com/en/faqs/) + recruiter article: apply → recruiter screening call (role, requirements, **salary range** — they say this is not the interview) → Zoom interviews with HM, team, or a **panel**. Most interviews are **behavior-based**. “At least two rounds of face-to-face” is the FAQ default; length varies. New-grad: [Leap](https://jobs.fidelity.com/en/students/leap-program/) (SWE or systems-analyst; rotations; Boston / Durham / Merrimack / Westlake).

| Stage | Official / reported |
| --- | --- |
| Apply | [jobs.fidelity.com](https://jobs.fidelity.com/en/faqs/) — tailor the career summary (official: four sentences) |
| Recruiter | Fit, band, hub; they will tell you **which** interviews you have |
| OA (guides) | TechPrep / Dataford 2026: **HirePro or HackerRank**, ~90–120 min MCQ + 1–2 easy–medium coding; SQL shows up on many tech reqs |
| Tech | Resume + Java / Spring / SQL; mid/senior: design (retry / ledger / Kafka) |
| Panel / HM | Behavioral stories; some loops add a **business-case** (outage / constrained ship) |

Treat OA vendor and business-case as **reported**. Official FAQ on AI: **represent yourself honestly** at every stage. Some interviews use **HireVue**; they will not interview you on WhatsApp / Hangouts. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md): OA ≠ paste a model into the live hour.

## How this track differs

| vs Schwab / Capital One | vs FAANG |
| --- | --- |
| Private asset manager; official **stories**, not SBO or Power Day | Easy–medium DSA + **Java + SQL**, not olympiad graphs |
| Leap is the named new-grad tech path | Design is **retirement / brokerage / controls**, with risk in v1 |
| Recruiter screen is officially **not** the interview | Comp is cash + bonus; ask RSUs vs none |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** Fidelity tech org — Integrity when a control and a launch date disagreed.
2. Easy–medium: strings / arrays / hashmap; then a SQL join + `GROUP BY`.
3. Java: Spring vs plain, REST, idempotent post of a trade or contribution.
4. Design: retry-safe money movement or Kafka dead-letter when a downstream times out.
5. Story: people-first — you unblocked another team without becoming the hero.
