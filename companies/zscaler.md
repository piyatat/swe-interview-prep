# Zscaler engineering track

Sits beside [palo-alto.md](palo-alto.md) and [crowdstrike.md](crowdstrike.md): **zero-trust security cloud (SSE / ZIA / ZPA)**, not a NGFW/Prisma loop and not a sensor EDR loop. Official [Candidate Resource Hub](https://www.zscaler.com/candidate-resource-hub) + [Culture Framework](https://www.zscaler.com/culture) + [Ethical AI guidelines](https://www.zscaler.com/aicandidateguide) are the sources of truth. Recruiter confirms **ZIA vs ZPA vs ZDX vs platform**, language, hub (3+ office days), and whether **your** coding hour is the rare AI-on exception.

Typical official path: application → recruiter (scope, location, comp **and** culture) → manager review → structured interviews (role knowledge, cognitive ability, Ways of Working / TOPIC; HUMAN if you manage people) → decision → offer. ## Official culture (TOPIC + Ways of Working)

Do **not** invent Amazon-style extras. Official culture stack is **TOPIC values**, **HUMAN** (managers), and **Ways of Working** commitments.

| Official TOPIC value | Hub one-liner |
| --- | --- |
| **Teamwork** | Step in beyond the org chart |
| **Ownership** | Strategy **and** hands-on; unclear work still has a name on it |
| **Passion** | Mission, not a generic “I like security” |
| **Innovation** | MVPs, iterate, no-surprises urgency |
| **Customer Obsession** | Zero-trust outcome the customer feels |

Official Ways of Working: committed to the **mission**, the **outcome**, and **each other**. Behaviors they publish: flex strategy ↔ execution; trust is earned by results not title; **challenge culture** — clarity over comfort, then disagree-and-commit. “Why Zscaler?” that only says “zero trust / SSE leader” fails. Name a **proxy, identity-aware access, or inspection-at-scale** problem you have lived.

Official hybrid: teams plan **3+ office days** per week. Confirm the hub.

## Official AI policy (do not guess)

Official [candidate AI guide](https://www.zscaler.com/aicandidateguide). Prep is encouraged. **Live evaluation is unaided** unless they write otherwise.

| Stage | Official allowed | Official not allowed |
| --- | --- | --- |
| Application | Grammar / clarity on a **true** resume | Invent skills; AI-hallucinated history |
| Prep | Research, mocks, questions for them | Scripts you will read live |
| Live interview | Camera on (unless accommodation) | Any real-time AI / copilot / notes-bot |
| Take-home | Research / brainstorm; AI for **core** work only if instructions say so | Generate the analysis or final solution |
| Live coding | **Off by default**; recruiter/interviewer must opt in | Hidden model in the pad |

Official: impersonation, plagiarism, and unauthorized help can kill the loop **or a later offer**.

## Official process

Official candidate hub. Quantity of interviewers **varies** — recruiter outlines yours.

| Stage | Official |
| --- | --- |
| Application | Impact + data; ambiguous problems; collaboration; growth/ownership |
| Recruiter | Role, location, comp band; they expect you have read Ways of Working |
| Manager review | Hiring manager sees the packet before the loop |
| Interviews | Structured: role knowledge, general cognitive ability, TOPIC / WoW; HUMAN if people-manager |
| Decision / offer | Recruiter updates either way; benefits walkthrough with the offer |

Guides / reports (Staff SDE, May 2026): treat round *counts* (DSA, LLD, values hour of **hypothetical** staff scoping) as **reported**. Senior loops may ask how you use AI **at work** while still banning it **in the pad**.

## How this track differs

| vs Palo Alto / CrowdStrike | vs FAANG |
| --- | --- |
| Official **TOPIC + HUMAN + WoW** and a written **AI-off** eval | Design is **inline inspect / ZTNA / identity**, not “design Twitter” |
| Hybrid **3+ planned office days** | Values hour can be hypothetical staff scoping, not only STAR |
| Cloud SSE, not a box or a sensor | “I only grind hards” misses ownership / challenge-culture stories |

## Coding and design flavor

Official “role-required knowledge” is the posting: protocols, distributed policy, data path. Live coding is **your** problem-solving, default unaided. Design: policy evaluation at the edge, log/telemetry without drowning analysts, identity-aware access. Related: [../answers/system-design-rate-limiter.md](../answers/system-design-rate-limiter.md), [../answers/system-design-metrics.md](../answers/system-design-metrics.md).

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** zero-trust cloud — a time you chose customer isolation over a shortcut.
2. Coding: medium unaided; narrate; no copilot unless they said yes.
3. Design: inspect / connect millions of sessions without becoming the outage.
4. TOPIC: challenge culture — you gave direct feedback, then committed.
5. Questions: ZIA vs ZPA, hub days, AI-in-pad exception.
