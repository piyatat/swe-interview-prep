# Autodesk engineering track

Sits beside [adobe.md](adobe.md) and [product-companies.md](product-companies.md): **Design and Make Platform** (AutoCAD, Revit, Fusion, Maya, construction / manufacturing clouds), not a generic FAANG slate. Official [Careers FAQ](https://www.autodesk.com/careers/faq) is the hire-process source of truth. Official purpose: a better world **designed and made for all**. Recruiter confirms **desktop product vs cloud platform**, language (C++ vs C# vs TypeScript), Office / Hybrid / Home-Based, and **AI-in-pad**.

Typical timeline **3–5 weeks** (guides + reports). CAD / scene graphs: [../general/low-level-design.md](../general/low-level-design.md). Cloud services: [../general/system-design.md](../general/system-design.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (One ORBIT)

Do **not** recite the acronym. Map **your** stories. Official [Culture](https://www.autodesk.com/company/culture): **One Autodesk** plus five values.

| Official value | Culture one-liner |
| --- | --- |
| **Optimism** | Believe in better; resilient, timely feedback |
| **Relentless** | Accountability, execution, urgency; take customer problems as your own |
| **Brave** | Calculated risks; hard conversations; lead customers through uncertainty |
| **Ingenious** | Curious, experimental; unlock customer ingenuity |
| **Trusted** | Reliable, transparent, ethical; secure customer experience |

Official FAQ work types: **Office-Based**, **Hybrid** (no company-wide day count — team sets it), **Home-Based**. “Why Autodesk?” that only says “I used AutoCAD in school” fails. Name a **geometry, BIM, CAM, or collaboration** problem you have lived.

## Official + reported process

Official [FAQ](https://www.autodesk.com/careers/faq): recruiter → hiring manager → optional **functional assessment** → interview team, typically **3–4** people. Timing varies by role and location. Official AI rule: prepare with tools; **live interviews and assessments are unaided** unless they tell you otherwise. 2026 guides (Dataford, ClavePrep) + candidate reports — treat round *contents* as **reported**.

| Stage | Official / reported |
| --- | --- |
| Apply | Official: up to **5** roles per session; recruiters still decide who advances |
| Recruiter | Official first meeting; JD + resume; work type |
| Hiring manager | Official second meeting; scope, level, team |
| Functional assessment | Official, role-dependent: OA / take-home / live coding |
| Team loop | Official 3–4 people. Guides: coding, design or domain, behavioral |
| Feedback | Official: status update; **not** typically a detailed debrief |

Official recruiter [interview tips](https://blogs.autodesk.com/autodesk-life/inside-autodesk/interview-tips/): balance **we** (collaboration) and **me** (your decisions); pick **recent + relevant** stories, not only your proudest. Internship recruiting is typically **fall (Sep–Nov)** and **spring (Feb–Apr)** (FAQ).

## How this track differs

| vs Adobe / creative cloud | vs FAANG |
| --- | --- |
| **Design and Make** users (AEC, manufacturing, M&E) | Official **no live AI** unless invited |
| Desktop kernels + cloud collaboration on one platform | Official HM **before** the 3–4 person team |
| One ORBIT, not LP / Googleyness | Hybrid days are **team-owned**, not a 3-day mandate |

## Coding and design flavor

DSA: trees (scene / assembly), intervals (timelines), graphs, practical parse / merge. Design: model sync, versioned drawings, large-file upload, permissioned project hubs. Related: [../answers/system-design-file-storage.md](../answers/system-design-file-storage.md), [../answers/system-design-collab-editor.md](../answers/system-design-collab-editor.md).

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** product line — BIM clash, CAM toolpath, or cloud collaborate — not “I like design software.”
2. Live: medium + a tree / nested-structure follow-up; narrate before you type.
3. Design: versioned drawings across offices — conflict, permissions, huge binaries.
4. STAR: a calculated risk (Brave) where **you** owned the call inside a “we.”
5. Questions for them: desktop vs cloud on *this* team, hybrid days, assessment type.
