# Northrop Grumman engineering track

Sits beside [lockheed-martin.md](lockheed-martin.md) and [anduril.md](anduril.md): **prime contractor software** (air / cyber / land / sea / space), not a FAANG feed and not Lattice-pace defense-startup. Official [Careers](https://www.northropgrumman.com/careers): ~100k people; **Defining Possible**. Recruiter confirms **sector + program** (B-21 vs Sentinel vs space / mission systems), C++ vs Java vs embedded, site, and **clearance / US-person** on the req.

Typical timeline **~3–5 weeks** to offer (Dataford); **clearance** can delay start. Embedded: [../roles/embedded.md](../roles/embedded.md). Behavioral: [../general/behavioral.md](../general/behavioral.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (four values)

Do **not** invent Amazon LPs. Official [Values](https://www.northropgrumman.com/who-we-are/our-values). Map **your** stories.

| Official language | What they score |
| --- | --- |
| **We Do the Right Thing** | Ethics / integrity over shipping a defect |
| **We Do What We Promise** | You owned delivery and quality, not a slide |
| **We Commit to Shared Success** | Mission + teammates; integrity not sacrificed for a date |
| **We Pioneer** | Curiosity on a hard problem — not “I like defense” |

“Why Northrop?” that only says “B-21 / space / I like aerospace” fails. Name a **sector or program** and a **reliability / ethics** story.

## Official + reported process

Official [Our Hiring Process](https://www.northropgrumman.com/careers/our-hiring-process): apply (Job Hub) → application review → recruiter **phone screen** → interviews with team / HM / leadership → offer (Workday portal) → pre-onboarding (**background, drug screen, clearance verification**). Official [Interviewing Essentials](https://www.northropgrumman.com/careers/interviewing-essentials): **STAR**, research mission / values / businesses, business attire even on video. **Ask** coding vs panel-only.

| Stage | Official / reported |
| --- | --- |
| Apply | [Careers](https://www.northropgrumman.com/careers) / Job Hub |
| Recruiter screen | Fit, site, **clearance / citizenship**, program |
| Interview (reported) | Often **one** 30–60 min HM or 2–5 person panel: resume, OOP / C++, STAR. Live coding **uncommon** |
| Offer + start | Drug screen + background; clearance can **delay start** |

**Official AI line:** hiring-process page — resume format / practice OK; **no** invented experience, **no** real-time AI in the interview, **no** recording / transcription. Same “AI is not allowed” line on Interviewing Essentials. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md).

## How this track differs

| vs Lockheed / Anduril | vs FAANG |
| --- | --- |
| Official **four values** + STAR essentials page | Loop is often **one panel**, not five DSA hours |
| Design is **mission system / radar / C2 / space**, not a social feed | Clearance / ITAR is a **gate**, not a footnote |
| “Why NG?” must name **sector + program** | Comp is program bands + benefits — not public RSUs |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** sector / program — Do the Right Thing on a safety or integrity miss.
2. OOP pillars + pointer vs reference + stack vs heap if the JD is C++.
3. Design: ingest sensor / vehicle telemetry without dropping a track.
4. STAR: conflict or a missed date mapped to **Shared Success / Do What We Promise**.
5. Questions: clearance timeline, coding vs panel, live AI (official no), hybrid vs program site.
