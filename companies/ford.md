# Ford Motor Company engineering track

Sits beside [gm.md](gm.md) and [tesla.md](tesla.md): **Ford Blue / Model e / Ford Pro software** (connected vehicle, OTA, fleet / commercial tools) — not a generic “auto OEM” loop. Official purpose: **help build a better world, where every person is free to move and pursue their dreams**. Recruiter confirms **Blue vs Model e vs Pro vs digital platforms**, Java / Spring vs Python / cloud, Dearborn vs other sites, and live AI.

Typical timeline **~3–5 rounds, often remote** (TechPrep 2026). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). ## Official culture (purpose + Ford+)

Ford does **not** publish Amazon-style LPs on the careers site. Use official language, then map **your** stories.

| Official line | What they score |
| --- | --- |
| **Purpose** ([Ford Purpose](https://corporate.ford.com/microsites/our-purpose/index.html)) | Move people; do the right thing, not the easy thing |
| **Ford+ plan** (2026 integrated report) | Blue (ICE trucks), Model e (EV + digital), **Ford Pro** (fleet software / services) — name **one** |
| **People & culture** ([Life at Ford](https://www.careers.ford.com/en/people-culture)) | Collaborate to solve real problems; build what matters |
| **How we hire** ([FAQs](https://www.careers.ford.com/en/faqs)) | **People hire people** — AI may sort applications; humans make the offer |

2026 report: software and services capability is growing, **led by Ford Pro**; new Dearborn HQ is framed as a software-and-technology campus. “Why Ford?” that only says “F-150 / Mustang” fails. Name an **OTA, telematics, uptime, or dealer/fleet** problem.

## Official + reported process

Official [FAQs](https://www.careers.ford.com/en/faqs): apply at [careers.ford.com](https://www.careers.ford.com/en/); recruiters mail from **@ford.com**; **no fee**; AI tools may organize applications but **do not auto-reject** without a human and **do not make the hire**. Resume AI polish is allowed if the page stays truthful. They do **not** publish round names.

| Stage | Official / reported |
| --- | --- |
| Apply | careers.ford.com — posting lists on-site / hybrid / remote |
| Recruiter | Why Ford, resume, site, visa (US postings say sponsorship or not) |
| Tech screen (guides) | HackerRank **or** live 45–60 min; easy–medium arrays / lists / intervals |
| Pair / deep dive (guides) | 60–90 min: small **REST / CRUD** feature, error handling, sometimes a code review |
| Design (some SWE) | Connected-vehicle / inventory / logging — tradeoffs out loud |
| HM / behavioral | STAR: conflict, learning a stack, pushback on a design |
| Offer | Some roles: pre-employment drug screen (official) |

Treat HackerRank vs pair vs onsite as **reported**. 2026 Glassdoor: some loops are **three remote hours** (recruiter + tech lead + team coding), not a six-round FAANG day.

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** Ford segment — Pro uptime vs Model e digital experience.
2. Merge intervals / reverse a list / palindrome check if there is an OA; then a small REST handler.
3. Design: OTA campaign with canaries, or fleet telematics without drowning on-call.
4. STAR: you simplified a process (waste) without breaking a plant / dealer partner.
5. Questions: HackerRank vs pair, live AI, Java vs other, Blue vs Pro, site.
