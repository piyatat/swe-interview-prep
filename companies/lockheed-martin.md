# Lockheed Martin engineering track

Sits beside [anduril.md](anduril.md) and [spacex.md](spacex.md): **prime contractor software** (Aeronautics / Missiles and Fire Control / Rotary and Mission Systems / Space), not a FAANG feed and not Lattice-pace defense-startup. Official [Who we are](https://www.lockheedmartin.com/en-us/who-we-are.html): defense tech that helps customers **keep people safe**; ~121k employees; **one in five veterans**. Recruiter confirms **business area + program** (F-35 vs Sikorsky vs space / cyber), C++ vs Java, site vs telework, and **clearance / US-person** on the req.

Typical timeline **~3–5 weeks** to offer (Dataford); **clearance** can add ~**3 months** before start (official guide). Embedded: [../roles/embedded.md](../roles/embedded.md). Behavioral: [../general/behavioral.md](../general/behavioral.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (three values)

Do **not** invent Amazon LPs. Official [Who we are](https://www.lockheedmartin.com/en-us/who-we-are.html) + [Why LM](https://www.lockheedmartin.com/en-us/careers/why-lm.html). Map **your** stories.

| Official language | What they score |
| --- | --- |
| **Do What’s Right** | Ethical call when shipping faster would hide a defect |
| **Respect Others** | Talent / expertise of the team — not a lone-hero story |
| **Perform With Excellence** | Mission trust: you named the bar and met it |
| **Collaborate to Win** (careers) | Cross-program / discipline; One Lockheed Martin |
| **Accelerate Change** (careers) | Urgency with a decision you owned |
| **Hear and Be Heard** (careers) | You spoke up; you also listened |

“Why Lockheed?” that only says “defense / F-35 / I like aerospace” fails. Name a **program or BA** (air dominance vs rotary vs missile defense vs space) and a **reliability** story.

## Official + reported process

Official [Interview Guide (PDF)](https://www.lockheedmartin.com/content/dam/lockheed-martin/careers/hiring-process/interview-guide.pdf): apply → recruiter arranges **in-person / phone / video** tailored to the role → offer → **background check + drug screen**; clearance verified with DCSA when the req needs it. **Ask** HackerRank vs panel-only.

| Stage | Official / reported |
| --- | --- |
| Apply | [Careers](https://www.lockheedmartin.com/en-us/careers/index.html) / lockheedmartinjobs |
| Recruiter | Fit, site, **clearance / citizenship**, BA |
| Panel (reported) | Often **one** 45–60 min Teams panel: STAR + OOP / CS; some teams add coding or a second hour |
| Offer + start | Drug screen + background; clearance can **delay start**, not always the loop |

Official STAR examples in the PDF: team goal, unexpected problem, took the lead, conflict, change, competing priorities, new idea, customer need. Pair: [../general/cs-fundamentals.md](../general/cs-fundamentals.md).

**Official AI line (same PDF):** they embrace AI in the work, but **limit AI during the interview** so the team sees *your* skills. Accessibility is separate — ask. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md).

## How this track differs

| vs Anduril / SpaceX | vs FAANG |
| --- | --- |
| Official **three values + STAR PDF**; classified programs | Loop is often **one panel**, not five DSA hours |
| Design is **mission system / avionics / C2**, not a social feed | Clearance / ITAR is a **gate**, not a footnote |
| “Why LM?” must name **BA + program**, not “defense is cool” | Comp is GS-like bands + AIP — not public RSUs |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** BA / program — Do What’s Right on a safety or integrity miss.
2. OOP pillars + stack vs heap; `volatile` / deadlock if the JD is embedded.
3. Design: ingest radar / vehicle telemetry without dropping a track.
4. STAR: conflict or change mapped to **Respect Others / Hear and Be Heard**.
5. Questions: clearance timeline, coding vs panel, AI-off (official), hybrid vs program site.
