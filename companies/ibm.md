# IBM engineering track

Sits beside [cisco.md](cisco.md) and [oracle.md](oracle.md): **hybrid cloud, watsonx, z/mainframe, consulting-adjacent product**, not a consumer social loop. Official [application process](https://www.ibm.com/careers/application-process): apply → screen → optional assessments → interview / assessment center → decision. Recruiter confirms **Software vs Consulting vs Infrastructure**, **HackerRank vs video vs IPAT**, Java vs Python, and **AI policy** for *your* assessment.

Typical timeline **varies by country** (official: they will not quote one clock). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). ## Official culture (three values)

Do **not** invent extra pillars. Official [Culture](https://www.ibm.com/careers/culture):

| Official value | What they score |
| --- | --- |
| **Dedication to every client’s success** | Outcome with a denominator; you talked to the user of the code |
| **Innovation that matters** | Useful change for IBM **and** the world — not novelty for its own sake |
| **Trust and personal responsibility** | Own misses; no silent risk; relationships you can name |

Official entry-level blog: they want **technical leaders who still meet customers**. “Why IBM?” that only says “Watson / they are stable” fails. Name a **client, hybrid-cloud, or reliability** problem you have lived.

## Official AI policy (do not guess)

Official application-process page, “Acceptable Use of AI by Candidates”:

| Allowed | Not allowed |
| --- | --- |
| Grammar / tone on resume; summarize **your** achievements | Generate a whole resume/cover or **invent** experience |
| Prep: research, STAR practice, questions for them | Complete **assessments / coding challenges** with a model |
| Learn a concept; disclose **significant** AI help on submitted materials | Live interview copilot; rewrite a take-home so it “looks like you” |

Official: IBM does **not** use NYC LL144 automated employment-decision tools (they say they reassess). Recruiters email from **`@ibm.com`**, not Gmail.

## Official + reported process

Official entry-level developer blog lists: CV screen → online coding assessment → recruiter screen → technical interview → behavioral with **upline management**. Official process page adds optional **video** and **English** assessments; some regions use an assessment center.

| Stage | What they score |
| --- | --- |
| Application / screen (official) | Portal status; “No Longer Under Consideration” right after apply usually means **min quals** |
| Coding assessment (official) | MCQ **or** coding; they explicitly point candidates at LeetCode / HackerRank / Pramp |
| Video / recorded (official option; guides: ~5 prompts) | STAR, ~3 min; client + trust stories |
| Recruiter (official blog) | Fit, logistics |
| Technical (official + guides: 45–60 min, 1–2) | Easy–medium DSA, OOP / OS / SQL, **resume** projects; explain the miss |
| Managerial (official) | Who you are; deadlines; collaboration |

2026 guides (TechPrep): HackerRank 60–90 min, 1–2 array/string problems; mid-senior may see URL shortener / crawler / chat. Treat vendor and counts as **reported**.

## How this track differs

| vs Cisco / Oracle | vs FAANG |
| --- | --- |
| Official **written** AI rules + client-facing bar | Fundamentals + **SQL / OOP** over olympiad graphs |
| Product **and** consulting loops share values | “How does the **customer** use this?” is a real probe |
| Recorded video hour is common in some geos | Design appears mainly **mid-senior** |

## Coding and design flavor

OA / live: arrays, strings, Two Sum family, palindromes, reverse list, [coding-subarray-sum-k.md](../answers/coding-subarray-sum-k.md). LLD: parking lot, vending machine. HLD (senior): shortener, crawler, messaging. Talk **clean names, edges, REST vs what you actually shipped**. Related: [../answers/system-design-url-shortener.md](../answers/system-design-url-shortener.md), [../general/low-level-design.md](../general/low-level-design.md).

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** IBM unit (watsonx, z, Cloud, Consulting) — portable “I like AI” is weak.
2. OA: one or two mediums; narrate as if they will read the replay.
3. Tech: a miss you would look up — official blog **wants** that honesty.
4. Design (senior): shortener or notify with **client** SLAs.
5. Client success: you changed the design after sitting with the user.
