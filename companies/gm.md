# General Motors engineering track

Sits beside [tesla.md](tesla.md) and [ford.md](ford.md): **OEM vehicle / connected software** (Ultifi-class OTA, infotainment, controls, enterprise IT) — not a FAANG feed and not “Tesla but Detroit.” Official [How We Hire](https://search-careers.gm.com/en/how-we-hire/): apply → optional assessment → competency interview → offer + drug screen / background. Recruiter confirms **vehicle software vs cloud / data vs embedded / controls**, C++ / Python / Java, Warren vs remote, and live AI.

Typical timeline **~3–5 weeks** (guides; campus can stretch). Coding: [../general/coding-patterns.md](../general/coding-patterns.md). Embedded: [../roles/embedded.md](../roles/embedded.md). Comp: [../general/offer-negotiation.md](../general/offer-negotiation.md).

## Official culture (values + behaviors)

Do **not** invent Amazon LPs. Official [How We Evaluate Talent](https://search-careers.gm.com/en/how-we-hire/): interviews score **skills, knowledge, values, and behaviors**. Use **STAR** with job-related examples. Map **your** stories.

| Official value | What they score |
| --- | --- |
| **Customers** | Every interaction; put the driver / dealer at the center |
| **Excellence** | Ingenuity + tenacity to win, not slide-deck innovation |
| **Relationships** | Inside and outside GM; you unblocked a partner |
| **Truth** | Facts over assumptions; you challenged a plan with data |

Official behaviors (same page): **Win with Integrity**, **Commit to Customers**, **Innovate and Embrace Change**, **Speak Fearlessly**, **Move with Urgency**, **Be Inclusive**, **Lead as One Team**, **Own the Outcome**. Safety is named under integrity — vehicle software is not a toy CRUD app.

“Why GM?” that only says “I like cars / EVs” fails. Name an **OTA, telemetry, safety, or dealer/customer** problem you have lived.

## Official + reported process

Official skeleton is four steps; they say it generally takes **a couple of weeks** application → offer and that process **differs by role**. Workday candidate home is the status source. Ev-e schedules many interviews.

| Stage | Official / reported |
| --- | --- |
| Apply | [search-careers.gm.com](https://search-careers.gm.com/en/how-we-hire/) / Workday |
| Assess (some roles) | Official: optional qualification assessment. SWE guides: **Codility** or HireVue/CodeVue, ~2 easy–medium tasks, AI-off in the OA tab |
| Recruiter / HM | Resume, site, stack; some teams HM-early |
| Loop (guides) | Live coding + resume systems + STAR vs values/behaviors; senior reports add design + a “power day” |
| Offer | Drug screen + background (official) |

Treat vendor, round count, and Codility clock as **reported** — ask. LockedIn / Dataford (2026): live AI often **off** in the interview even if Copilot is used on the job. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md).

## How this track differs

| vs Tesla / Rivian | vs FAANG |
| --- | --- |
| Official **four values + eight behaviors** and STAR as the default hour | Medium DSA + **vehicle / OTA / CAN-adjacent** design, not olympiad graphs |
| Union / manufacturing context sits next to the software org | OA is **Codility-class**, not a five-hour Blind-75 gauntlet |
| Comp is OEM bands + bonus; site (Warren / Milford / remote) is live | Safety and Own-the-Outcome stories beat “I shipped a feed” |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** GM org — Truth when telemetry disagreed with a launch date.
2. Easy–medium array / grid / two pointers if there is a Codility; narrate tests.
3. Design: staged **OTA** with canaries, rollback, and a safety hold.
4. STAR: Speak Fearlessly when you stopped a merge that would have shipped a bad calibration.
5. Questions: Codility vs skip, live AI, C++ vs Python, vehicle vs IT org, site.
