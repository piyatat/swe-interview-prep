# Johnson & Johnson engineering track

Sits beside [medtronic.md](medtronic.md), [abbott.md](abbott.md), and [ge-healthcare.md](ge-healthcare.md): **MedTech + Innovative Medicine software** (NYSE: JNJ) — **not** Kenvue (consumer-health spin). Official [Our Credo](https://www.jnj.com/our-credo) (1943): first responsibility is to **patients, doctors, and nurses**. Recruiter confirms **MedTech (robotics / vision / surgery) vs Innovative Medicine vs enterprise digital**, C++ / LabVIEW vs Java / cloud, site, and live AI.

Typical timeline **~4–6 weeks** (Dataford 2026; treat OA / HireVue / panel counts as **reported**). Embedded: [../roles/embedded.md](../roles/embedded.md). ## Official culture (Our Credo)

Do **not** invent Amazon LPs. Official Credo is four **responsibilities**, in order. Map **your** stories. Quality and patient-trust beat “we shipped Friday.”

| Official line | What they publish |
| --- | --- |
| **Patients, doctors, nurses** | First responsibility — high quality, reasonable prices |
| **Employees** | Inclusive workplace; each person as an individual |
| **Communities / world** | Better access and care; good citizenship |
| **Stockholders** | Sound profit **after** the first three |
| **Fair hiring** | Official: Credo-guided, competency questions, trained interviewers |

Official [How we hire](https://www.careers.jnj.com/en/how-we-hire/) + [Inclusion](https://www.careers.jnj.com/en/life-at-jj/inclusion/): digital interviews; behavioral / competency questions aligned to the role; diverse panels trained in fair hiring. Official first-round tips: stay **positive**, bring ideas, ask questions, rehearse STAR **without** a script, and know **Our Credo** before you talk.

“Why J&J?” that only says “healthcare / Credo / New Brunswick” fails. Name a **patient-quality, device, or regulated-platform** problem you have lived. Do **not** reuse a Medtronic Mission tenet as if it were this company.

## Official + reported process

**Official** (How we hire): explore → apply → **digital interview** (pre-recorded ~10 min, up to two re-records, **or** live video 30–60 min) → offer letter. Reasonable accommodations are a published Credo duty.

**SWE (Dataford / Glassdoor 2026, treat as reported):** recruiter or automated assessment → on-demand HireVue / behavioral → technical (Java / SQL / DSA / resume systems, sometimes OA) → panel or Super Day. MedTech reqs look more like C++ / RTOS / V&V; digital platforms more like Spring + microservices. **Ask** which.

| Stage | Official / reported |
| --- | --- |
| Apply | [careers.jnj.com](https://www.careers.jnj.com/en/) |
| Screen | Official digital (pre-record **or** live); reported OA / HireVue |
| Technical | Reported coding, SQL, or project architecture |
| Loop | Reported HM + panel; Credo behavioral |
| Offer | Official offer letter with benefits |

Live AI: **ask**. A regulated product is a reason many teams keep the pad AI-off even if Copilot is used on the job. [../general/ai-assisted-rounds.md](../general/ai-assisted-rounds.md).

## How this track differs

| vs Medtronic / Abbott | vs FAANG |
| --- | --- |
| **Credo order** (patients first), not six Mission tenets or four Abbott values | Medium DSA on some loops; **quality / ethics** stories are first-class |
| MedTech **and** Innovative Medicine sit in one ticker | Design is **device / trial / hospital workflow**, not a feed |
| Comp is diversified-health bands; site vs hybrid is live | Speed without a verification story reads as a miss |

## Sample prompts (shapes, not leaked puzzles)

1. Why **this** J&J org — Credo when a date and a quality hold collided.
2. Official first-round: a solution you would bring, not a complaint about a prior boss.
3. Easy–medium coding or SQL if digital; C / RTOS if MedTech firmware.
4. Design: surgical / vision / trial data with checksums, hold-and-release, and audit trail.
5. Questions: MedTech vs IM vs digital, live AI, pre-record vs live, onsite days.
