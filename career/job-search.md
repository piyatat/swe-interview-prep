# Job search cadence

Treat search like a product: **pipeline metrics**, weekly review, and a fixed prep budget so applications don’t crowd out interview skill.

## Pipeline stages

`Sourced → Applied → Recruiter screen → Tech loop → Offer → Decide`

Track company, role, level, source (referral / HM / job board), next action, and date.

## Weekly cadence (example)

| Block | Time | Focus |
| --- | --- | --- |
| Sourced + outreach | 3–5 hrs | Referrals, HM notes ([linkedin-and-outreach.md](linkedin-and-outreach.md)) |
| Applications | 2–4 hrs | Tailored resume; quality over spray |
| Interview prep | 8–12 hrs | Coding / design / behavioral ([general/prep-plan.md](../general/prep-plan.md)) |
| Review | 30–60 min | Conversion rates; kill weak funnels |

Adjust ratios for timeline: **interviewing soon** → more prep; **pipeline empty** → more sourcing.

## Sourcing mix

| Source | When it shines |
| --- | --- |
| Referrals / warm intros | Always prioritize |
| Direct HM / team pages | Startups & mid-size |
| Recruiter inbound | Filter for level + loop clarity |
| Job boards | Volume filler; tailor top matches |

Pair company type with [companies/comparison.md](../companies/comparison.md).

## Conversion health (rough)

If **Applied → screen** is very low: resume/targeting.  
If **Screen → loop** stalls: story and level clarity.  
If **Loop → offer** stalls: technical depth or behavioral signal — drill with `answers/` and mocks.

## Constraints to decide up front

- Location / remote policy  
- Visa / work auth  
- Comp floor (private note; not in public repo)  
- Stack must-haves vs nice-to-haves  
- Big-tech vs startup mix  

## Checklist

- [ ] Target role + level written down ([leveling.md](leveling.md))  
- [ ] Resume + LinkedIn aligned  
- [ ] Tracker exists (sheet or tool)  
- [ ] Weekly prep hours protected  
- [ ] Next 5 outreach targets listed
