# Career track

Job-search and career growth notes that sit **beside** interview prep. Use with the project skill **`swe-career-advisor`**.

## Suggested order

1. Clarify **role + level + company type** ([leveling.md](leveling.md)).
2. Fix the **resume** ([resume.md](resume.md)) and **LinkedIn/outreach** ([linkedin-and-outreach.md](linkedin-and-outreach.md)).
3. Run a **search cadence** ([job-search.md](job-search.md)) while following [general/prep-plan.md](../general/prep-plan.md).
4. Before offers: [negotiation.md](negotiation.md) + [offers.md](offers.md).
5. On the job: [growth.md](growth.md).

Interview loops and answer outlines stay under [`general/`](../general/), [`roles/`](../roles/), [`companies/`](../companies/), and [`answers/`](../answers/).
