# Practice platforms

## Coding (DSA)

| Platform | Best for | Notes |
| --- | --- | --- |
| [LeetCode](https://leetcode.com/) | Volume, company tags, contests | Focus mediums; narrate while solving |
| [NeetCode](https://neetcode.io/) | Curated 150 / roadmap videos | Pattern-first order |
| [Grind 75](https://www.techinterviewhandbook.org/grind75) | Time-boxed list | Adjustable weekly hours |
| [HackerRank](https://www.hackerrank.com/) | Fundamentals, SQL | Good for beginner drills |
| [Codeforces / AtCoder](https://codeforces.com/) | Competitive stretch | Optional for strong algorithm signal |
