# Prep plan (4–6 weeks)

A balanced schedule for a typical SWE loop: coding, system design (mid+), behavioral, CS fundamentals, and (in 2026) possible AI-assisted rounds.

## Typical loop shape

| Stage | What it tests |
| --- | --- |
| Recruiter / HM screen | Fit, scope, communication |
| Technical phone | 1–2 coding problems, sometimes fundamentals |
| Onsite / virtual loop | 2–4 coding, 1–2 system design, 1–2 behavioral |
| Bar raiser / leadership | Judgment, ownership (senior+) |

Junior loops weight **coding + fundamentals** more. Senior loops weight **system design + behavioral** more; coding still matters but depth shifts to tradeoffs and production judgment.

## 4-week intensive (2–3 h/day)

| Week | Focus | Deliverables |
| --- | --- | --- |
| **1** | Arrays, strings, hash maps, two pointers, sliding window, stacks/queues | 15–20 mediums; explain complexity aloud |
| **2** | Trees, graphs, BFS/DFS, heaps, intervals, binary search, recursion | Timed sets; log mistakes in a personal bank |
| **3** | System design framework + 4 classic prompts; STAR story bank (8–10) | 2 spoken design mocks; rehearse stories |
| **4** | Mixed retakes, company research, mocks | 3+ full mock interviews; light new problems only |

## 6-week steady (1–2 h/day)

- Weeks 1–2: patterns ([coding-patterns.md](coding-patterns.md))
- Week 3: CS fundamentals ([cs-fundamentals.md](cs-fundamentals.md))
- Week 4: system design ([system-design.md](system-design.md))
- Week 5: behavioral + role pack ([../roles/](../roles/))
- Week 6: mocks + AI-assisted prep if target company uses it ([ai-assisted-rounds.md](ai-assisted-rounds.md))

## Daily habit (45–90 min)

1. **One timed problem** — narrate approach before coding.
2. **One retake or design sketch** — alternate days.
3. **One STAR story aloud** — 2 min, record yourself weekly.

## Pre-interview checklist (48 h before)

- [ ] 8–10 STAR stories mapped to themes (conflict, failure, leadership, deadline)
- [ ] 2 system design prompts walked through with estimations
- [ ] Language/runtime quirks refreshed (your primary stack)
- [ ] Questions for interviewers written down
- [ ] Recruiter clarity: AI-tool policy, take-home vs live, round types

## Common failure modes

- **Volume without narration** — recognition ≠ interview fluency.
- **Skipping behavioral** — many rejections happen here at senior level.
- **Design before requirements** — always clarify scope and scale first.
- **No company-specific prep** — stack, product, and values matter in HM rounds.
